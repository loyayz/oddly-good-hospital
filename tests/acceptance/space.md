# 空间、交通与安全改建专项验收

范围为阶段08、09、26、27、28。每项从正式需求推导，使用独立医院与合法内容定义构造最小场景；生产服务负责报价、提交和推进。预览及失败比较完整相关事实；进行中工作推进到实际边界后检查。下列高层样例检查区间与稀疏事实，不作帧率、长程经营或性能结论。

手工病人夹具使用正式医院UUID、关闭新接诊，并冻结合法的当日零机会计划：三班能力与机会均为零、随机种子为空、游标为零。该前提仅排除无关随机到访；手工入院、手术、改建、安全完成与人员移动仍执行完整生产固定步。

SPACE-28通过正式`HospitalJsonStream.encode/decode`在唯一`user://`临时路径写入并恢复乘梯快照，核验实际字节数与SHA-256，并保留整数与浮点数的原业务类型。原世界与恢复世界从同一边界按同tick推进至真实离舱及后续行走完成，比较规范化后的业务事实、原身份和单次磨损凭据；快照验证不放宽。

SPACE-35门诊改建及SPACE-36手术改建夹具隔离临床对运营科室就绪查询的依赖，保留实际临床、空间、排班和账目服务。科室相互作用由OPS运营专项验收；本专项继续检查同一病例的诊疗、手术、苏醒、真实转床及改建安全边界。其他空间夹具保留原科室依赖。

SPACE-36的初始闲置医护位于患者接待及设施展开、操作区域之外，入院仍核验真实身体占用。SPACE-40以新院原有库存为基线，只允许本次选中的一份复用资产从库存进入布局；其他既有库存完整保留，不把新院赠机算作本次新建或丢弃。

SPACE-36使用目录中的一格病例`B_S13_D09_M09`与`P_D09_SURGERY`：正式承托适配`SA_B_S13_D09_M09`、`TP_SURGERY1`和`R34`前置均保持。入院前以实际固定步等待当班的两名手术医生、手术护士、病房护士、查房医生及GP医生A/B完成共享基地整理和实际移动，排休者不要求整理；1800 tick内未满足时，明确报告前提失败及实际人员任务与位置。共享办公桌和护士工作台按真实轮转使用，不设置整理完成事实或增加独享桌。仅两名专用手术医生具备4级外科能力，GP与查房医生保持外科0级。实际接待、初诊和会诊后，通过正式选择方案命令确认该手术；到院请求中的方案意向不替代院长确认。该项验收手术及住院承诺在改建期间的安全连续性，身体变大与多格通行仍由对应空间用例验收。

SPACE-36在方案选择或真实开术前提受阻时，将完整世界流式保存至当前验收工程的`res://space36-plan-blocked.json`；失败详情记录实际文件路径、保存结果、医护职责/位置/整理与移动事实，以及真实床位、升级档和病房布局。该现场仅用于定位原规则拒绝原因，不替代实际护理覆盖、床边站位或手术就绪校验。

有效改建安排不能把原WardStay在预约、转床、恢复及最后查房期间的护理覆盖者和已承诺查房医生当作闲人疏散，床边会话之间也保留原责任。护理仍要求真实在所属病房、到实际床边且能合法接单；查房仍等护士实际让位。SPACE-36的护理尾段失败时，另存`res://space36-care-blocked.json`与最终病例、住院、医护、移动、会话和覆盖查询；转床时的住院快照与最终现场分别标明。安排保留到原护理、恢复和查房安全完成，不撤销安排来满足临床前提。查房开始后继续观察原会话工作量归零、同一病例治愈及患者真实离院，床位和展开预约实际释放后才判定通过；本例手术台60、护理床60、治愈360各结算一次，重复完成通知不产生第二笔账目。整个过程保留同一Attempt、领用凭据及待确认安排，不自动应用改建。

按[临床§8.2](../../docs/design/07-clinical-team.md#82-陪诊与探视的真实到院过程)，护理让位中的家属沿真实路线到原合法公共等候点；改建不能把这一医疗让位任务改成别人的疏散终点。地面移动目的地被覆盖时，从当前实际位置重发原等候请求，不改变剩余探视时间和窗口凭据，乘梯中的安全段先完成。尚未开始、剩余时间为零的普通探视到达等候点后真实离院，陪诊者继续公共等候；退出途中保留原Actor和容量，真正到院外才释放在院占用。护理继续等待真实到达等候点，不能以已经走出病房代替。

SPACE-33另以两名闲置员工位于同一改建源房间的独立场景核验疏散：公共终点须容纳完整身体、当前空闲，并与已发行移动的最终身体位置不重叠；路线仍有实际人物争用时不采用。两人通过真实移动分别到达不同合法终点，源布局与目标范围实际腾空后仅变为可以应用，安排不自动提交，不提前移除人员。

双床蓝图的护理点取正式布局`ward_two_beds`的`care_1=[0,2]`、`care_2=[4,2]`，随房间和床的实际旋转保持；两床都须让患者、护理护士和出院查房医生各自有合法路线。护理与最后查房按[临床§8.1](../../docs/design/07-clinical-team.md#81-护理覆盖与床边工作)顺序使用同一真实床边位，职责索引可以引用同一物理位置，查房不能与尚未让开的护士重叠。SPACE-35在独立最小病房中检查四向旋转、正式流式保存恢复与展开后的大身体医护空间；SPACE-36沿同一真实手术病例继续观察主动护理、护士实际离位和医生到位后查房。原门诊暂停和改建期间手术、床位、Attempt、耗材承诺的断言继续独立成立。

SPACE-08另在独立单格通道检查占地不变的设施适配：旁观者原本可以到达出口，候选患者区域会堵住唯一通道，冷查询与重复查询均须拒绝且世界不变；新增真实绕路缺口后，同一占地报价均成功。该边界与原大身体扩展、真实到位及安全释放共同验证适配，不能因复用通行图或出口路径省略新预约区域。

SPACE-01核对4×4矩形的四条实际墙边，显式房壳与矩形定义均使用独立坐标预期。SPACE-10在共享通行缓存上交替查询几何不同的两个世界，另核对热查询的16格直路、18格绕路与四分之一格位置到整数路网的接段距离和分别向上取整的行走时间；查询不能改写世界事实。实际移动仍检查当前身体、分数坐标扫掠、静止阻挡、礼让、原目标和请求序。
