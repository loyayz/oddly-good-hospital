# 候诊邻友资格专项

依据 `docs/design/08-hospital-life.md` §17.4：关系必须确为 friend，且朋友在同层、可达三格公共邻域闲等。治疗、真实移动（包括无独立 moves 记录的队列成员）、乘梯及院外不成立。既有附近人数、权重、种族偏好、环境带宽、全部合法座位枚举及采样频率不变。

入口：`godot --headless --path . --script res://tests/acceptance/waiting_friend_eligibility_runner.gd -- OUTPUT_PREFIX`。八个局部计算/运动用例共用一次工程准备，分别创建独立完整世界，保存操作前输入和观测状态，不使用外部缓存或历史二进制。与本次改动无关的完整导诊、让座、环境组合和性能测试不在此入口。

- idle：合法站立患者，真实 friend 关系，合法公共椅旁可达两格，选座条件为真。
- visitor_waiting / visitor_leaving：陪诊自身目的状态控制资格，不能借关联患者的候诊状态冒充闲等。
- own_move / convoy：真实请求后推进四个 0.1 秒步长，验证位置确实变化；队列成员没有自己的 moves 键。移动期间不算朋友；恢复完整世界后仍不算；实际走完后再次可被识别为公共闲等。不改位置、游标、计时或工作量来制造运动完成。
- foreign_floor / outside：合法独立输入，邻域资格为假；不声称验证了跨层或离院过程。
- clinical：合法初始输入把医生与患者放在诊断台正式操作/患者点，临床调度真实创建 GP 会话后验证其不是闲等。此计算边界不执行导诊，临床服务未绑定导诊器；没有伪造会话、实际到场或既往工作。公共椅与诊断台距离超过三格，因此选座条件阴性本身不能单独证明临床状态门禁，另直接检查同一个生产闲等资格函数。它不证明从入院到诊断的完整流程，也不宣称复现了临床邻友缺陷。

所有资格/选座计算前后完整世界（含 RNG）必须不变；输入和结果须通过世界校验。全套不是性能测量，不能据此宣布 item41 的环境/混合椅集成已全部通过。
