# 未到达接点与目标附近几何

回接点只是意图。未实际到达的 B 不能因为曾尝试 C 而被永久排除；真实到达才推进原路线游标，原请求和最终目的地保持。静态短连接可以绕过实际位置与目标附近的设施，未来可移动人物不构成提前否决整条连接的条件。

本专项从合法的已侧移/已后退边界开始，后续每一步都执行生产 Movement 和正常移动预算。家具与人物在输入构造时加入，没有在被测行走中瞬移、伪造到达或改变步长。

| 选择项 | 输入与独立预期 |
| --- | --- |
| RETURN-EARLIER-SIDE | `[40,71]` 的侧移点保留远处意图 `[48,80]`。两种简单连接分别被 `[48,74]` 的 1×2 家具与 `[44,80]` 的 2×1 家具阻挡；`[41,70]` 仍是实际游标处未到达且可连接的原路线点。重新接回该点，再沿完整原路线实际到达 `[48,80]` |
| RETURN-EARLIER-RETREAT | 同类几何，从 `[40,70]` 的真实后退检查点重新接回未到达的 `[42,70]`；原始后退标记合法，实际回接后才推进游标 |
| RETURN-TARGET-GEOMETRY | 从 `[41.8,69]` 走向 `[40.5,73]`，`[40,72]` 的 2×1 家具不在起点邻域，却挡住两种简单连接。必须利用目标附近设施边缘构造并实际走完短连接 |
| RETURN-MOVING-INTENT | 上述末段 `[39,73]→[40.5,73]` 当前被另一名有真实移动订单的人占据。静态连接不因此提前否决；另一人实际走到 `[38,73]`，两人均按正常预算移动并安全到达 |

每例验证输入/终态合法、身体与真实扫掠不穿家具或其他人、原目标/路线/请求保持、实际到达后才推进游标，以及没有整层回接搜索。首个真实移动步后用生产 HospitalJsonStream 写盘、解码和冷建 WorldState，验证完整事实及下一真实步一致。完整冷恢复后的最终到达另由 WIDE/LOST 和 CLIN-37 专项覆盖。

```text
godot --headless --path . --script res://tests/acceptance/local_return_recovery_runner.gd -- OUTPUT.json RETURN-EARLIER-SIDE RETURN-EARLIER-RETREAT RETURN-TARGET-GEOMETRY RETURN-MOVING-INTENT
```

前三例在修复前均能保持身体安全和保存恢复，却在 180 步后仍未到达；安全与可保存不能替代到达判定。修复后分别用 98、93、44 个真实移动步完成，第四例同时验证未来移动者不提前否决当前意图。
