# 目标占位的实际接触

依据模拟规格的真实到场、固定身体安全、原任务保留及回接意图规则。只读本次实际碰到的身体；走路中、同行中及未接触的远处人物不会被当成这个等待条件。等待不创建通行权或让行承诺。

```powershell
godot --headless --path . --script res://tests/acceptance/run_local_goal_contact.gd -- OUTPUT.json
```

| 用例 | 输入与实际执行 |
| --- | --- |
| LOCAL-GOAL-CONTACT | walker 从 `[40,70]` 实走至 `[43,70]`，holder 当前静止在目标。先发生真实身体接触，再检查连续 30 步保持实际位置、原目标/路径/请求。之后 holder 通过真实请求走到 `[43,67]`，walker 必须到达原目标 |
| LOCAL-GOAL-CONTACT-MIDDLE | 终点改为 `[46,70]`，`[42,70]` 另有固定身体。walker 必须先发生中途接触并绕过它，真正碰到远处 holder 后才稳定等待；远处目标有人不能提前否决这段行走。holder 再真实离开，中途身体保持，walker 到达原目标 |

两例均逐步核对真实身体、扫掠、移动预算和完整世界合法性；到达包含双方实际到点且订单清理。等待边界通过生产 HospitalJsonStream 写盘、校验摘要、解码并冷建完整世界，核对事实相同，再实际释放占位者并完整到达。没有瞬移或伪造到达。

目标必然占用以所有直立朝向都包含的内接正方形为保守证据，沿用既有身体尺寸与中心定义；不能仅因当前朝向包围盒的边角相交，就排除另一种合法到达朝向。没有修改精确迈步碰撞或旧整队目标判断。

关联回归包括 `LOCAL-BLOCKED-MOVER`：两个仍有原移动订单的人即使互相占着目标，也不进入静止占位等待。床岗位、CLIN-37 的派生停车点重选及导诊实际到场仍由各自所有者执行，移动层不改变任务目标。
