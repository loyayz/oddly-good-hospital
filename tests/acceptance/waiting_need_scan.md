# 生活需求到期不预建整层距离场

范围：普通生活需求调度不为全部到期患者的起点预先生成整层距离场。仍按原实体顺序决定资格、临床暂离、实际目标与移动，不延长轮询或期限。

`waiting_need_scan_runner.gd` 在一个进程内运行以下受影响契约：

- 普通12人同刻需求与原始/同步人体位置变化两组。测试参考保留原预热算法并强制逐人刷新；当前调度不预热。完整事实、随机流、身份、票序、身体位置和移动意图相等。未到期者及已有移动者排除，作用域清理断言保留。原参考产生12个场；当前普通调度产生0个场、0个原生批次。
- STAFF-35：8秒安全服务/兜底与45秒界限。
- STAFF-47：繁忙厕所正常排队、真实安全退出和期限取位。
- STAFF-61：相关空间、身体及预算查询保持完整结果。
- 原生距离场显式准备与消费对照。完整批次可供后续只读报价消费；无效输入及携带伪造部分输出的拒绝结果均不能安装字段，原事实、路线计数和作用域不受污染。两条预期错误日志属于主动注入的失败用例，不是生产运行错误。

计数只证明移除了到期调度这一处无条件全层预热；不把现存候选整区排序、普通报价自动距离场升级或导航图冷建宣称为已消除。显式准备API仍独立验证，不能为了旧计数断言在普通调度中保留全层计算。
