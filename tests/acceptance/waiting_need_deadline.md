# Public need deadline dispatch regression

Run `waiting_need_deadline_runner.gd -- <fixture-prefix> <unique-output-prefix>`.
The named immutable inputs are `<fixture-prefix>-outside-predecessor.bin` and
`<fixture-prefix>-inside-predecessor.bin`. The item044 baseline provides these:
normal first need at tick1800 with a pending clinic toilet route; and actual
31-step arrival at the ordinary toilet use point at tick1831, before claim.
Their generation and hashes belong to item044-baseline-artifact-manifest.json.
Do not replace them with an already-using snapshot or rewind completed work.

Each restored predecessor supplies the independent age449/450/451 dispatch
input. Only clock and invalidation revision change to declare elapsed seek
history; these tests do not claim to physically simulate that historical time.
Fractional tests advance the actual route in0.1-second steps before creating
an independent aged input. They distinguish rounded current region from full
body membership, and region arrival from exact facility-use arrival. Invalid
area and failed-facility cases are explicitly supplied input conditions.
Dispatch itself never changes position, cursor, work or clock in the harness.

At equality, safe cancellation precedes fallback, outside bodies cannot renew
facility travel, and only genuinely present atomic use can start. Region
selection and further walking cannot earn time. Protected transit, support
exit, actual80-tick work and current waiting return require separate functional
coverage; this suite is not whole-traffic, full-suite or performance acceptance.
