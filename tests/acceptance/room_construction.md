# 墙、定向门与房间建造专项

规则依据为 [房间、设施区域与同层导诊完整规格](../../docs/specs/26-11/2026-11-10-rooms-areas-guidance.md) §2、§3、§9、§10.1，以及 [房间用途数据](../../docs/data/room-purposes.json)。结构墙每格边长 1.5 米，价格只读取 `balance.wall_cost_edge`；当前每格边 20 币。地砖不随房间形成自动安装或收费。

| 编号 | 前置边界与实际操作 | 检查结果 |
| --- | --- | --- |
| ROOM-BUILD-01 | 空地逐段画墙、闭合前装门、闭合、重复确认、多门、无门与门朝向 | 未闭合墙保留并按新增长度收费；闭合且门朝内才成空房；门独占归属；重复确认不重复付款 |
| ROOM-BUILD-02 | 共墙房、重叠、孔洞、L形、1格房与设备放置 | 共墙不重收；连续无孔洞；重叠/孔洞失败原子；无最小内接矩形；设备仍须完整放下 |
| ROOM-BUILD-03 | 两间相邻房和真实家具，拆共墙、改用途、逐门拆除 | 原两房失效，新范围为空房；家具身份位置保留；拆最后门失效；墙门不退款 |
| ROOM-BUILD-04 | 已有诊断桌的门诊室，修改用途和开放意愿 | 九种服务用途；改用不移走家具；关闭不抹除结构；未知用途失败原子 |
| ROOM-BUILD-05 | 已具备设施解锁的合法建造边界 | 休息室不能放个人床或护理床；个人床只在宿舍；娱乐只在休息室；手术室拒绝第二张手术台 |
| ROOM-BUILD-06 | 已闭合房间的墙、快照与撤销边界 | 重复墙不收费；完整事实复制恢复保持结构；共墙连房门失败原子；破坏闭合失效，撤销恢复原结构 |
| ROOM-BUILD-07 | 护士已真实出发的普通行走 | 建墙不能截断既有实际移动目标，失败不扣款或改写世界；原旅程真实走完 |
| ROOM-BUILD-08 | 有门房间、未成房独立墙、单格与三格身体的合法静态输入 | 原生单格掩码和大身体完整路径与逐格逐向谓词一致；实际墙阻挡扫掠，入口缓冲区不可堵塞 |
| ROOM-BUILD-09 | 已排房间班表和当日覆盖的合法改用途前状态 | 预览只读；失败确认不泄漏班表修改；改用/失效原子移除不匹配房间引用；撤销恢复原班表 |
| ROOM-BUILD-10 | 三层医院中正式购入并逐层扩展的电梯 | 首层、中间层、顶层穿井墙均拒绝，预览与确认失败不改事实/账目；井道外同层合法墙仍按实际长度收费 |

所有用例从空地工厂或明确的建造/解锁边界独立开始，正式建造命令承担预览、付款、确认与失败回滚。金额从墙边数量、单价和所选门独立计算，不从旧面积收费快照推导。完成后分别校验建造状态和完整世界快照。

```powershell
& 'C:/programs/godot/Godot_v4.7.2-stable_win64_console.exe' --headless --path . --script res://tests/acceptance/room_construction_runner.gd -- --case=ROOM-BUILD-01 --case=ROOM-BUILD-02 --output=<结果路径>
```

省略 `--case` 执行本专项十例。选择编号只执行对应断言和必要输入，不执行其他用例后过滤报告。`elapsed_ms` 记录各例实际耗时。

本专项覆盖建造、几何和摆放边界。房间排班、服务资格、原临床安全完成与设施交接、真实个人桌床使用、公共区域、同层导诊和生产存档流式写入分别由相应业务专项验证；本专项通过不能替代这些结果或性能验收。
