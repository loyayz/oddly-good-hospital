# 环境表面与污渍来源

## 规则与交接

不改变日常生活 §4、§20 的环境数值、墙边判定、传播距离、污染生成上限、清扫工时或装修材料。来源位置只在服务绑定/恢复时冷建，环境所有者完成产污、清完与装修安装后维护一条；改建应用替换完整 facts，由集合身份重新绑定。无关几何变化不应重扫墙面或污渍。

位置表保存 ID，局部相交后读取当前事实。每层来源边界用于证明某格没有任何影响源，不决定分值：新增扩展，删除保守保留，最后来源删除清空。设施边界随既有设施来源缓存构建。噪声会话/施工源和附近人物的原获取方式不在本次修改范围。

原始同 ID 位置或分类改写，以及删除后新增导致净数量不变的集合原地改写，须由所有者通知或替换集合。材料值同 ID 替换可实时读取。这不是任意原始事实修改的自动检测器。

## 选择用例

```sh
godot --headless --path . --script res://tests/acceptance/environment_surface_sources_runner.gd -- OUTPUT.json ENV-SOURCE-SCOPES ENV-SOURCE-OWNERS ENV-SOURCE-RESTORE ENV-SOURCE-EDGES ENV-SOURCE-WORKERS
```

- ENV-SOURCE-SCOPES：1072 条已装表面、12 处污渍作为合法观察输入。300 次新 scope 不重扫；全部观察字段与无 scope 原始事实参考一致；完整 freeze（含随机流）只读；无关几何更新和同 key 材料字典替换。
- ENV-SOURCE-OWNERS：暖空索引后正式产污，实际派工、移动与 4 秒清扫直到最后来源删除；实际安装 MAT05 墙面，再同 key 更换 MAT08，逐步观察与原始事实参考比较，不伪造到场/完工。
- ENV-SOURCE-RESTORE：同数量集合替换、删除数量变化、同世界 facts 替换、新世界、外世界嵌套观察和空集合恢复。
- ENV-SOURCE-EDGES：索引计算边界包括删除极值时剩余来源不漏、floor 材料与桶污排除成员的计数维护、64 位原始 key 的保守回退。实际桶污由正式 spawn 生成；原始大坐标仅为计算输入，不宣称合法楼层或施工。
- ENV-SOURCE-WORKERS：使用正式 SampleJob，分别单任务和真实四任务线程组读取热索引；正式产污后再执行下一批，完整数值与串行相同，全部事实与随机流只读，worker 不重建来源。

功能交接复用 OPS-11、13、14、16、17、18 与 GROW-75；继续使用环境直接观察四例、布局缓存和 9×9 热图用例。无需因本次优化扩大导诊、移动或全功能回归。

## 固定操作测量

单独选择 ENV-SOURCE-MEASURE。在基线和候选隔离工程中用相同驱动、引擎和原生库运行三个独立进程对，交错次序。固定 1072 条表面、12 处污渍，预热后执行 1000 次独立 sample_at scope，计时仅覆盖这些查询，记录完整只读检查及来源计数。此结果不代表完整模拟步、渲染或整机帧率。
