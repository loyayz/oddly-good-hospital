# 候诊补充采用回归

依据：医院日常候诊、生活暂离与安全退出，模拟环境偏好，以及公共设施真实到场取位规则。此组支持 A13/A23/A36/A38 单独选择，不以旧实现当答案。

命令：Godot --headless --script res://tests/acceptance/waiting_followup_runner.gd -- 输出.json [--case=A13]。

- A13：真实行走/入座后转诊、未使用生活需求取消、真实厕所使用与返程拒绝、随身用品安全段、using/returning 保存恢复后安全返回再重试、怒气弃候原子清理与真实离院。
- A23：两人真正走向同椅，近者先坐；自动失利者下一边界停止追逐，手动仍等明确目标；赢家真正离开后失利者能实际坐下。
- A36：真实灯、水、安静信号和朋友实际走动/到达/入座；湿干最近邻与等距ID、故障、范围和座椅局部覆盖；串并行完整观察一致，包括真实水可用性与更近干燥源。OPS-18 同时验证真实临床/施工噪声、屏风、移动和旋转对 quiet 的响应。
- A38：另一实际人物先到自动站位目标后重新选择，无身体重叠；无座必要安全挪位的目标被先占后也重选，叫号不提前中止，包含保存恢复。

安全约束：不恢复强迫闲置旁人让路；不预占将来的椅子/站位；不让新的叫号权限取消必要安全移动。独立审计脚本作为合法输入的来源，所有被测移动、使用、返回与离院均执行真实模拟。
