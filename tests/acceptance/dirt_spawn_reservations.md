# 地污生成与有效预约

依据 `docs/design/08-hospital-life.md` §20，地污不得进入已承诺的伸展或工作预留；按最近距离、XY稳定选取其余合法格，保留来源去重、每格一份和地块预算。

执行：

```sh
godot --headless --path . --script res://tests/acceptance/dirt_spawn_reservations.gd -- /absolute/output.json
```

从合法世界真实放置椅子与非阻挡屏风，给三格身体角色实际预约椅子，独立按原始 `regions` 核对全部81个候选格。核验预留内部拒绝、边界仅接触允许、屏风排除、实际落点及来源幂等；只读查询不改变完整事实。恢复完整世界后仍拒绝预留内部。使用者位于预留外时，通过生产释放入口验证同tick重新开放，不手写预约完成。

预约索引由现有空间服务及其变更通知所有，不增加污渍专属预约缓存。既有 `occupied_cells` 并非生产预约字段，现改读完整 `regions`。选定关联回归为 OPS-45（生成合法格和最近排序）、OPS-16（真实清扫接续）、OPS-17（桶内合并与旧地污保留）。没有全量验收或性能结论。
