# 公共选区类型查询

依据：`docs/specs/26-10/2026-10-18-public-facility-area-use.md` §1、§3。选区不能因每个人的存在性检查重新遍历全院设施。已有静态成员索引可共享；故障、权限、占用和真实到场仍现场判断。

本次不改变业务规则或所有权交接。`select()` 复用 `WorldState.facility_ids()` 的类型桶，缺类时仍在建区域、身体索引和路线查询之前返回。首次或布局失效后的静态类型索引构建保留；普通 `touch(false)` 不重建。既有区域索引和区域内同类成员索引不变。

运行 Godot 4.7.2，显式提供输出路径：

```sh
godot --headless --path . --script res://tests/acceptance/public_select_type_index_runner.gd -- /tmp/public-select-type-index.json
```

专项包括：

- 首次缺类只构建一次既有类型索引，暖态、空类型、重复类型及普通 tick 只读取请求类型桶。
- 真实选区结果与未做类型存在性剪枝的选择算法一致。参考算法使用现行 `arrival_point` 入区接口，不能把旧 `waiting_point` 安全驻足点当作现行入口预期。
- 同 tick 增删/重新添加、同版本独立世界、保存恢复、同实例等数量事实替换/恢复。
- 故障/恢复、存放、房间权限、已占用区域仍可选、家具为空时允许短休/返回候诊安全站立。
- 事实、随机流、入参、失败输出和调用者查询边界不变，不新增预约或座位所有权。

以上是合法输入下的查询验证，不声称执行过完整移动或使用。实际交接选择 `STAFF-45`（自动先到区域再取座）、`STAFF-48`（后请求但先实际到椅者坐、保留原临床票）、`STAFF-69`（满座站立、按原扫描节奏重试、真实离位后坐下）及 `STAFF-21`（无椅短休与真实恢复）。不做长性能测量或全量回归。
