# 非阻挡屏风附近的真实等候

依据：`docs/design/02-content.md` §8 规定安静屏风不阻挡公共通路，日用家具按唯一维护集合判定且屏风不维护；`docs/design/08-hospital-life.md` §17.1 保留真实8秒随身用品、原票号暂离与唯一效果。公共设施区域规格的门口、临床操作区、交通登离区及真实身体/预约限制不变。

改动只让非阻挡噪声屏风的通用放置锚点不再成为虚构工作位。真实设施、区域入口、寻址、顺序、期限和动态占用算法均未更改。本用例不宣称解决所有真正不安全位置的远处空位选择。

运行：Godot headless 执行 `res://tests/acceptance/public_screen_waiting_runner.gd`，首个用户参数为结果 JSON 路径。

- `portable_current_position`：合法候诊患者在49个非阻挡屏风围成的区域，以当前真实合法占地开始原兜底。执行全部80个0.1秒步长；不得提前完成、创建移动或搜索整层站位。结束后怒气只加5一次，原票号和累计等待保留，暂离解除。每步校验世界。
- `portable_restore`：先真实执行31步，复制当前版本完整事实后重建原服务，验证余49步、原起始时刻、票号/累计等待/暂离和未提交效果；继续真实完成剩余49步。没有历史存档迁移。
- `screen_does_not_relax_other_safety`：三个身体、三种朝向、16个整数/分数位置，共144个只读计算输入，对照同场景仅移除屏风的结果。屏风附近可以停留，另有人体、临床患者/操作/维修位、门带和墙体仍拒绝。计算前提不声称人物真实走过这些输入坐标。

关联回归按共享 `safe_wait` 的实际使用者选择：员工真实短休、患者候诊/生活计时及安全取消、亲友/访客候诊与当前格式恢复。未触及适配、预约提交和移动内核，不因文件引用扩大至全量验收或长性能基准。结果、选例和运行环境另留本轮证据。
