# 真实临床连续交接

## 变化与范围

本次修复两处实际移动交接：

- 人物绕过身边设备需要连续转弯时，用身体附近的设施/人物空间索引取得真实边缘，验证有限的正交连接。保存已验证短连接的剩余拐点，逐步实际行走后才接回原路线。不搜索动态整层格网，不改目的地、请求顺序或通行权。
- 已有生活任务明确拥有的单人地面行走不再被当作固定工作身体。仍保护实际工作、临床离位、在途/工作培训、非行走姿态及其他移动拥有者。

实际影响是护送离位与护理到场、病房释放与出院、离班生活往返的碰撞交接。因此选择 CLIN-24、25、27、37，独立短连接和生活所有权合同，以及下列完整工时场景。并未选择全部临床库或进行性能测量。

## 执行

使用项目要求的 Godot 4.7.2 和真实原生库，输出目录须预先存在：

```sh
godot --headless --path . --script res://tests/acceptance/clinical_full_chain_runner.gd -- /absolute/output.json LIVE RESTORE
```

LIVE 和 RESTORE 可独立选择；只生成所需前提。同一批共享一次只读 `surgery_queue`，各次续跑独立复制完整事实。

治疗随机流在输入边界设为固定合法成功样本，不改结果事实。

输入从真实导诊、初诊和会诊建立候治疗边界，在该合法输入医院中加入手术与病房资源，通过正式选方案命令到候手术。资源建造过程不在测试范围内。之后不采用“团队已到齐”“最后一工作 tick”“恢复即将结束”或完成护理状态，也不移动人物、改变时间步长或预填完成事实。

两次续跑均实际完成团队到齐、1200 tick 手术、150 tick 苏醒、陪同转床、1800 tick 恢复、80 tick 护理、合格医生查房和离院。逐步检查真实世界与身体不重叠、服务剩余量逐 tick 推进、实际床边到位、唯一 Attempt、8包领用、一次床费60/治愈费360及总收入505。查房时长按开工前真实劳累、治疗能力和该人类的非查房天赋独立推导，不从服务时长倒推。

RESTORE 在护理护士实际局部绕行中用正式世界流式编码冷恢复，核对事实完全一致后继续。已停好的护送护士不被搬开，两次续跑均须亲自抵达原目的地并完成实际离院。

相关独立回归：`local_obstacle_corners` 验证连续拐点与障碍离开邻域后的持续路线；`life_local_movement` 验证已有生活旅程所有权与受保护工作，不将直接资格调用当作完整生活流程。

## 已知边界

这不是所有地图都能到达的证明。原有 SPACE-10 家具/入口几何仍有独立预存失败；本次合法临床链与双设备回接不替代它。旧 `rejoin_no_eligible_endpoint` 要求当前分量全图 BFS 和50 tick 重试的历史断言也不作为现行局部移动通过证据。功能、静态检查、冷恢复、渲染和性能分别报告。
