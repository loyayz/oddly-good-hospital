# 员工每日采样的同次读取复用

`python3 -B tests/native/department_staff_sample.py --output <新目录>` 原样提取完整生产 `DepartmentService.sample()` 与 `35d656dc` 基线，在真实 Godot 中运行。输入适配器提供员工事实和有序 ID；患者集合为空、环境关闭，患者分支辅助函数若被调用即失败。本工具不证明患者环境采样、工作线程或完整部门流程。

独立预期覆盖 0/1/4/32/128 员工、已有与新日统计、缺省任务/班次、体力35边界、重复tick、日界和旧日记录保留。仅外提同一同步调用内重复的日期与日记录读取；空员工集合不创建日记录，不增加跨步缓存。

微基准对0/1/32/128员工分别执行12个A-B-B-A窗口，每窗1000次真实sample调用；0/1员工使用每窗10000次以减少短窗噪声，创建前提在计时外。保留全部窗口和源码/引擎身份，不外推为整个部门、模拟步或帧率收益。完整部门功能回归仍须在目标环境运行。
