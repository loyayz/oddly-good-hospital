# 精确扫掠区间的局部验证

`python3 -B tests/native/body_sweep.py --output <新目录>` 在一个真实 Godot 进程中同时运行完整生产 `BodySweep` 和默认 `35d656dc` 基线；只重命名基线类，没有空间、物理或方法替身。

覆盖明确的严格接触、相互穿越、仅终点接触、对角擦角、增长和缩小包络，十万组固定种子的移动包络、精确网格组合，以及与引擎原生静态 Rect2 严格相交结果对照的近边界值。测试固定输入不改变游戏规则。SPACE-55 的原移动/增长包络断言仍需随完整环境运行；局部 helper 通过不等于完整移动流程通过。

测量先同时预热两侧，然后按 A-B-B-A 运行十二窗口，每窗 102,400 次完整 helper 调用。保留全部窗口和返回值校验，不删除较慢窗口。输出引擎、源文件、基线、工具哈希及原始时间。此结果只描述精确碰撞计算中的两份临时数组消除，不证明实际候选数量、整步性能、原生桥接、GPU 或正式验收。
