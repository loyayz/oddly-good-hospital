## Finite oracle and honest limitation

Getting the first3 real original-constructor visitors therefore requires practically the whole slow constructor, not a bounded prefix. Its visitor placeholders also have no business owner. This package does not rewrite ratios/order or claim those placeholders are legal owned visitors.

Instead oracle.gd accepts an EXISTING qualified current160 complete input and deterministically selects first3 floor staff, first3 floor patients and first3 actual VisitorStay-owned floor visitors. For each it independently clones full facts/RNG into A/B, queries four fixed prefix-grid points[6,6],[8,6],[10,6],[12,6], the actor's original point and first other same-floor actor point. Compares exact static reason strings and conditional dynamic result (null means not called); checks full facts/RNG unchanged. Uses original static_reason on A and candidate Query on B. This is a deliberately read-only spatial-query oracle, NOT constructor alias/commit equivalence. Existing actors are never teleported or committed into those hypothetical positions.
