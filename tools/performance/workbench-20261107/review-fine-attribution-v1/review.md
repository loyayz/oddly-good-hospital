## Timing semantics

FineTimer uses a stack of frames; direct timed children's inclusive durations are subtracted once from their parent. Synchronous nesting/recursion is handled per frame even when names repeat; grouped recursive inclusive totals would count nested time multiple times, so NEVER sum inclusive rows. Selected exclusive rows partition selected invocation time, not the whole step. The stack does not record caller edges. Therefore aggregate child costs cannot all be assigned to movement.advance without call-path evidence; methods can be called elsewhere.

The exclusive label means remaining time after selected timed descendants. It includes untimed descendants, wrapper dispatch, timer stack/dictionary overhead outside child measured intervals and scheduler delays. It is not pure self-code CPU time. FineTimer.enter timestamps after some work; leave timestamps before bookkeeping, so portions of child observer overhead remain in parent exclusive. There is no measured total observer overhead subtraction. Static global state assumes this synchronous single simulation driver, not concurrent simulations or asynchronous interleaving. A runtime exception may skip leave, causing mismatch/unclosed errors or raw script ERROR; either must invalidate the run. begin resets each step only after finish checked the preceding errors.
