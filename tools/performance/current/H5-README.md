# H5 detour scratch and first-segment proof regression

The single-body return search owns one actor scratch and exact proof maps. Each full predicate resets facing before the original initial rectangle; the early negative-first-segment helper uses the real actor and keeps original index/shape side effects. Scratch does not escape or cross decisions. Convoy and standalone/default calls retain their original path. Storage limits do not limit geometric work. No native, threading or timestep change.

## Selected regression commands
Use the project's compatible Godot and platform native library, a prepared/imported project, and absolute writable output paths. From the repository root (replace GODOT with the executable):

    GODOT --headless --path . --script res://tools/performance/current/h5_functional.gd -- /absolute/output/h5-main.json
    GODOT --headless --path . --script res://tools/performance/current/h5_interleaving.gd -- /absolute/output/h5-independent.json

Run serially under an external watchdog: main hard600s, independent hard120s. Require exit0, no raw ERROR/timeout, complete main six groups and independent16 assertions. These GDScript entrypoints and their oracle dependencies are byte-identical to the passed versions. The commands are portable usage descriptions, not a new tested shell wrapper. A timeout/missing result is incomplete, not a pass.

`h5_h3_reference.gd` is the literal previous H3 search/helper/predicate used only as test oracle. `h2_scratch_oracle.gd`/`h3_prefix_oracle.gd` are named by the hypotheses they test, not production alternatives. Original acceptance groups retain convoy/cap/permission coverage. Permission changes are main detour_step_proof's validated real reservation plus grant/revoke notification case. No newly added body-binding-specific transition test is claimed; lying/facing coverage is narrower.

## Scope and maintenance boundaries

Selected regression covers the single-body owner/predicate handoff, exact geometric/proof behavior, scratch isolation, derived shape/token effects, and original convoy/cap/permission cases. It does not establish whole-product release readiness, GPU/FPS, persistence support, or all workload sizes. No newly added body-binding transition case is claimed.

Keep scratch private to one synchronous decision. Reset before every full predicate's initial rectangle; early helper uses the real actor, never stale scratch. Unknown or storage-capped proofs execute normal geometry. Preserve original candidate ordering and earliest valid result. Future predicate changes must maintain these ownership and reset obligations and rerun affected tests.

The short restored-input command is a diagnostic business window, not full-run acceptance. Any release acceptance uses its separately authorized workload and published commit. Measurements and analysis belong in their dedicated evidence records, not this usage document.
