# 前后跟随队列

同行成员按 members 的稳定顺序排队，首位是队长。成队要求所有人已在同层真实集合点、站立、没有其他移动归属。旧横向 offsets 不再作为合法队列输入或存档。

成队和只读报价计算一次能够包含每个成员转向身体的方形队长代理。队员之间以实际尾迹弧长保持间距。每步只对新队长前端验证通路、人物、门和预约；队员位置从已证明的尾迹发布，不逐人再次申请移动权限。队长折返若会使队列包络重叠，则不得提交该步。

完整尾迹由一个复合身体索引项占用，外人不能进入队员之间的预留通路，折角外侧未占用空间不被外接矩形误封。门的通行尺寸采用队长代理，门预约直到完整尾迹离开后释放。拒绝一步不得部分移动队员或提交一部分门预约。

真实登梯、乘梯和离梯分别持有连接所有权。队列必须沿门户指定方向在入口完整对齐后才可领票。登离舱每个固定步共享一个队长距离预算，分段只细化安全证明，不额外消耗一帧。队尾完全出舱后才释放连接。容量、净宽和净高不满足时拒绝；不通过重叠摆放或瞬移解决。

临床转床先在病患实际所在层集合，队长到床不等于护士已完成交接。护士必须在队列结束后真实走到床旁岗位，随后才能开始恢复。只读估价必须包含集合、队列转移和最后床旁步行，不改变世界事实。
