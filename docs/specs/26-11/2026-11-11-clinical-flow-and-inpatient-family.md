## 1. 范围与术语

| 概念 | 本轮定义 |
| --- | --- |
| 患者复诊 | 原“熟客回访”机制的新名称；本轮只改概念与设计表述，不改复诊机制 |
| 普通就诊陪诊 | 普通患者到院后产生家属、陪患者在门诊公共区等候的旧功能；删除 |
| 住院陪同家属 | 部分住院患者对应的一名固定家属，白天陪同、夜间离院，持续到患者出院 |
| 探视家属 | 另外一名家属，按每日概率短时探视，不与陪同家属合并为同一人 |
| 有效探视时间 | 探视家属真实进入患者病房后可探视的累计模拟时间，不含路径与医疗等待 |

普通陪诊删除不等于删除所有家属。陪同与探视属于不同角色与不同生命周期，不能通过把同一人的停留目的从陪同切换为探视来实现。两类均关联本次真实住院患者，不成为新患者或无事闲逛居民。

本轮不展开新的聊天、鼓励、家属故事或其他互动表现，不重做患者复诊内容，也不据文档完成宣称功能已经实现。既有不冲突的空间安全、临床结果、费用与原有表现规则继续适用。

## 2. 确认结果与替代关系

| 项目 | 最终规则 | 被替代的旧口径 |
| --- | --- | --- |
| 普通就诊陪诊 | 删除，不抽取、不产生普通门诊陪诊请求 | 普通患者入院抽25%陪诊 |
| 住院陪同资格 | 开始住院时独立抽一次80% | 每位患者固定有陪同；将探视概率套给陪同 |
| 陪同身份 | 有陪同者时，本次住院始终为同一名家属；每日回来不重抽 | 每日重新决定有没有陪同或重新造人 |
| 探视概率 | 每患者每医院日白天独立抽一次30% | 早、中班各抽一次；讨论中的50% |
| 探视人数 | 每次最多一名，与陪同者是不同的人；两类可同时在场 | 同Visit总共只允许一位家属、复用陪同者为探视者 |
| 病房停留位置 | 两类可以同在病房，不要求都到床边 | 只有床边位置可算探视 |
| 探视计时 | 实际进入病房后累计；医疗中断暂停并保留已完成时间 | 到床侧才开始、让位期间继续扣30秒、打断后重计 |
| 夜间手术 | 不安排新手术，已开始的安全完成 | 只要晚班排齐人就可新开手术 |
| 跨夜家属 | 陪同者等患者回房后离院；探视者等回房并完成探视后离院 | 入夜立即清场或一律取消未开始的在院探视 |
| 家属生活需求 | 陪同者饮水和如厕，探视者不产生 | 对两类一律使用相同生活需求 |

80%与30%是最后明确确定的两个独立概率。30模拟秒为沿用既有节奏的初始探视时长，属于获准合理确定的数值，不是把旧50%保留为另一层抽签。30模拟秒等于300个0.1秒模拟步，按当前医院时钟对应24医院分钟；暂停、1×/2×/3×不改变所需模拟量。

## 3. 患者复诊仅更名

面向玩家和设计文档的功能称为“患者复诊”。原居民留存、自然再次来院及带前情的表现机制不在本轮改变：

- 普通来客先选病症与种族，再按既有规则确定身份，不以家属需求改变来客计划。
- 复诊候选仍须满足真实离院间隔、病症/身体兼容和身份互斥；现有两完整医院日间隔与20%身份选择概率保持。
- 沿用居民姓名、外观、性格与关系，新Visit的病症、诊断状态与检查结果、怒气和收费按本次重新建立。
- 既有记忆与短演出仍须真实来源及原参与者，不新增治疗、金钱或奖励加成。
- `Resident`、现有存档键、`memory_callbacks`等内部标识不因文案更名强制迁移。

“患者复诊”不意味着只能治疗上次相同病症，也不表示上次治愈失败。既有“熟客”身份名册可以继续描述被记住的居民，不需要把所有“熟客”字样机械替换。

## 4. 住院陪同家属

### 4.1 生成与绑定

1. 资格来自患者开始住院，不来自普通门诊入院。
2. 每次关联就诊首次进入住院阶段时评估一次80%概率；结果保存，有陪同与无陪同均不因换床、重试、读档或次日而重新抽取。
3. 抽中时建立一名固定家属与患者的关联，没抽中则本次住院没有陪同家属。存在陪同者并不是住院、手术或护理开工前提。
4. 同一住院过程每日回来的都是这名家属，不创建另一个同名人物，不将每日返院当作新的陪同资格。
5. 探视概率与陪同资格分别判断，没抽到陪同仍可有探视，没抽到探视不影响陪同返院。

### 4.2 日夜往返

白天在医院陪同，晚上真实离院，不住在病房或占患者床位。患者尚未出院时，第二天白天再从真实入口返回，持续到患者出院。

若患者手术延续到夜间，陪同者继续在手术室外等待；手术与安全转床结束、患者实际回到病房后，陪同者才离院。不能只看到“手术完成”便省略回病房这段陪同。

### 4.3 手术随行与生活需求交接

通常流程为：在病房陪同 → 患者去手术时随行 → 手术室外等待 → 随患者回病房 → 白天继续陪同或夜间离院。

陪同者可去公共饮水设施和卫生间，遵守现有真实到场、排队、身体适配、使用与安全退出规则。患者需要去手术时不用等待家属完成生活需求。此时家属的路径顺序固定为：

1. 完成饮水或如厕。
2. 先真实回到患者病房。
3. 发现患者已经去手术，再自行走到手术室外等待。
4. 若患者已经回病房，就在病房继续陪同，不追赶过期手术目标。

家属生活需求属于本人，不暂停患者的临床票、护理进度或手术任务。生活需求结束后不能直接从设施改道去手术室，以跳过已确认的“先回病房”行为。

## 5. 探视家属

### 5.1 每日意向与独立身份

每位仍在住院的患者每医院日白天评估一次30%探视意向，命中后至多一名探视家属来院。不能在早班、中班各抽一次，不能每次扫描、换床或读档重抽，也不为没有抽中的患者补发保底探视。

探视者是另一位家属，不是既有陪同者。两类身份独立，不能因已有陪同者而跳过当天探视，也不能因探视者出现而移除陪同者。本轮未要求探视者跨日固定为同一个人，不把这一点写成已确认限制。

### 5.2 到场与计时

探视者实际进入患者所在病房后开始累计30模拟秒，不必到床边。正常走路、等入口、乘梯、病房外或手术室外等待均不算有效探视。

探视结束后真实离院，不转换为长时间陪同者。探视者停留较短，不产生饮水或如厕需求。

### 5.3 患者正在手术

探视者到来时患者正在手术，就在手术室外合法位置等待。患者回病房后再进入病房并开始探视，即使等待跨到夜间也完成探视后离院，不因晚班到来取消已经在院等待的这次探视。

## 6. 病房护理、治疗与共同空间

一名陪同家属和一名探视家属可以同时在病房，两人都不必站在床边。站位、座位与移动取各自真实身体，仍须保留医护操作区和出入路线，不以“允许两类家属”绕过实际空间限制。

患者在病房接受护理或治疗时，两类家属都到病房外等待，不只是退到房内另一角落。护理或治疗结束后再返回。

探视受打断时暂停计时并保留累计量。例如已经有效探视12秒，之后在房外等20秒，再回到病房时还需18秒；不是已经过了32秒便立即结束，也不是再重新等待30秒。出房与回房的路程不计入有效探视。

医疗优先仍服从真实空间：家属开始让位不等于身体已退出，医疗人员不能穿人或瞬移。既有2秒开始响应与安全行走约束继续适用，不将2秒当作无条件完成撤离的承诺。被动住院恢复是否推进仍由床位、护理覆盖等原条件决定，与家属是否在场无关。

## 7. 夜间手术与出院

### 7.1 手术开始边界

夜间不安排或启动新手术。白天已开始的手术继续安全完成，苏醒和转床按原医疗规则完成，结果、工时、耗材与床位承诺不重置。夜间规则不代表停收全部门诊、不停止护理，也不允许为等家属而延误治疗。

手术处于尚未开始的准备或排队阶段时，不能凭“已安排”绕过夜间新开术限制；下一白天再沿原资源与团队规则安排。已开始与未开始的判断应使用实际临床开工事实，不使用播放动画或计划时间。

### 7.2 出院优先

患者出院时，尚未完成的探视终止，在场家属随患者离院。取消尚未到院的探视和陪同请求，以及该患者后续的陪同返院。出院不等探视满30秒，不等院外家属回来。

家属各自完成必要的安全退出与真实离院。正在电梯内、生活设施中或安全移动段的角色不能直接消失；空间、座位、路线和电梯占用只有实际释放后才可复用。终结后的请求不得生成孤立家属。

## 8. 沿用的安全规则与实现约定

本节衔接既有系统，不把实现细节误写成新增玩法确认。

- 时间沿当前医院时钟，以早/中班对应本规格白天、晚班对应夜间；不修改一日长度、班次长度或新增第二个时钟。
- 按既有arrival随机流与稳定患者顺序消费家属抽签，保存已评估结果。住院陪同一次资格和每日探视资格使用不同记录，不能共用一个概率或窗口消费位。
- 可沿既有访客请求扫描处理首次白天合格机会；同日已评估不再评估。夜间新住院不夜间补发新的白天家属到场，已在院跨夜手术等待按第4、5节继续。
- 入院仍从真实入口开始，路径不足保留轻量请求，不先生成院外演员；停止新接诊不会取消现有住院患者合法的家属到场。
- 每类请求至多一份，两类分别去重；允许同时两类家属不等于允许重复陪同者或重复探视者。上一场探视未结束时不叠加第二位探视者。
- 患者暂不接待探视仍沿原无心情、评分或奖励惩罚规则，只约束探视者，不取消陪同绑定。本轮未新增邀请或重抽按钮。
- 无安全站位、座位或路线时不能挤入病房、缩身或抢临床空间；无座但有合法站位时可以站立。家属条件不成为患者治疗准入门槛。
- 改建、换床及安全转诊沿既有真实退出与身份清理合同，不能用重新创建家属来回避既有身体和资源占用。

## 9. 身份、进度与保存合同

实现可以沿既有Visit、WardStay、VisitorStay及请求所有者调整字段，不要求新建一套并行模拟系统。必须保存以下业务事实：

| 事实 | 保存与恢复要求 |
| --- | --- |
| 陪同资格 | 记录是否评估及结果，无陪同也是稳定结果 |
| 固定陪同身份 | 夜间离院后保留绑定，次日同一人返回；不能因Actor已离院丢失身份 |
| 每日探视结果 | 记录医院日与是否已评估/结果，早中班、换床及读档不重抽 |
| 两类家属状态 | 分别保存请求、关联患者、真实在院/在途/院外状态，不复用为同一人 |
| 探视进度 | 保存已累计有效模拟量或等价剩余量，医疗中断与读档不清零或继续偷扣 |
| 手术与生活交接 | 从患者当前实际状态继续；生活需求后先回病房的步骤可恢复 |
| 出院终结 | 取消未入院和返院计划；保留已有Actor安全离院所需的最小引用 |

同一居民仍不能同时拥有冲突的患者、访客或其他在院身份。现有陪同绑定不得在午夜因普通访客临时身份清理而被释放；真正结束住院后的清理沿原引用与保留预算完成，不能无限积累每日家属记录。家属进度不复制患者的治疗结果、恢复量、医疗预约或收费凭据。

旧存档、旧请求和旧purpose字段如何迁移须在实施前依据当时实际数据核对；本次文档不声称已完成迁移，不通过悄悄重新抽签解决兼容问题。

## 11. 专项验收清单

以下为后续实现的目标用例，本轮未运行。用合法业务边界准备前提；被测的实际到场、出房、返房、手术随行与离院必须真实执行。概率边界应通过受控随机输入验证0…9999下的8000/3000阈值，不以少量随机样本恰好达到比例作为通过依据。

| 编号 | 场景 | 必须得到的结果 |
| --- | --- | --- |
| FAMILY-01 | 普通门诊入院、候诊、治疗、离院 | 全程不产生普通陪诊请求或家属Actor，不消费旧25%陪诊抽签 |

| FAMILY-04 | 同日早班后进入中班，反复扫描和加载 | 当日探视仅评估一次，不重抽或补第二次 |
| FAMILY-05 | 陪同者晚间离院、次日返院 | 同一身份真实离开并从入口返回，不重抽80% |

## 14. 初诊、一次检查与原医生接续

### 14.1 诊断判断与结果

初诊仍由具备资格的门诊医生真实完成。以开始时医生的诊断能力冻结证据不足概率并抽一次，服务完成后揭晓。诊断能力越高，直接确诊概率越高；不再保存或显示诊断分数，也不按病症档位、设备升级或本院治疗经验加分。

- 未命中证据不足：完成初诊即确诊，显示正式病名，原医生选择治疗方案。
- 命中：保留原门诊、原医生及一次检查待办，先去当前楼层导诊，由该层安排适配检查。没有合适诊疗室按第16节换层。
- 只选一个已开放且身体/设备/人员适配的检查模式；不同时排光谱和共振，不为少收费用补检查。合格完成即可取得足够结果，未完成沿原Session恢复，不算另一次。
- 检查完成后直接回原门诊，同层走路、跨层使用真实交通，加入门诊队尾，不插队、不再导诊。原医生实际复核结果并确诊，然后选择方案。
- 检查期间原医生下班不打断检查；完成后确需返回原医生时再按下节处理。正在执行的其他安全医疗服务同样不因原门诊医生换班被取消。
- 保存/读档、换层、移动受阻、改派设备和第一次治疗失败均不能重抽诊断、重复检查或重复收初诊诊费。

### 14.2 下班、返院与结束

需要原医生接续时发现其已下班，患者安全离院，保留同一Visit、病症、检查结果、治疗次数与实收凭据；不是新患者复诊、弃候退款或重新抽病症。

1. 第一次因此离院所在医院日记为D；在D+1随机日内时刻返院。
2. 返院从真实入口进入，直接到原门诊所在楼层导诊台，不随机选其他楼层。轮到他办理时才判断原医生是否上班，不在生成返院计划时先匹配班表。
3. 医生已上班：安排原门诊队列，接续已有结果；仍未上班：安全离院，并安排D+2随机返院。
4. D+2同样办理；轮到时仍未上班，投诉一次并离院，本次就诊终结，不继续第四天返院。检查历史保留，不删除实收费用。
5. D+1/D+2当次需要再次处理原医生下班时，沿同一既定日序推进，不能把D改成今天而无限重启三天窗口。正在进行的服务先安全完成。
6. 投诉沿原投诉事实和评分入口记一次，不另加新的罚款、永久关系惩罚或禁诊。日后随机再次生病可作为新Visit，沿原20%身份选择、两完整医院日间隔和身份互斥规则；不复活已结束的这次诊疗。

原门诊楼层暂时无可用导诊台时保留定向返院目标并合法等待，不回退为新患者随机选层；仍执行适用的普通等待与安全退出规则。原房间关闭/拆除不等于医生离职，沿既有无效目标与安全改建处理，保留原医生与检查事实，不借此重做诊断或自动换医生。原医生正常短休等临时不可用不自动等于已下班，以真实班次/在班状态为准。

### 14.3 离职或被解雇

原医生真正离职或被解雇时，随机转给一位仍在职、有门诊资格的医生，更新负责医生及其门诊目的地，保留已完成检查与就诊收费，不因原医生永不返岗而卡住。只抽一次当前转交，保存结果；无合法候选时沿原等待/缺员提示，不造医生或抹掉检查结果。合法接续地点、当班与真实到场仍须核验；不是对医院全部诊疗设施预搜索。之后若接续医生也下班或离职，分别处理其真实原因，不能借换人重置已经消费的返院日序或治疗次数。

## 15. 治疗、住院及手术

### 15.1 方案与普通治疗

保留常规、舒缓，以及部分病症的手术方案；默认由医生自动选择，玩家可指定当前合法方案。沿用研究、病症适配、医生能力、75%预计效果底线、材料和真实空间条件，具体成功率与工时公式见临床章。方案选择不提前预订整条治疗链，也不授权导诊按全院距离或负载寻找最优设施。

原门诊有合适治疗设备且原医生资格足够时直接治疗；否则回当前楼层导诊，由其安排具有适配设施和人员的诊疗室，缺项按第16节换层。普通治疗包含常规与舒缓，成功后结算离院；原C档舒缓强制住院观察、对应R33/病床/护理门槛及60床费随该流程一并取消，舒缓其余研究、治疗能力、成功率、1.8倍工时、耗材和治愈费倍率不因此改变。

每Visit最多两次**实际开工**的TreatmentAttempt。首败由医生自动选择原方案或另一当前合法方案并继续，不再诊断、检查或收初诊费。第一次为玩家指定也不锁死第二次方案；玩家仍能在第二次实际开工前指定合法方案。第二次失败友好转诊。准备超时、移动、缺货、维修、换班、暂停和恢复不是新尝试，不重领耗材或重抽结果。

### 15.2 先住院，再安排手术

选择手术后，导诊负责安排病房，**不负责安排手术**。本层没有兼容空床时随机前往其他有可用导诊台的楼层；无其他层才留在原层等待，该等待沿用普通候诊离院规则，不阻塞其他患者。

患者实际入住后才建立本次住院与原床归属，并触发第4节80%陪同资格。此后留在病房，由医院按手术室排班、原手术队列及合法完整团队安排。缺手术室、手术医生或完整开工条件时继续在病房等，不再去导诊，不因这类短缺自动转诊。

手术室可以在其他楼层，不要求该层另有导诊台。患者从病房直接去已安排手术室，完成手术和15秒苏醒后，由护士实际带回原病房；原床不能在患者离房期间让给他人。医护、患者、必要同行的真实身体、门、电梯/楼梯容量和路线全部核验；不能用“允许跨层”省略安全运输，不能传送或将两层同XY当同一位置。

原30秒开工准备窗口只用于已到场患者和术组的真实准备，不把长距离跨层路程挤入该窗口。准备失败释放本次术台/团队/耗材预约，患者安全回原病房继续等；原床与住院身份不释放、不重新抽陪同。病房护理覆盖与手术护士须分别合法，不能一人同时占两个安全岗位。

### 15.3 夜间、失败与出院

夜间不启动新手术，准备或已安排但未实际开术不算“已开始”。白天开术延续到夜间，手术、苏醒和回病房安全完成；家属跨夜按第4—7节处理，不能因天黑取消原临床承诺。

首次手术失败先回原病房并完成该次必要恢复与护理，再由医生自动选择第二次治疗。若再手术，继续在原病房等待；改为普通方案时按合法地点执行，不为改变方案重复初诊/检查。第二次失败在完成必要安全医疗后友好转诊。术后成功也须完成真实恢复和必要护理才能结算离院，不能在手术动画结束时提前治愈或释放病床。

“等手术”与“恢复”分别保存。未开术不预先累计或刷完未来Attempt的恢复量/必要护理；第一台开术冻结本次恢复目标，回房后才推进适用恢复。重试各自有唯一Attempt，床与家属归属仍是同一住院过程。实际床故障、护理覆盖中断、改建和安全转诊保留原医疗安全合同；仅缺术台/手术医生不套病床故障120秒或护理缺员300秒的转诊期限。

## 16. 随机楼层选择与导诊

### 16.1 新患者

从医院实际入口生成并入院后，从有可用导诊台的楼层等权随机选择一层，再按原规则选择该层可用导诊台、真实走到队尾加入。楼层被选择的机会不因该层导诊台较多而额外加权。没有可用导诊台时在入口附近合法位置等待；不得堵住入口或绕过真实落脚容量，沿现有候诊离院规则处理。有台可用后再选层。

可用导诊台沿原已启用、合法、护理岗位可提供服务等条件；已有患者排队不等于不可用。只维护/读取导诊楼层与导诊台资格，不能在选楼层前计算全院门诊、检查、治疗和床位能否完成。必要的跨层交通及身体安全检查不算诊疗设施预搜，无合法路线不得假报到达。

### 16.2 当前层没有目的地

初诊无可用门诊室、检查/普通治疗无合适诊疗室、入住无兼容空床，统一在**其他**有可用导诊台的楼层中等权随机选一层，先真实前往该层导诊，再检查该层当前需求的目的地。仍无目的地就重复随机换层，不预先搜索全院设施，不要求遍历未访问层，也不因曾来过而永久排除。

没有其他楼层可选时，患者保留等待及需求，其他患者继续办理；不暂停整台导诊队列。等待患者不持续占用导诊服务位、护士或临床资源，仍需合法队列/等候空间；重新满足条件时沿原序号公平安排，不通过每tick反复呼叫刷导诊工时。目的地相关条件变化或可用导诊楼层变化再处理，原候诊累计、怒气与离院规则继续。

普通门诊/检查/治疗/住院需要导诊安排的楼层必须有可用导诊台，缺少时界面提示“该楼层缺少可用导诊台”。手术是医院住院排班流程，手术室所在层不受该条导诊要求约束。

### 16.3 在途变化与例外

选好楼层后不逐步复查导诊台状态；到达后发现不可用，再随机选其他可用导诊楼层。实际路障和交通安全仍由Movement处理，不借“途中不检查”穿墙或越过停运电梯。无可选目标时合法等待，恢复时继续，不能瞬移回入口。

同层多台导诊的真实队尾、离队后新序、临时缺员保留已在队患者等原规则继续。临床改层保留原Visit和有效等待，离开原导诊队列后不带着旧台的排队点、号码或未完成工时跨层插队。

两类明确例外：检查后直接回原门诊队尾；原医生返院直接去原门诊层导诊。另有手术患者由原病房直接往返手术室，不随机逐层找手术室，不进入导诊循环。

| 光谱/共振基础检查 | 18/22模拟秒 | 保留原执行者诊断能力、设备和天赋工时修正 |
| 检查后复核 | 基础8模拟秒 | 沿初诊工时修正，最低4秒；不另收诊费、诊桌费或耗材 |
| 返院随机时刻 | 对应D+1、D+2各在日内[0,18000)tick等权 | 计划建立时抽一次保存；不按医生班表重抽 |
| 楼层与同类候选 | 稳定ID列表内等权随机 | 楼层等权；不按房间数、距离、负载或未访问历史加权 |
| 最大治疗次数 | 2次实际Attempt | 与准备次数、换床、跨层和返院次数无关 |
| 手术/恢复/护理 | 原120/150/180秒手术、180/240/300秒恢复、15秒苏醒、8标准秒护理 | 不包含术前无限定时长等术组；实际覆盖与安全规则照常 |

诊断、检查模式及原医生离职后的随机接续使用既有treatment流；导诊楼层/目的地选择使用registration流，返院时间使用arrival流。实现时按原稳定实体处理顺序消费，决定立即落入所有者并保存；界面查询、缓存重建、重复通知、途中扫描与读档不消费第二次随机数。家属抽签仍按第8节独立记录，不把诊断或返院复用成家属概率位。无需为新规则再造独立全局时钟或第二套随机系统。

治疗概率、费用、材料、工时和合法方案评分中未被本轮替代的部分沿原设计，不任意新增成功加成。新检查概率、返院等待、术前占床和普通舒缓不住院改变吞吐与账单条件，旧经济解析只可在其明确条件内使用；正式数据迁移后应重算受影响样例，不能用旧数据给新玩法背书。

## 18. 事实所有权、保存与实施边界

| 所有者/事实 | 必须保存和保持 |
| --- | --- |
| Visit诊断 | 原门诊/医生，初诊是否已抽及结果，唯一检查请求/完成结果，复核与确诊完成状态，收费凭据 |
| 未完成就诊返院 | D、下一目标日与已抽时刻、已消费返院次数、定向门诊层、在院/离院/院外待返状态、投诉与终结凭据 |
| 导诊与跨层 | 当前需求、已选目标层/台、原Visit与有效等待、真实到达/入队事实；个体等待不等于整台暂停 |
| TreatmentAttempt | 每次实际开工、结果/数值/费用/材料冻结、剩余工作与唯一结束；最多两份 |
| WardStay | 已入住原床、术前等待/离房手术/回房恢复、真实床位占用和覆盖；不依赖尚不存在的Attempt提前生成恢复 |
| 手术准备/执行 | 已安排术台和互异团队、真实准备到齐、夜间开工门槛、跨层行程及返原床目标 |
| 家属 | 第9节完整事实，尤其首次住院资格和固定身份；同Visit两次手术不重抽 |
| 财务与身份 | 同一Visit返院不重复初诊收费/统计新病机会；实收项目不因离院暂存消失；终结后取消返院和家属计划 |

未完成就诊可在院外保留最小接续状态，但院内Actor、座位、队列、导诊服务和医疗预约必须真实安全释放；返院时重新从入口建立唯一实际在院身份，不在院外保留幽灵占位。未完成的同一居民不能同时被新来客计划抽成另一患者或家属。相关状态须进入现有存档与内容兼容检查，不用读档重抽或创建第二个Visit来掩盖迁移问题。

本次不修改 `game/`、`tests/`、`docs/data/`、编译内容或性能工具。后续实施至少成组处理：证据分数与双检查数据/状态；原医生接续与院外Visit；楼层导诊资格及个体让过；先住院床归属、手术跨层安全运输和夜间门槛；普通舒缓住院门槛及账单；固定家属与每日独立探视；界面、内容校验、保存兼容与受影响用例。只改概率配置会让旧状态机运行半套新规则，因此不能据文档已合并声称功能完成。

## 19. 临床与跨层专项验收清单

| CLFLOW-04 | 同层及跨层完成检查返原门诊 | 真实到原门诊队尾，不插队、不经导诊；原医生免费复核 |
