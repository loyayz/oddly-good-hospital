# 电梯自动方向运行与实体队列

日期：2026-11-13

对应设计：[交通 §4、§4.1](../design/11-growth-arrivals-recruitment.md)、[导航 §6](../design/16-navigation-space-selection.md)、[技术同行生命周期](../design/04-technical.md)、[住院家属](../design/07-clinical-team.md)。与旧电梯单组运输、按移动请求选择个人、单组往返估时及电梯票描述冲突时，以本文和同步更新的设计为准。

仅变更本轮确认的电梯运行与候梯规则。保留 b87545e 的既有简化、安全移动语义及家属、员工睡眠交接修复，不以本轮改动覆盖或回退它们。其余身体、碰撞、层间时间、故障与缓降、医疗承诺、费用及维护等沿现有设计。没有电梯票，不锁个人，不增加最长等待优先机制。

## 2. 自动运行

- 电梯根据实际等待者和车内乘客目的层自动运行，无需求时停在当前层。
- 沿当前方向服务，在该方向最远仍有需求的楼层换向。不能因后方新增呼叫立即反向。
- 空闲时上下方向同时有呼叫，先选较近方向；等距使用固定顺序。实现需明确固定顺序并保持重复运行、存读档一致，本文不擅自增加优先级或指定未经确认的上下优先。
- 当前需求不是绑定个人的接送承诺。候梯者离开或改变目标不锁住轿厢，也不重置在途实际位置或剩余时间。

## 3. 上下行实体队列

- 距电梯门三格外分别形成上行、下行队伍，按实际先到先上，不以远处发起移动请求的时间授予优先权。
- 队位根据门的位置、方向与可走空间自动生成，人物必须真实走到位置。队位变化不能替代身体移动。
- 正式队伍排不开时，在附近合法位置等待补位。队伍和候补等待均不能堵门或通道，不能叠人、越墙或瞬移。
- 生成与移动检查完整身体、门、墙、家具、已接受扫掠及现有安全职责。门前保留真实上下梯通行空间，不把“三格”当作所有体型均合法的证明。
- 队列或出口被墙、家具堵住时显示可定位原因；不能穿墙，也不能无限无原因卡住。障碍移除或空间恢复后能够按真实状态继续处理；没有合法位置时明确保留未完成状态，不伪造到场或通行。

## 4. 先下后上与容量

1. 到站后，该站目的乘客全部真实下梯，才能开始上人；仍去其他楼层的车内乘客保留真实身份和目的地。
2. 当前服务方向队伍依次登梯，轿厢满或本方向队伍已上完就出发。不因等待未到场的某个人而锁车。
3. 患者与陪同家属一起乘梯。既有护理陪同组、受保护尾迹及安全交接不变；独立探视家属不因此自动并入患者同行组。
4. 队首同行组放不下剩余空间时，整组等下一趟，后面的组不插队，电梯先出发；不能拆组填空位。
5. 容量数值由实现结合真实轿厢空间和完整身体合理确定并验证。不得擅自固定未验证的尺寸、席位或人数，也不能继续以“一车最多一组”替代容量检查。
6. 如果整组连空梯也无法容纳，显示实际空间不兼容原因，沿现有可达性与安全规则处理；不得以“等下一趟”掩盖永不可能满足的条件。

## 5. 状态、恢复与既有安全约束

交通保留真实停层、方向、阶段、乘员及目的地、剩余时间和真实到达顺序。跨层安全段必须真实完成；取消、离院或改建不传送乘客或提前释放身体。静态队位可派生重建，但读档不得重抽身份、改写医疗排队承诺或重置在途进度。

家属的可选行程重算不得取消正在执行的局部安全移动；员工到睡眠设施的位置不等于移动所有权已交接，必须等原移动自然完成再改变睡眠身体。这些既有修复保留，不由方向队列重新实现另一套规则。

实际运行与估时使用同样的方向和容量规则。估时只读，不建队、不预约；步行与当前安全段共用同一时间轴，不重复累计重叠等待。未知时返回未知和原因，不能当永久无路；旧单组往返公式、257组等条件吞吐数不作为本轮依据。未经实测不得声明性能收益。
