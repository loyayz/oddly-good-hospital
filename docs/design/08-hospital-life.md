# 医院日常、科室、体验与居民回馈

版本1.97.0。医院的服务质量通过评分可见；病人的怒气、性格和现场情境共同产生行为；装修、导诊、分区、照护与排班提供改善办法。所有规则沿用暂停、原票号、公平调度、安全服务锁和可恢复存档。

## 1. 五类评分

评分统一0…100，可附0…5星、每半星一档的显示。展示分项、样本数、统计窗口和最近三条具体原因。评分不改变患者优先级，不自动解雇员工，不扣除既定补助，不偷偷增加到访人数。医生的工作评分就是该医生的职工评分，不另存一份重复总分；职称和能力独立显示。

| 对象 | 评分含义 | 分项权重 |
| --- | --- | --- |
| 病人 | 本次就诊体验分，说明这位病人接受服务的感受 | 结果30%、流程30%、照护20%、环境20% |
| 医院 | 全院服务与经营质量 | 病人体验40%、诊疗质量20%、流程15%、环境15%、职工体验10% |
| 科室 | 该运营科室的服务表现 | 病人体验35%、诊疗质量25%、流程20%、环境20% |
| 医生 | 已实际执行工作的评价 | 工作质量40%、本人服务反馈25%、交接协作20%、岗位履责15% |
| 其他职工 | 按岗位实际任务评价 | 工作质量35%、本人服务反馈30%、交接协作20%、岗位履责15% |

病人评分是就诊体验，不是病人的价值或“优质客人等级”。尚未治疗时结果项不参加加权，其余已观测项按权重归一化，卡片标“进行中”；离院后冻结最终分数。没有数据的对象显示“积累评价中”，不能显示0分或虚构五星。

结果项：治愈100、主动安全转诊65、放弃等候50、两次尝试后未治愈40；检查和会诊不提前算治愈。流程项=clamp(100−超出宽限的实际排队秒数/6−实际走到错误入口次数×8−院方重复失约次数×10,0,100)。错误入口只取§6的真实到达事实，提前纠正不扣这项。同时等待多个原因只取原主服务QueueTicket的有效候诊事实；患者实际服务、正常恢复及原规则暂停该票累计的时段不计排队。医护依规培训与休息不算员工拒工，但不因此暂停仍在真实候诊患者的原票或免去已发生的等待。环境项为病人在院时实际所在格环境值的时间加权平均。照护项从80开始，每次不同阶段的及时解释/安抚+5、最多100，已承诺而未处理的求助每项−10；同一求助、同一阶段不能反复刷分。

医院/科室取最近3个已结算医院日、各最多100个离院病例；至少5个有效病例才显示总星级。科室以最终承担治疗的运营科室归属病例，导诊差错记发生科室的流程事实，不能转科清掉负面记录。全院不重复累计转科病例。诊疗质量使用平滑治愈率：(治愈数+8)/(完成治疗离院数+10)×100；纯转诊无治疗不进入该分母。流程/环境取患者相应分项，职工体验对有观测员工取等权均值：50%×当日能量时间均值+50%×休息覆盖率；覆盖率=clamp(实际休息/当日应休息tick,0,1)×100，医生按模板休息班、其他员工按能量触发的休息任务统计，休假日视为完全覆盖；无样本项退出权重归一化。

医生与职工取最近3日、最多50项已完成任务，至少5项才出总星级。工作质量按岗位合格结果计算：医生用上述平滑治愈结果，检查结果完整、导诊正确、维修后功能恢复、清洁目标完成、装修合规完成、研究完成均为成功事实；病人打断或设施故障造成的任务取消不算员工失败。服务反馈按本人参与的每个Visit取clamp(80+5×不同及时帮助−10×未处理承诺,0,100)，再求均值；无本人服务事实则此项缺样本。不把远处厕所排队归罪于医生。协作=正确交接数/应交接数，履责=在具备资格、可用资源和应工作窗口时按规则接受的任务数/可接受数；休息、培训、补休和无工作可做不算拒绝。比率项使用5个成功/5个总数先验；没有任何真实相关任务时仍标缺样本，不用先验伪造实际评价。已有真实样本时使用(成功数+5)/(总数+5)，原因可追溯到任务ID，不能由动画结束随意加分。

统计按事实序号幂等消费，保留有界窗口与日汇总。实时分数是统计的投影，不在医院、科室、员工卡分别写一份。评分初期可用于改善提示和纪念奖牌；固定补助、基础招聘、必要研究不以评分作为生存门槛。

## 2. 怒气与心情

每位患者有0…100怒气值，初值、增长与平复倍率来自其性格。怒气是运行事实；“平静、烦躁、生气”等心情文字与表情由怒气派生，不再另存一套独立心情数值。需要旧mood接口时使用clamp(100−anger,0,100)。住院和手术中不因怒气取消安全照护。

| 原因 | 宽限 | 基础增长 |
| --- | --- | --- |
| 等初诊/门诊治疗/出院查房 | 45秒 | 每10秒+1 |
| 等检查/治疗机器/候手术 | 60秒 | 每10秒+0.8 |
| 等厕所 | 20秒 | 每10秒+2 |
| 等导诊或办理转科 | 20秒 | 每10秒+0.6 |
| 需要座位但没有兼容空座 | 15秒 | 每10秒+0.6，与当前队列原因相加 |
| 附近持续脏乱/施工噪声 | 10秒 | 每10秒+0.4，每类最多一次 |
| 实际走到错误入口 | 到达后复核仍不匹配，每就诊最多一次 | +12 |
| 院方取消已承诺预约 | 每次实际失约 | +8；同一故障不按每次扫描重复算 |
| 冲突参与者/围观受扰 | 每事件一次 | +18 / +4 |
| 治疗失败 | 每实际尝试一次 | +15，完成安全阶段后才评估反应 |

持续增长每10秒计算一次；同一患者只取一个主队列原因，再加无座与环境原因，基础合计上限3。基础增长×性格倍率×环境缓冲；环境值<60时乘1、60…79乘0.75、≥80乘0.5。漂亮环境能缓和等待，不把无厕所或缺医生变成完全无影响。离开原因后对应连续计时清零；重复加入同一主服务队列保留已等待时间，移动椅子不能重置。

每10秒无当前增长原因时自然减1×平复倍率；坐上满足偏好的兼容座位额外减0.5。开始一个新的实际临床服务阶段减6，每阶段一次；护士安抚8秒减15，同一患者60秒冷却。冲突调解结束减12，每事件一次。暂停、离线、其他医院运行均不改变怒气。

35以下平静；35…64烦躁气泡；65…84可能提出一次可处理的投诉；85以上主动请求帮助。怒气不会必然触发攻击。≥90且连续60秒没有服务或有效安抚时，未进入安全治疗阶段的患者选择友好转诊离院；这是普通600秒无进展规则之外的体验退出路径，不收未完成治疗费；普通候诊另有随机来客规格定义的概率离院。手术、转床、正常恢复期间暂停此退出倒计时，完成后再处理需求。没有死亡和永久医院仇恨。

患者卡按最近的真实来源显示“等医生+12、无宽座+4、花园缓冲−6”等累计贡献；环境缓冲记录实际少增长的量，不能标成实际扣除过的怒气。批量提示只列最需要处理的三类问题，不为每10秒变化弹窗。

## 3. 病人性格与条件行为

每位居民有一个稳定的社会性格：温和15%、急性子15%、好奇12%、害羞10%、热心10%、爱较劲8%、爱整洁10%、爱热闹8%、慢性子7%、幽默5%。相同种族可以拥有任何性格；熟客在复诊、存档和医院内转科后保持性格。新居民才抽取，不能每次走进房间重抽。医生的六种专业性格负责方案选择和沟通回应，与居民社会性格不同。

| 性格 | 更常见的条件行为 | 不满足条件时 |
| --- | --- | --- |
| 温和 | 怒气较低时主动让座、冲突后接受和解 | 正常等待，不强制当和事佬 |
| 急性子 | 超过宽限后询问进度、看叫号屏、提出投诉 | 正常就诊，不因种族自动吵架 |
| 好奇 | 空闲时观察机器、向另一种族问问题 | 叫号后立即结束，不擅自启动机器 |
| 害羞 | 人多时换到安静候诊位、用留言卡提问 | 无替代座位也可继续正常就诊 |
| 热心 | 帮邻座递号单、提醒过号、帮助解释导诊牌 | 不代替有资格员工进行治疗 |
| 爱较劲 | 有抢座、顺序争议或恶作剧时较可能争执 | 没有矛盾情境就不凭空开打 |
| 爱整洁 | 发现脏物后提出清洁请求、整理自己座位 | 不无条件嫌弃僵尸或微生物 |
| 爱热闹 | 有合奏、闲聊、围观空位时参加 | 病房安静和手术锁优先 |
| 慢性子 | 更耐心等待，闲时慢慢赏景 | 表达节奏可增加问诊工作量，已承诺的服务中不再追加拖延 |
| 幽默 | 有愿意回应的空闲对象时演一个无声冷笑点，用表情和图符化解尴尬 | 对方生气或需要安静时不追着表演 |

12种性格行为在内容目录patient_behaviors中定义，使用现有交互调度；各有情境、概率、最大演出时长与打断方式。每5秒扫描一次，居民最多拥有一个日常行为，行为30秒个人冷却。普通闲聊/观察最多8秒，被叫号1秒内结束；安抚属于真正的护士任务，不伪装成无成本日常动作。并发仍为全院6组日常互动，新增内容不另开无限通道。

每项行为的context_source指向已有现场查询或已提交事实，scene只描述表现，不执行规则。持续条件从当前世界读取；已发生的帮助、道具落下和调解以原source_fact_sequence及参与者引用进入候选，沿原10秒上下文有效期消费一次。没有来源就没有候选，不补演院外故事或创建一个障碍来满足条件。

| 行为 | 现场依据与边界 |
| --- | --- |
| PB01 礼貌让座 | 自己实际占用的可让座位与附近真正需要座位、身体可用的居民；对方接受后沿实际占用安全交接，自己身体离开才腾空，不让第三人重复获得同一座位 |
| PB02 询问进度 | 本人原票号已超过对应等待宽限；显示当前阶段和实际原因，不改票序、不召回医生、不额外暂停服务 |
| PB03 观察机器 | 同层近处真实可达机器及合法公共观察位；不进诊疗操作区、不打开设备、不产检查证据或研究资料 |
| PB04 寻找安静座位 | 当前有实际噪声处罚，或同层可达3格内至少有4位其他居民；新座须在原候诊范围内，使噪声/邻居数至少一项降低且另一项不增加，并且兼容、空闲、可达；没有更安静位置就继续原座等待，不在同等座位间循环换座 |
| PB05 递还号单 | 现有号单道具在获准候诊动作中滑落的事实；双方实际在场且可够到，逻辑票号与叫号预约从未丢失，不生成失物库存或地面垃圾 |
| PB06 顺序争论 | 原队列仲裁已经产生的真实争执；求助复用该来源的护理请求，已有任务不再生成；若演员已由原事件锁定，手势嵌入原事件，不另占日常会话或暂停时长 |
| PB07 清洁请求 | 同层可达的现有地面DirtPatch；只指向原任务，不加一份工时、不自动置顶、不另弹全院提醒、不清除垃圾 |
| PB08 参与小合奏 | 同层已有且允许回应的轻声演奏/邀请及合法站位；只轻拍节奏，不扩大范围、延长效果、产生第二份安抚或增加演出成员 |
| PB09 慢慢赏景 | 同层可达的已放装饰和实际公共观察位；不从库存或楼上借景，不增加一份环境加成 |
| PB10 演个冷笑点 | 实际空闲且愿意回应的邻居；原小牌改用雪花图符与身体会意姿态，无对白文字、语音或真实降温；怒气≥65、明确需要安静或正在医疗工作者不进入候选；仅患者或普通访客可发起，不作为医生/护士工作回应 |
| PB11 接受和解 | 该双方真实调解已完成；概率只决定是否播放握手回应，不重新决定和解，也不重复关系、心情或任务事实 |
| PB12 挥手感谢 | 对方确实完成了本次帮助；只作短回应，不再生产help_received、谢礼意向或第二次积极互动 |

patient_behaviors的发起者范围固定为patient_or_ordinary_visitor，即在院患者或普通陪诊/探视者。医生和护士的工作回应使用doctor_responses及各自临床动作；员工休闲、同事合作使用原员工规则，不能从候诊行为表派出医护冷笑点。性格改变合法行为的选择，不突破角色职责。

现场动作中的事实也必须匹配：拥挤可以来自人群，不能总画施工；尚未绑定诊室的号签只显示等待原因；发出求助不代表护士或清洁员已经到场。安静赏景使用当前居民的真实表达部位，不给所有身体添加小叶子、手或脚。

让座、递还道具和无声冷笑点只在双方接受并真实完成时沿原上限产生一条积极互动；叫号打断不计完成。其余观察、询问、换座、请求和回应不暗加关系进度。所有行为使用实际身体和可达范围，表达不强制双手、双脚或人形；投影可以解释动作，不能代替占位、搬人或清扫。改变原世界的动作仍由座位、护理、清洁及关系各自原所有者提交，表现层只引用结果。

是否出现冲突按顺序判断：安全状态与场地 → 当前矛盾情境 → 行为能力/表现适配 → 双方性格与关系 → 怒气 → 概率。情境包括争用同一资源、叫号顺序误会、无意碰到随身物、恶作剧被误解、旧怨被具体事件勾起、治疗失败后的怪脾气。仅仅两种族走到一起不构成矛盾。

冲突候选概率=clamp(事件基础概率×发起方性格发起倍率×回应方性格回应倍率×情境强度×怒气倍率×关系倍率,0,0.75)。情境强度：轻微误会0.5、资源争执1、明确挑衅1.2；怒气倍率=0.5+max(双方怒气)/100；关系为neutral（陌生/普通）1、朋友0.25、冤家1.25、已和解0。只有一方为患者时另一方使用中性倍率1。旧怨型事件在和解后不再发生；普通意外接触仍可有一句道歉的无害小动作。

失败/等待暴发使用事件基础概率×本人发起倍率×(0.5+本人怒气/100)，夹在0…0.75，不借用不存在的第二位患者。无害误会使用基础概率×双方参与倍率，非居民一方乘1；同样夹在0…0.75。每种事件还必须命中incident_contexts中的具体现场条件。情境令牌最多保留10秒，每世界最多160条，处理或过期即释放，不把仅有物种接近写成情境。

先使用原有每5秒一次全局机会，再按优先级、产生tick、事件与演员ID稳定排序处理候选；每个情境令牌只抽一次自己的概率，成败均标记已消费，只接受首个成功取得资源的候选。事件名额与冷静期仍然适用。暴怒、种族标签和ice_temper都不是必定触发器。E03仍要求实际治疗失败、法师能力与ice_temper；温和法师也可能抱怨后原谅医生。正在手术的工作人员不会成为目标。

植物与僵尸可以因为花盆被误当零件箱而争执，也能交换种子、互相让座或合影；牧师与吸血鬼可以误把遮阳伞当道具而争论，也能共同找阴凉位。种族专属事件只规定适合怎样演出；新增加的角色组合可复用资源争执、误会、安抚等条件，不把“species A遇见species B”写成强制冲突指令。

## 4. 环境值与付费装修

环境值按角色所在格计算0…100：clamp(35+地面材料分+墙面材料分+装饰分+设施分+临时回馈分−脏乱−噪声,0,100)。地面最多12，4格可达范围内最近合格墙面最多10；装饰按不同类别各6、最多24；照明7、洁净8、可用饮水4，共最多19；洁净项按§20的实际污渍查询，不由某个设备直接发放。同种堆放不叠加，故障功能设施不贡献分数。脏物每处−4最多16，施工/运行噪声取最大处罚15/10，不把同噪声逐设备无限累加。临时回馈分最多6；花草光影与纪念投影共同取最大值。墙隔断传播，R15把环境增益的搜索半径从4改为5，包括邻近墙面、装饰、功能环境设施；脏乱、洁净判定与噪声仍按4格，研究不会扩大清洁查询和负面范围。脚下地板只作用当前格，专属遮阳仍只作用其座位，不向外传播；临时回馈保持效果定义自身的范围。

可用饮水的4分与舒适等级2中的饮水条件共用一次本人可用性查询：范围内至少有一处本身体能展开、操作且到达的真实饮水设施。检查保留其他设施已经展开的占地和当前建筑阻挡；仅把目标饮水设施当前用户的短时服务预约视为正常排队，不把“有人在喝水”当成整片区域失去饮水。实际取水仍等前一位身体退出、再原子复核空间，不提前供水或恢复需求。被墙、床尾或不足的伸展空间长期挡住时，不能沿用小体型居民的可用结果。等水时间仍按原生活需求规则单独处理。

材料完成后才贡献分数；基础房间的20/格地面和20/格装修费用提供可用的标准墙地，额外美化材料另付钱。8种材料分为4地面、4墙面，按格/墙边报价。装饰、家具、绿植继续按物件价格购买，普通摆放可直接确认；铺地面、刷墙、贴壁材必须雇佣装修工并配工具台，不能在暂停时瞬间免费完成。

噪声沿本层四邻格传播，最多4步，墙和已摆放的FUR23安静屏风所在朝向边阻断传播；仍能在4步内从侧面绕达的噪声照常生效。屏风摆放时明确所依附的格边，只有该边隔音，人物通行不受影响，不能靠屏风所在格把整片区域标成安静。屏风只改变噪声传播，不隔断其他环境增益；地毯按地材分贡献环境，不另减噪。quiet偏好与噪声扣分共用同一传播结果，包含实际运行与施工源；移动屏风或机器后一起更新。

运行噪声仅由environment.machine_noise_definition_ids中的整复台M09、调理舱M37、奇想台M17和手术台EQ01，在实际执行治疗/术中工作、标准工作量正在推进时产生，处罚仍为10。会诊、术前等人、苏醒、停机、空闲和单纯待修不算机器运行。诊断台、护理床、研究桌、日用设施、电梯及娱乐家具的轻声表现不产生这项经营处罚；床边恢复不能因为“床正在用”就让整间病房持续吵闹。设备等级不另加噪声，种族体型和说话外形也不是噪声来源。

施工噪声只在装修表面、付费楼板施工或机器升级的实际工作推进时产生，处罚仍为15；来源位置取当前实际工作单元或设备实际展开占地，不包含员工站位，不是整间待改建房或整座楼。未开工订单、暂停、等工人、材料预览和普通家具即时放置不发声。两类传播取最大处罚，不逐机器叠加；有任一有效源到达角色所在格，quiet即不满足，没有来源时恢复原安静结果，不另加倒计时。噪声源判断取当前有效工作段，设备源使用实际展开占地；全局暂停只冻结这个状态，不因现实一帧没有推进就消音、提升环境或满足quiet。运行/施工状态与传播只从现有任务、位置和格边派生，不为声音动画保存第二份经营状态。

建造详情以“治疗时有声”或“施工时有声”说明相关设施，原环境叠层可定位实际来源和绕过屏风的路径。音乐、角色非语言反应与道具音效属于听觉表现；静音、切层、远景降级和声道不足不改变患者环境或安静偏好。玩家不需要管理分贝、电器开关或隔音材料库存。

新增第七员工岗位“装修工”，招聘160、工资80/日；普通人类候选保底。装修工具台SE02价格300、1×1、workstation故障类别；需要已放置、可达且正常。装修工领取材料并到实际工作格施工，基础每格/墙边8秒，岗位技能每级加速5%。同一工单最多2名工人，各自领取不同的单元；所有在职时间发工资，材料不反复按工人扣。

装修操作：刷选最多64个单元 → 显示材料费、工时、缺少的工人与工具 → 支付并创建工单 → 工人逐单元完成。钱不足保留预览，不创建半付订单；研究/必要开支援助不支付装修材料或装修工招聘。取消未完成部分退尚未消耗的材料费；已完成表面保留，替换时按实际已付成本的80%回收一次，赠品成本0。不能对同一表面同时下两单，搬移或读档不重置退款凭据。

施工不把唯一通道硬封死；地面单元只有无人站立、无安全服务占用时才开工，旧表面在该单元完成前仍生效。临时施工噪声影响附近体验；手术/苏醒中房间不能施工，占用病床区域等待转床或出院。玩家可暂停工单、限制为科室空闲时施工；这不会暂停其他医院服务。大面积变更布局仍使用原建造事务，材料施工不能绕过门宽、出口和占用校验。

舒适等级继续0/1/2：兼容座位且满足偏好为1；再有环境值≥70、洁净与饮水为2。无偏好居民以座位满足第一项；巨型患者没大座时仍可候诊，但会明确积累无兼容座位的不满。环境值既用于怒气缓冲，也用于体验评分和可视热图，不再维护另一套互相矛盾的“美观度”。热图采用当前选中居民的实际身体；没有居民时沿用体型预览示例并标明“人类体型参考”等对象说明，不能把示例值写回患者体验。具名患者卡直接展示本人的当前查询结果与来源。

## 5. 运营科室与专业分区

T01…T10统一称“医疗专业”，其数据集合为specialties，病例与治疗演出通过specialty_id归类；它们是治疗知识分类。“运营科室”是玩家在这座医院划定的实际区域，可以命名为“森林舒缓科”“星际整复区”或“日常综合门诊”。房间是物理空间，医疗专业是病例分类，运营科室是管理单位；医护能力另由诊断、治疗、手术、护理四项定义。

运营科室拥有一组完整房间、相邻公共区域、入口接诊点、专注专业、接诊范围和排班池。一个房间最多属于一个运营科室；公共走廊可共享，手术室、诊断室与病房可标为全院共享并由科室引用。关联设施须在同院、真实可达，不能隔未购地连接。运营科室数量随实际房间增长，不设16个全院上限；初始自动建立综合诊疗科，接入原有初诊、体态与日常房间，无新增开局费用。

划区与改名免费。玩家选一个专注专业，其他已具备资格和设施的病例仍可开放；专注不赋予能力或解锁病症。病例符合专注专业、实际医生治疗≥2（门诊）或主刀手术≥2、科室至少5个有效评分病例且总分≥75时，本次操作工作量乘0.95一次。不另检查科室技能，不提高随机概率、缩短护理恢复或叠加多区；疗程开始冻结加成。

改变专注花200标识与协作调整费，600秒后生效；调整期间照常治疗但无专注加成，正在进行疗程保持原值。第一项专注随新科室设立可免费选择；房间保存上次专注及调整完成tick；重新分配或重建后，沿用相同专注可免再付费，但换成其他专注仍付200并等待600秒。若房间仍处在过渡期则不得提前结束，不通过反复创建刷新免费专注。建区不能绕过实际房间、设备与人工费用。

科室面板显示覆盖的专业、房间、当班医生/导诊、病人评分、排队与环境热点；接诊准备查询统一验证自己或共享设施的整条路线。科室只是归属与调度作用域，不复制一套患者、员工、账目或治疗成功率。科室图鉴统计按实际治疗归属，跨科检查不把一个病例算成两次。

## 6. 导诊护士与挂错科

导诊是护士的工作分配，所有护士入职带q_guide；工资仍为护士100/日，不创造免费引导NPC。SE01导诊台2×1、600币，SE03叫号导览屏1×1、250币，均免维护。护士可分配到导诊台、科室入口或巡回导诊池；手术与病房覆盖锁定的护士不能同时算导诊人手。

仅当存在两个以上实际开放、入口可达的运营科室，同时存在至少一个本病例可接诊目的地和一个真实不匹配目的地，才可能挂错科。正确目的地包括所有具备本病例完整路线的运营科室，不能按房名、装修主题、专注专业或首选科室ID排除同样能接诊的综合门诊。错误目的地须因接诊范围明确排除本病例，或实际设备没有对应已解锁方案而不匹配；仍须开放接待其他病例且本患者能走到入口，不能故意选关闭、拆除、无路或空白区域。新患者基础18%，熟客8%；正确入口与完整路线有可用导览屏时减10个百分点，最低0。种族不提高挂错概率，不把诊断所需检查和真实病名直接显示给护士。患者社会性格只影响询问、停留或接受引导的表现，不修改隐藏病症。

只有存在合法错误候选时才使用原概率生成一次registration_choice并保存；候选为空直接选择合格目的地，不消耗这次错误抽签、不为凑笑点改接诊范围。正常排队、换班、休息、缺货、检修、暂时床满和人员拥堵不是挂错科的原因；它们使用原Readiness原因与调度，不改变已生成的挂号选择。导诊护士核对6秒，95%概率纠正已有的错误；对正确挂号不制造新错误。若未纠正或没有护士，到错误科室后由当班医生用5秒入口确认发现，只解释去向、不收初诊费、不产生诊断/培训经验；正确初诊完成时才收对应职称诊费及初诊台5币。每次就诊最多一次挂错和一次纠正，纠正后不得再次随机跳错科。

开始护士纠正、医生入口确认或自助纠正前，使用当前世界再次检查目的地。原错误科室现在已能接本病例时，就地沿原队列正常接诊，取消尚未开始的纠正，不额外花6秒/5秒、不补一份纠正绩效；已有实际完成的导诊工作仍如实保留。原正确科室变得暂不可用时按实际原因重新选可接诊目的地，不再抽挂错，不给患者第二次绕错路。必要检查、转手术与真实治疗转科属于临床路线，不计为挂错。内部查询可以使用已生成的病例定义，但号签、导诊说明和初诊前界面仍只显示已知症状与目的地，不提前揭晓病名。

走错科的流程−8与怒气+12共同消费唯一actual_mismatched_entry_arrival事实：患者依据本次错误选择实际到达该科入口，且到达时复核仍为接诊范围/设备不匹配，才提交。出发前被导诊纠正、途中按新情况重选合格科室、抵达时目的地已具备接诊能力，都不产生这条事实；正常排队及已有真实延误仍按原计时记录。回看入口、换班、改名、读档或第二位工作人员解释不会再次扣分和加怒。

RegistrationRoute保留该来源键及发生时科室归属，评分与怒气沿各自原消费游标更新，不从error_rolled或corrected布尔值猜测患者经历。corrected表示本次路线问题已解决，可能来自护士、医生、自助路线或目的地能力复核；护士实践和导诊成绩只取本人实际完成的6秒工作，不能把自动就地接续记成一份远程护士绩效。correct_department_id只记录当前选定的合格调度目标，不意味着其他兼容科室错误。

转科保留原排队序号、已经取得的证据、生活需求和收费凭据，取消错误目的地的预约，再指向可接诊的正确科室。护士可陪同，或给患者发出可见路线；陪同仍走患者真实尺寸，不能穿过没有足够伸展空间的门。错误科室等待20秒后生成导诊求助；30秒无可用导诊护士时使用公共自助路线完成纠正，不依赖错误科室医生一直有空。这条恢复有路程和怒气成本，不能形成挂错科永久循环。

正确科室临时停诊时暂停引导，显示下一合格窗口、等待或友好转诊；绝不把患者推向没有完整医疗路线的空房。导诊正确率、等待和成功纠正都有事实来源；一次多步陪同只计一个护士任务，纠正错误不会重复计多次绩效。

HS13是本人随身物标签的短暂误会，只使用当前造型已声明且在本人体型内可表现的独立道具，不根据屏幕LOD判断有没有物品。没有对应道具或合法原位动作就略过，不补一只包、不摘身体部件。居民须已完成登记、与原接待员同在合法接待位置，且无实际叫号、必要移动、待登记患者或接待员休息需求；不再为笑点把人从候诊区叫回来。原8秒核对占接待员的真实工作时间，不能同时登记另一人；开始即消费本Visit的一次表现机会，中断不重播、不继续扣住患者。

失物柜FUR41保持装饰用途，不提供储物格、寄存收费或认领队列。核对中的包和姓名签始终属于本人，没有掉到地面的垃圾、遗失库存或从另一位居民取回物品的事务。接待员指明标签后，居民沿原票号继续；叫号或新登记优先，一秒内结束小动作并释放实际接待工作位，人员离位仍走真实路线。核对不发registration_completed，不增加挂号费、队列票号或登记实践；减少动态只显示原标签与核对结果。

accessory_obstructs只指独立装饰道具妨碍当前工作视野或工具准备，且该道具已具备合法收纳姿态。角、尾巴、翅膀、身体绷带、症状附件、承托水泡和微观载具都不属于可摘装饰；身体与症状包络不能靠收纳变小，仍由设备真实适配。小袋与摆放动作留在本人已验证的道具范围，不另占通道、不产生库存、失物任务或治疗包消耗。

## 8. 康复谢礼与居民回馈

病人治愈、完成必要查房、最终体验≥85且怒气≤20时，有35%概率产生一次感谢意向。每次就诊只评估一次，医院每医院日最多实际兑现2次；熟客同一居民3医院日冷却。所有种族都有同等机会，不按账单高低、身份或病人评分另调治疗优先级。

基础包80种族各有一件专属土特产：长颈鹿的树梢蜂蜜、吸血鬼的月光果酱、哥布林的歪齿轮八音盒、微生物的微缩合唱瓶、普通人类的家乡点心盒等。物品是纪念摆件，不能售卖换钱、当现实药物使用或暗加医生治愈率。默认谢给最终执行治疗的医生；团队手术的卡片列出主刀、麻醉、护士，实物归医院谢礼收藏，署名保留。医生离职不丢医院收藏。

感谢形式在“土特产礼物”和“能力回馈”中等概率选一；该居民的能力当前没有合法目标时直接转为土特产，不重新抽多个候选刷奖。礼物第一份进入收藏，玩家可摆到医生桌边或公共展示架；重复礼物转换成同款感谢卡计数，不刷实体、钱或无限物品。每种最多一件可摆物；摆件计为真实物件，同范围所有谢礼只贡献一个装饰类别6分。

能力回馈使用6种有限处理器、80种不同表现：为现场清洁员提供一次清扫准备提示；180秒花草/光影环境加成；120秒轻声演奏安抚；帮助维修员完成一张工单的诊断准备；帮助装修工整理一份已付材料；布置一块180秒的纪念投影。公共环境加成最多6分，多个来源不叠加；安抚每10秒最多额外−1怒气。投影、花草不改变阻挡格，也不强行覆盖原温湿/明暗偏好。

花草光影、纪念投影与轻声演奏在提交时固定一个真实公共CellRef，以该格沿本层公共四邻格传播最多4步，墙边阻断，不能跨临床房间、楼板或不连通区域；不读取居民后来走到的位置，也不因R15扩大。效果本身没有占地，不能改变人物通路、原装修、光照设施、温湿偏好或垃圾。临时花朵、种子、纸花和小瓶都是光影，不生成需要清理却会自行消失的实物；真正的谢礼摆件仍按收藏与摆放规则处理。

轻声演奏的4…8秒感谢动作留下定点的小音符回声，居民照原行程离院，不被锁在现场唱满120秒，也不是医院广播。每次原怒气采样，只给当时位于有效范围内、已有PatientAffect的在院患者额外减1，最低0；多个旋律取一次，不按音符数、围观人数或重复进入累计。进入区域不立刻补减，离开后不继续远程安抚，不额外降低员工压力或访客情绪；关闭音量、字幕或动态只改变表现。花草与投影对当前有效范围内的环境查询共同取最高6分，不叠成12分。

每份感谢凭据最多建立一个临时区域效果，remaining_ticks沿模拟推进，归零后在下一次环境/怒气采样前移除；暂停、切医院、离线与读档不刷新。范围从当前墙体与公共区域派生，改建使锚点不再是合法公共格时提前结束，不跟随搬走的花盆、不迁到新楼层、不另给纪念物补偿。环境卡可查看来源与剩余时间，平时无需操作。来源只保留原就诊键和冻结署名，不因此把已离院演员或熟客身份留在医院。

清扫、维修和材料整理帮助各只作用于一项已有合法工作，按剩余标准工作量减少10%、最多10标准秒，向下取整到工作tick，且至少留一工作tick由职员实际完成。维修/装修仍要求已付材料和合资格工人；清扫要求清洁员已在同层可达公共区域的真实操作位处理该DirtPatch，按距离、任务ID选取。居民指出位置或提供准备提示，不捡走、移动、打包或删除垃圾；没有清洁员、目标已完成或没有实际可减少工作量时转为纪念物，不伪造一份清扫任务。没有额外清洁工具库存。

三类工作帮助统一从居民当前合法公共位置寻找：目标工作位在同层、可见且沿本人体型可达路径不超过4格，原工单有效、合资格职员已在真实工作位推进工作，维修/装修材料已付。按实际路径距离、工单ID选择一项，不能隔墙、跨层、借读档远程减工时。没有合法目标就沿原规则转为土特产，不另派居民去找工人、不排谢礼任务、不改变离院路线。

材料帮手使用原工作现场已有的包装、色样或清单，短整理和指认都在参与者现有身体/道具包络内进行；够不着材料时用工单图示，不表现成已经搬交实物。积木、线团和木偶的身体保持完整，不拆件造车或缩小身体。准备提示只减少原工单的标准工作余量，不移库、不改变装修单元、付款、耗材或工作归属；它和清扫提示一样不能自行发出工作完成事实。减少动态时保留工单提示与感谢图案，实际职员继续工作。

帮助提交前重查同一工作及现场条件，以本次感谢凭据只应用一次；若清洁员随后休息或离职，余量仍留在原DirtPatch，由后续清洁员接续。只有实际清洁完成才删除垃圾、恢复环境并计一次原清洁绩效；谢意本身不发绩效、任务进度或工作完成事实。维修提示也不独立修好设备，材料帮手不免费购买材料。石巨人的指示动作、微观居民的发光箭头和树人的小花都在安全可达公共区表演，不能闯进手术或挤进不够大的门。

正式感谢演出4…8秒，可1秒内结束；不能延迟已经提交的治愈、收费或离院。开始前占用当天回馈名额并保存，效果与纪念物使用visit_id构成的唯一凭据原子提交；若被打断，效果已提交就不再播放/发放，尚未提交则只保留感谢卡。减弱动态模式保留简短挥手与礼物图标。

院史记录“萨米把月光果酱送给了林医生”“微观居民为清洁员指了指椅脚边的纸屑”。记录实际发生的帮助，不在垃圾尚未清理时宣称大厅已经干净。熟客关系增加一次正向互动，依然受原有每对每日上限约束。良好服务能留下可见的地方特色，不需要玩家逐一点击收礼；患者与医院的长期关系由这些小变化积累。

## 9. 界面、事实归属与验收

医院评分入口展开五项总览与原因；科室视图叠加归属/专长/候诊/环境，不同时满屏显示四种热图。患者卡显示性格、怒气条、体验分、当前原因和安抚/引导操作。装修刷选页显示材料单价、总价、人工缺口、预计工时和影响；谢礼收藏显示来源居民、署名医护、日期和摆放状态。

新增运行事实：CareDepartment、RegistrationRoute、PatientAffect、VisitExperience、RenovationOrder、SurfaceFinish、RatingWindow、GratitudeReceipt与TemporaryCommunityEffect。世界拥有它们，UI只读。专业定义、材料、病人性格、行为、服务情境、谢礼与回馈处理器来自内容注册表；评分权重、怒气增长、概率、工资与时间来自数值表。

存档保留原有患者性格、注册错误抽签、已纠正标记、怒气原因时钟、原票号、待处理求助、体验累计、装修已付与未消耗材料、逐单元工时、科室专注转换、各评分窗口、谢礼已提交凭据与效果剩余时间。不按离线天数赠礼、完成装修或平复怒气；退休定义和扩展依赖仍遵循原内容兼容协议。

新内容验证须覆盖五类评分权重与缺样本归一化、十种性格概率总和、怒气原因范围、8材料/3功能设备故障类别、24服务情境与12性格行为的合法出口、80谢礼及80回馈表现的种族引用。实际情绪节奏、诊疗吞吐、装修等待、导诊有效性和内容趣味在Godot实施与试玩中验证，静态表检查不能代替。

| 改建草案 | 界面中的候选布局；不改变接诊与世界占用 | 不写医院快照，不扣钱；切层保留，退出医院丢弃 |
| 改建安排 | 医院拥有的已确认准备事项，冻结参与房间/物件与目标布局 | 写医院快照；准备期间不扣建设费、不保留目标空地 |
| 改建应用 | 玩家对当前报价执行的一次原子建造命令 | 同步提交位置、物件、表面、账目和拓扑；任一条件失败均不改变世界 |
| 空间蓝图 | 共享资料库中的布局定义，可以在不同医院重复使用 | 不拥有医院实体、资金和服务进度；每次放置按当前医院核验 |

每间房或公共物件最多属于一份待改建安排。整组安排只有一份目标布局和一次应用结果，各房间不另存一套进度。选择“停止新预约并准备改建”后，受影响服务不再接受新预约，已开始的服务继续至安全边界；尚未开始的预约回到原票号队列，保留证据、等候时钟与已付凭据，由其他合格服务承接。公共物件同时停止新的实际入用，未使用意图及真实等候者按[公共设施规格](../specs/26-10/2026-10-18-public-facility-area-use.md)处理，不将区域意图冒充物件预约。患者仍按实际候诊条件增长怒气、决定离院，不因改建获得无限等待。员工继续正常计薪。

当前使用者离开后，调度器使房间内其他人员和目标范围内人员走到可达的公共安全点。没有合法出口就保留原布局、提示修复路线，不能传送、隐藏或删除角色。活动占用场地时先按活动中止规则真实散场，已完成活动的关系与故事事实保留，未完成活动不补发完成事实。改建准备不抢占其他人的服务位、唯一出口或电梯泊位。

等待腾空期间，不给受影响设备派新的研究、培训、娱乐或普通服务；原工作保留进度，员工可去其他岗位或休息。已承诺的临床交接、已开工装修收尾，以及完成这些安全工作必需的故障修复仍可进入；准备改建不能把“修好工具才能收尾”锁死。应用或取消后，原暂停任务重新检查人员、排班、设备和路线再接续，不强制召回休假或已离职员工。

安排显示“等待腾空”或“可以应用”，不可用原因从当前事实推导：当前手术、未释放床位、进行中的事件、未结束装修单元、目标占用、资金不足、缺少楼板或路线不合法。原因消失后只改变提示，必须点击“应用改建”才提交。等待期间其他建设仍可使用目标空地，因此提交前重算报价、身体通路、科室覆盖和所有建设上限。差价或新障碍在当前预览显式展示，不改成另一套布局、不暗中购买替代品。

取消安排只移除这份安排的接诊阻止原因。房间是否恢复接诊取决于当前开放意愿、工作人员、设备、路线及其他停诊原因；不恢复一份过时的“原开关”快照。取消不撤销已完成的治疗、转床、散场或退款。应用失败保留安排以便调整或取消；调整参与范围时原子释放退出成员、检查新增成员是否已属于其他安排。源成员在安排结束前不能另行出售、打包或参加另一改建，医院其他区域正常操作。

## 11. 搬的是空间，延续的是同一家医院

整房移动保留房间ID、设备ID、累计购买与升级成本、磨损、故障、保养状态、所属科室、科室转换冷却和院史引用。诊疗记录仍归原就诊与实际执行人员，不能通过搬房重置指标、维修费、赠品资格或计数任务。对象只改变位置及由位置派生的环境/通路；新房或新购物件才产生新ID。免费搬迁不重收原房间面积费；扩建仅收新增格，缩减按原有逐格使用状态退款。

| 正在进行的工作 | 可改建的边界 | 必须延续的事实 |
| --- | --- | --- |
| 门诊诊断、检查、治疗 | 等本次安全完成，或显式采用已有安全转移 | 原票号、诊断证据、已承诺结果、剩余工时、耗材与收费凭据；无合格接续机器仍执行60秒兜底 |
| 手术、苏醒、术后转床 | 已开术等手术、苏醒及真实转床完成；未开术释放预约后重新匹配 | 不打包术中患者；已承诺的同层病床不得被安排搬走，除非先完成既有规则允许的兼容床交接 |
| 住院、护理、查房 | 等出院或先安全转入另一兼容床；空床还须无预约 | 护理余量与查房任务跟随同一住院病例，不重新开疗程或扣耗材 |
| 研究、培训、维修保养 | 当前工作在安全停点暂停，工作人员实际离开 | 已付成本、有效工时和任务归属保留；原设备落位且路线合格后原任务接续，不重抽故障或返还已开始的服务费 |
| 装修 | 完成原工单，或显式取消未开工单元；已开工单元完成后再腾空 | 已领材料和当前单元工时不能借搬迁回收；未开工部分按原额退，已完成表面随归属处理 |

改建准备允许已开始手术所锁定的术后转床继续进入受影响病房，这是履行既有承诺，不是新预约。该病房仍须等这次住院安全结束或转床后才可移动。若手术室与病房成组搬迁，整组满足边界才一次应用；不能先搬走病房再让术后患者跨层找床。已实际转入病房的患者不再占用原手术室的搬迁锁。移到新位置的职工仍须走到岗位，房间不会因几何落位瞬间恢复生产。

完成的室内地材和内墙面随房间一起平移、旋转和跨层搬迁，已付成本与完成时间保留，不重新施工、不重复获得回收费。共墙有两个独立墙面，搬走本房间的内墙面不带走邻室那一面。缩改以房间局部格及有朝向的墙边匹配：保留表面沿用；真正删除的已装材料按80%回收一次；新增表面使用基础装修，另选美化材料时仍生成付费装修工单。施工用的上层结构楼板始终属于楼层，不能成为房间退款。

原位置回到该层普通基础地面，不留下另一份内装。目标范围已有付费公共地材或冲突墙面时，预览列为明确的表面替换，按原表面已付成本80%回收；应用时移除旧表面后安装搬来的表面，同一表面只能结算一次。空白地面不产生退款。源与目标重叠时先计算最终布局及表面归属，再结算实际删除项，不能把仍保留的表面当作被覆盖物退款。未完成装修订单、他房墙面和未选家具不能被这种替换隐式删除。

墙地材料按一个实际表面贡献一次环境；同一材料的移动、截图和蓝图预览不叠加舒适度。房间归属、共享临床服务引用和岗位安排保持原引用，重新验证真实路线与当班覆盖；无法支持原接诊范围时保持停诊并列出差项。院史可按一次成功整组应用记录“把旧门诊搬到了3楼”，同一命令重放不重复记事；记录不另发现金、评分或员工绩效。

## 12. 空间蓝图与库存复用

自建蓝图可以框选一个楼层内的多房间及公共家具，使用相对楼层0与局部格坐标。范围沿用单层96×96的真实几何；房间和物件按完整布局与实际资源检查，不借用性能样本的数量上限。资料库分页，不另设八张或其他玩法数量上限。名称、说明和缩略图可编辑；保存、重命名、替换与删除蓝图只操作资料库，不改变已建医院或已确认改建安排。选中房间必须完整纳入，不能截取半间手术室；共同选择的相邻房间保留共墙两侧归属。

蓝图记录房型、门、主体设备、朝向、升级档和装修；手术台/护理床的内置麻醉、监护、器械助手与照护卡随主体出现，不拆成额外商品；真实医生办公室和同层护士工作台仍按原开诊条件配置，可复用已有共享基地，不按每床重复购买。临床布局bed_links仅记录每张真实床在objects内的唯一索引，实例化时映射为实体引用，重复/缺失床引用必须拒绝。蓝图不复制患者、员工、预约、工单、状态、现金、购买凭据、结果或关系；借用品、唯一谢礼和故事纪念物不进入购买清单。

9张内置蓝图复用已有起始房间及四套临床布局：慢慢问诊屋、伸懒腰整复室、日常小诊室、普通手术室、巨型手术室、双床安心病房、大个子安心病房、双床员工休息室、共享医生办公室。它们不赠设备、研究或资格。内置源按房间提取物件并转为局部坐标；临床图中的演示角色、服务点与路径夹具只用于解释和校验，不实例化成额外人物、免费家具或固定员工。基础包目录保存源引用，打包时转换为与自建蓝图相同的布局定义，避免两份坐标失配。

放置面板默认开启“优先使用库存”。仅匹配当前医院未预约、未借用且定义、升级档与外观一致的库存对象；优先无故障，再按稳定对象ID选取。实际选择、磨损、故障与缺件在报价中可展开查看，不拆正在摆放的物件补库存。复用项购买费为0，其ID、已付成本与状态保留；新购项按当前解锁及目录价格付款，升级单独列价，不采用蓝图保存时的旧报价。库存故障不被清除，落位后沿用故障/维修规则，缺少可用关键设备的房间不能开诊。

确认前用当前医院做整组预检：地块和楼板、解锁、门/床/设备的真实展开范围、人员操作区与修理位、入口和竖向路线、现金及实际空间和服务条件。蓝图注明能容纳的身体示例，不承诺适用于所有居民或更大员工；预览可切换目标体型，实际来院仍按同一通路合同调度。无钱或缺定义时保留草案而不部分扣款；可显式删除缺件形成新草案，空房只作为未开诊建筑。不同房间不能各自成功一半，原子放置失败时库存与现金均不变。

大型蓝图的预检、报价、读写可以按稳定对象序分段计算，但最终确认仍是一份整组命令。预览未完成时显示正在核对布局并允许取消，不只取前64间房或前1200件物品宣称成功；旧医院已有数量不作为拒绝条件。操作开始前及执行中按真实可用内存与磁盘判断能否完整完成，资源不足时明确保留旧蓝图、原医院和库存，不删减对象、拆成部分付款或悄悄省略后半段。检查结果只缓存于当前草案，提交前继续按原修订与空间条件复核。

复制已装修的蓝图不会瞬间铺好美化材料。“房间与家具”和“美化施工”分项报价；选择美化施工时，材料仍走现有装修工、工具台与逐单元工作，每张工单最多64单元、最多2工人。按材料与表面类型、稳定格序分单，超过64自动拆成多张，不能绕过各单施工与退款边界。创建布局和所选材料工单同一原子提交，一次付清已选材料；没有可用施工岗位或SE02时说明缺口，可选择只放房间家具、以后再装修。人工日薪照常结算，界面给工时估计而不把未来工资算作已锁定费用。基础房间布局有效即可按正常规则接诊，美化工单另按空闲与安全边界施工。

新房间没有从蓝图复制来的科室与员工分配；玩家明确选定已有运营科室时，在同一命令中核验并加入其房间集合，否则保留待分配标记。临床床组内引用重建后仍检查同层服务与医护覆盖。只在单层内复用布局，电梯井、楼板、土地和医院入口不保存进蓝图，跨层交通缺口由放置预览指出。

## 14. 改建与蓝图的保存边界

医院快照保存改建安排的ID、参与实体、冻结目标布局和来源蓝图修订、创建顺序；当前失败原因和“可应用”由恢复后的现状重算，不保存另一套可独立变更的就绪布尔值或倒计时。现行医疗/维修/研究/装修任务仍由各自事实持有进度，安排只引用它们，不复制工时与患者状态。世界命令凭据同时保护位置、退款、库存消耗及院史，读档重试不能再次应用一份已经完成的安排。

共享蓝图保存在`user://blueprints/<uuid>.json`，包含schema_version、蓝图ID、修订、展示信息、内容依赖、相对布局和材料意图。临时文件写入并原子替换成功后才提示保存完成；资料库写入失败只影响蓝图，不回滚或重建医院。引用缺失、退休内容与未知格式按内容兼容协议给出差项，拒绝不可解释部分进入世界；不删除医院中的合法旧实体。已确认安排持有独立布局值，原蓝图改名、修改或删除不改变它。

医院导出只含该医院的实际布局与待改建安排，不依赖外部蓝图文件才能恢复；共享蓝图库随整个user://数据目录备份，不混作医院库存。离线、暂停与切换医院不会自动腾空、施工或应用安排。静态设计检查覆盖源引用、结构范围、引导内容和预算示例；实际腾空、路径、原子保存及同一病例跨改建连续性在实现后按验收矩阵验证。

## 15. 维修派工与预防保养

维修页提供三种全院保养策略：“修好再说”在状态≤30时自动保养；“顺手保养”在≤45时排单，为新医院默认；“细心照护”提高到≤60。手动保养仍只能用于≤60设备，不能对完好机器反复刷任务。切换策略只改变尚未开工的自动保养资格，不变更故障风险、维修价格、已付工单或设备状态。达到阈值自动生成或复用设备原工单，巡检偏好只是选择这些真实任务，不另生成一轮随机故障或收巡检费。医院已保存的主动选择按原值恢复，不在读档时重置为默认。

默认阈值留在状态40的效果惩罚线之上。以医疗主体初始100、每次使用减2、无随机故障且入队后及时保养为例，28次使用后状态44并排单，20币零件摊到每次约0.71币；较晚保养35次后到30，约0.57币/次，但已有4次新服务在状态低于40时开始。默认多出的约0.14币/次换取更早维护的机会，不保证远处、缺员或受阻的维修员能瞬间到场。保养排队和停机仍按实际时间发生，不免除故障、删除工单或重算已承诺疗效；40币/日的开院测算保养额度仅为预算参照，不是固定扣费。

策略卡默认用“较晚、适中、较早”说明取舍，详细比较从同一medical类别与阈值生成。满状态开始、每次使用减2、没有随机故障且及时保养时：较晚35次到30、默认28次到44、较早20次到60；每次保养均20标准秒与20币，零件摊费约0.57/0.71/1.00币。状态较低并不保证故障，提早排单也不保证免故障；维修员路程、工资和拥堵另列，不能写成设备的固定寿命或完整运营成本。

维修员可配置优先区域，或显式选择仅在指定区域工作。优先区域在同一紧急等级内优先，无本区可做任务就支援院内其他可达楼层；严格区域外任务保留并显示缺覆盖，不悄悄解除限制。未分区时全院可派。区域与楼层不复制员工或设备工单，维修员也检查自身门宽、高度和操作位。

维修员为外部上门服务人员，维修、保养和升级均由设备工单派入，不招聘、不发工资、不参与员工成长。派工等级依次为正在阻止已承诺住院恢复/术后转床的故障、其他停机服务设备、其他故障、预防保养、已确认的机器升级。等级内先看玩家唯一置顶工单，再看入队tick与ID。置顶不打断已经开工的维修，也不越过已承诺患者的安全需要；切换置顶只改同一引用。入口、路线、工具或操作位不足，以及须等安全服务释放的工单保留原排队时间和原因，条件具备才从1F入口派入真实人员。完成本单后人员走到出口离院，不在院内待岗或接另一张新单；离院受阻保留身体与占用。

维修仅通过设备使用状态查询取得实际放置、占用及未完成的关键服务承诺。临床模块持有并解释服务预约、执行会话和床位承诺，研究与课程持有共享工位，空间与电梯持有实际占用；维修不读取病例、治疗方案或住院阶段。停机服务设备的派工等级由设备用途确定，不随无关就诊的出现或结束改变。安全释放与派工优先级分别判断，关键承诺不能成为提前在有人使用的设备上施工的理由；已完成临床工作后的实际离位仍保留占用，直到使用方和空间都释放。

预防保养取得操作位后才停止设备新预约，已有安全服务先结束；队列中尚未开工的普通保养不提前停诊。其他必要维修仍依原故障规则停用或转床，门属于免维护物件。工作每完成一段保存有效标准工作量；更换上门人员、实际走路与改建暂停不清零。首次实际开工冻结本类别维修/保养两套工作量与服务费，按当前工作种类一次支付服务费，排队和走路不扣费；缺额仍用原必要维护援助，不产生可花现金。

保养未开工即故障时，原单改为维修并按维修报价开工。保养已开工后故障时，同一单升级为维修：目标工作量改为同类维修总量，保留已经完成的标准工作量，只收维修服务费减已付保养服务费的非负差额；不能再开第二张维修单。若原20秒/20币医疗保养已完成8秒，转30秒/40币维修后还需22标准秒、再付20币。故障处理阶段先于工作完成阶段，同tick冲突按这一顺序结算。已完成保养恢复100并取得原180秒免抽期，不能在同一完成事实上再补扣维修款。

未开工保养可取消，或在策略降低后移除已不符合条件的自动单。已开工保养只提供暂停与继续，不退已开始的服务费；暂停保留同一工单及设备停用原因，继续时接续剩余量，不能通过取消重新收费或刷完整工时。故障修理不提供删除工单；可暂停、继续或解除置顶，设备仍保留同一有效维修单与临床超时规则。设备转库存时暂停同一单，重新放置且可达后接续；售出或拆除才终结工单，已开始的服务费不计入物件可退款成本。

策略、唯一置顶工单、工作量、服务付款凭据以及上门人员的工单归属和实际位置随医院保存。维修完成仍只有一条设备恢复事实，不产生员工实践，不因保养转维修、路程重试或故事回馈重复计数；设备状态、工单进度、临床余量分别由原对象持有。暂停或取消后上门人员实际离院，继续时重派人员并接续原单余量；已付费用不重收。维护集合内的类别费率与故障随机流保持原规则，免维护物件不参与随机抽签。

## 16. 修理中的小喜剧

4种维修表现用于医疗、工作台、公用设备与电梯；只作用于维护集合。检测波形打结、说明书只展开当前页、检验旗等候最后一项、电梯箭头对照停靠刻度，都表达维修员正在处理的实际工作，包含在原维修工时内。没有修门、修椅子或倒垃圾顺带修桶的任务。

每种maintenance_scene提供开工、工作中、暂停、完成与低动态表现。检修动作读取原工单有效工作量，零件尚未支付、工作人员未到场或缺少操作位时不播放工作。保养使用同一检修动作但标为预防检查，不伪造设备已经坏了；同一工单从保养升级为维修时保留原进度，不重播开头。暂停、换人和读档都定位已完成比例，完成姿态只能在原工单结算后显示。

说明书、探针、检验旗都在既有操作位与工具包范围内，不能遮住走道、扩出新维修台或化成免费家具；纸条只是检测显示，实际操作针对设备原维护口。高等级设备按当前已安装结构打开维护点，维修员自身种族按既有工具适配，不能靠拧一张说明书把设备修好。

电梯优先使用专属表现，其余按设备类别选择，一张工单只绑定一种；不是每次暂停再抽一遍。开头与完成动作包含在原工时中，不额外扣设备、员工或玩家时间。处于临床安全工作段时仅显示故障图标，实际维修到位后才播放；画面显示修好了必须以真实完成事实为准。低动态保留前后状态图标，静音仍有简短字幕。没有新的故障种类、零件库存或维修小游戏，幽默来自可观察的修理过程。

## 17. 候诊中的生活服务

患者入院满180秒后，首次在非安全服务的候诊状态产生如厕需求，以后按如厕、饮水交替，每次实际完成或随身用品兜底结束后至少180秒才产生下一项。只有一个待办需求，长期治疗不会堆出多次欠账。已经叫到且获得临床预约、手术、转床、住院恢复或其他实际临床服务中只延后检查，不离开安全阶段，不提前积累厕所等待怒气；已经进入离院流程则不再生成新需求。

需求开始时原子标记临床票号暂离，保留既有waited_ticks和票序，释放原座位；此时没有临床服务位预约。公共设施的区域意图、到场排队和实际取位统一执行[公共设施区域寻址规格](../specs/26-10/2026-10-18-public-facility-area-use.md)，不提前占两间厕所或预占回来的椅子。若同tick临床叫号已经取得预约，临床预约优先，本次需求延后。票序轮到暂离患者时可让下一位先看，显示“正在生活服务”；回来重新参与选站，按原票号等正在进行的服务结束，不挤走别人，也不因暂离降到队尾。

生活暂离期间暂停主临床票的有效候诊累计与随机弃候评估，原累计保留；厕所等待另用当前连续排队时长，作为唯一主怒气原因；转为行走、使用或兜底即清零该连续计时，找设施的45秒总界限仍从需求开始计算。正常行走去生活设施及实际使用不算厕所排队，饮水没有额外一条等待怒气公式；仍可受到实际脏乱/噪声影响。离开座位去生活服务时不再认定“需要候诊座位”，不会同时罚无座。生活服务不是新的临床阶段，不触发临床开始的−6怒气；随身用品仅按原规则每需求+5一次。

### 17.1 找得到，也能用得上

普通卫生间FUR07和饮水机FUR17一次1人，按真实身体自动伸缩；空间不足则不能使用。AE03/AE02是宽敞造型备选，不是大体型许可。自动请求先选用途区域，到场再查具体使用位；区域选择、预计开始时间、局部竞争、8秒服务和45秒寻找/行走/排队总界限由[公共设施区域寻址规格§3～4](../specs/26-10/2026-10-18-public-facility-area-use.md#3-自动选区与局部选位)定义。所有日用设备免维护；离开后的回程以当前临床候诊区为目标，不追逐旧椅子。

短时占用与区域满员属于正常排队，不等于没有合法设施。无合法机会及精确期限边界按公共设施规格处理，计时不因换区或读档刷新。电梯安全行程先真实抵达站点，不能用倒计时传送。需求寻路失败不触发临床的60秒无站转诊规则。

已经开始的8秒生活使用安全完成，伸展占地保留到使用者离位才收拢。改建等待安全边界；设施免磨损与故障。队列先到先用，不硬占唯一出口，不把护士拉来服务。无合法设施的8秒随身用品兜底在真实落脚区域完成，不生成可售物、污物或清洁任务；完后原子提交下次需求与类型，只撤销本需求的暂离原因。

### 17.2 候诊角落的座位与小动作

自动候诊先选区域，到场后在本区域采用§17.4的就近、环境和性格顺序；手动选椅始终指定该设施。已有合法座位保持稳定，不因每5秒行为扫描、朋友经过或环境分改变反复换椅。座位被改建占用、路线不再可达、原PB04寻找安静处或玩家明确换座才触发重选。换座先真实安全离位，不预占第二张椅子或让包占位。具体取位与失败等待执行[公共设施规格](../specs/26-10/2026-10-18-public-facility-area-use.md)，出发不提前取得使用权；原票号、有效候诊累计和无服务倒计时保留。

陪诊/探视访客只在目标患者真正能使用该座时于2秒内开始让位，身体与伸展附件真实退出后才释放座位，不能把一张小椅子让给根本坐不下的巨人。员工正在恢复能量、实际使用中的生活设施和社区活动已经取得的席位不被座位选择当成空位。患者先选合法空座，再查询陪诊/探视让座；没有兼容位置仍在合法站位等待。社区活动限于独立休闲区，其座位不进入候诊选座池，患者缺座不触发活动取消。舒适等级2中的饮水条件沿用本地功能设施作用范围，并要求该患者的身体和实际操作区可用；隔墙、不同楼层或无法操作的装饰水景不算饮水设施。

六种amenity_scenes嵌入现有8秒设施使用动作，每次只选一条：先取当前性格的适用表现，无特定表现则取该用途通用表现。选择在使用开始冻结，加载不重抽；空间不足时不表演成功伸展或正常使用，实际使用和展开状态一起保存。饮水可看到杯沿纸伞、好奇地接一小滴、对杯子行礼；如厕只表现隐私帘外的小牌、急性子的“马上回来”牌和慢性子仔细折好提示卡，角色内部不入镜。所有身体使用自身正式承托/道具适配，不假设人人有手或脚。饮水的杯、承接器与微观载具接口为同一服务的身体表现，水不直接浇向不适合接触液体的身体，不要求物件居民长出嘴。隐私牌和纸花表示当前服务进度，8秒结束不等于设施立即空闲；真实离位前占用与展开外形保持。六条场景和两条随身用品各有低动态描述，只取当前阶段对应姿态，暂停和读档不重演已经结束的动作。这些是生活服务动作，不额外占主事件或日常互动预算，不生成关系、任务进度或独立资源。

LifeNeed拥有唯一需求序号、类型、下次检查tick、开始tick/实际排队时长、公共意图、实际使用引用与冻结表现；使用中的余量仍由原ServiceSession拥有，不另存一份。QueueTicket的暂离由理由集合派生，生活需求不能清除事件暂停；生活不满只按该需求唯一凭据提交。完成后仅保留最新需求序号与下一次类型/时间，不积累每次需求历史；就诊小票引用原流程事实。公共意图与保存接续执行公共设施规格，不增加饥饿、疾病惩罚、餐饮库存或强制日常点击；实际路径、占位和计时仍需实机验证。

### 17.3 一眼能懂的椅子差别

候诊与员工休息各有实用选择。原普通/宽体/培养皿座位、遮阳/接水/干燥/凉爽座位、双人友好长椅继续使用原身体、偏好与关系规则；新增四种椅子的尺寸、价格和效果由chair_variants定义：

| 椅子 | 收起占地 / 价格 | 实际效果 |
| --- | --- | --- |
| 轻摇安抚椅 FUR49 | 1×1 / 180 | 患者在真实候诊中连续坐满20秒，怒气−3，每Visit一次 |
| 静音罩椅 FUR50 | 1×1 / 220 | 在座患者的设备/施工噪声怒气增长×0.5；不改变其他增长原因 |
| 翻页阅览椅 FUR51 | 1×1 / 200 | 员工清醒短休每秒−0.04压力，替代普通短休的−0.015 |
| 伸腿活力椅 FUR52 | 1×2 / 240 | 员工清醒短休每秒+1.2能量，替代普通椅+1；不抵扣睡眠 |

四种椅子开局可买、免维护，不加耗材、升级树或种族限制。自动适配仍要核验展开后的主体、使用者身体与进出路径；罩子、脚托和书架都只能出现在真实预留空间内。放不下就不能使用，椅子堵住走道后照常阻挡。角色只使用一张椅子，邻近十张不会共享效果；医院里的同款数量不乘倍加成。

安抚椅仅在患者的真实候诊和实际坐姿中累计，暂离、叫号离座或换椅即清除尚未达标的连续时长；达到20秒原子消费Visit的一次安抚凭据后扣怒气。换另一张同款、搬椅、反复入座或读档不能再领。访客没有患者怒气，员工使用时只作普通座位。该小幅安抚不清票号、有效候诊或无服务倒计时，不算护士安抚、医疗服务、绩效或奖励。

静音罩椅只在持续怒气采样中把占座患者当前噪声分量减半，再按原合计上限、性格和环境缓冲结算。它不消除真实噪声源、不修改周围环境分或quiet判定，也不屏蔽患者的叫号卡；没有噪声时不产生额外减怒。离位立即失去效果，旁人不会被罩住。来源卡显示实际少增长的量，不假称已经扣过同样怒气。

阅览椅和活力椅仅在员工区的清醒短休使用相应速率；在候诊区被患者使用时只提供普通座位。它们不与普通同类恢复率相加，不与睡眠、带薪休假或娱乐速率重叠。员工选休息处时使用该椅的实际能量恢复率估算路程与恢复总时间；相同总时间且压力较高时优先阅览椅，仍不移动已经开始休息的人。能量到原90目标就按班表行动，不为了刷压力建立无期限短休。每名员工仍要按睡眠规则去员工床，活力椅不是廉价替代病床或职员床的捷径。

四种椅子的effect_scene、ordinary_scene与low_motion_scene按实际占座者及原效果状态切换。安抚笑脸只随本Visit真实连续坐姿推进，离位前未达标就回普通姿态；静音罩只在已有设备/施工噪声分量时显示大小声纹，不画持续掉落的怒气点。阅览椅的书页与活力椅的刻度只随实际短休恢复变化，达到下限/上限便停住。空置、错误用途或效果已用过仍可作普通座位，不发虚假生效图标。

生效提示只在选中椅子或其使用者时展开一句原因，不在每张椅子上常驻数字、倒计时或奖励图标。低动态用同一真实状态的静态构图；适配失败保持原收起姿态并显示实际阻挡，不先伸出罩子或脚托。动作不能重置安抚计时、延长占座、召回已叫号患者或替代员工睡眠。

购买卡用候诊安抚、隔开噪声、员工减压或恢复活力的一句生活语言说明主要用途，同时展示价格与实际占地；原秒数、幅度和限制放在展开后的效果说明，读取同一parameters，不把每秒速率变成默认挑选门槛。预览可切换身体并定位阻挡格；不显示内部处理器和累计凭据。候诊任务持有公共意图，原SeatSession/FacilityReservation只登记实际使用及安全离位占用，安抚使用凭据归Visit；保存只保留正在计时的实际坐姿段，不为每张椅子复制居民心情。新增椅子不改变治疗成功率、诊费、排队次序或居民性格。

### 17.4 性格在附近找到自己的候诊角落

患者在尚未叫号、没有临床预约和安全服务锁的真实候诊中自动选区，到场后在当前区域选座；住院、生活暂离、活动、事件或离院流程使用各自原规则。局部候选的身体、自动展开、出入口、实际空位与路径全部通过，员工区、休闲活动席位和使用中的设施不作为可立即使用的座位。先查空座，无合格空座才请求原陪诊/探视让位；实际离开后才取位。区域满员可合法等待，不在出发前预约座位。

自动选择的次序由balance.seat_choice拥有：

1. 本区域局部候选的累计预计去程包含选区行程与剩余行程，按实际身体速度、连接、可估计交通等待向上取整至tick；只保留累计预计不超过30秒的合法位，不能到区后刷新额度。让位候选还计入预计安全让位时间；未知预计不加入本次选择。30秒是自动选择窗口，途中拥堵不因此传送、截断合法移动或承诺准时抵达。
2. 取其中最近路程Tmin，只保留T≤Tmin+12秒。种族已有环境偏好只在这个附近集合中优先：若有人满足，取满足者；否则继续使用全部附近候选。身体兼容始终在偏好之前。
3. 读取同一身体在各候选处的当前环境分E，取本集合最高Emax，只保留E≥Emax−10。静音罩不加环境分；价格与购买数量不参与选择。
4. 当前社会性格的seating.weights给八项真实条件加权，各项最多一次，合计W。定点得分为100×W−路程tick×travel_penalty_per_10_seconds；0.1秒tick和10秒成本单位共同决定换算，不逐项浮点舍入。按得分降序、环境分降序、路程升序、座位ID升序选择，平分不抽随机数。

| 条件 | 成立依据 |
| --- | --- |
| 安静 quiet | 目标原quiet查询成立，没有实际设备/施工噪声；静音罩没有消灭噪声 |
| 不拥挤 less_crowded | 原3格同层可达邻域中的其他居民少于4位，不跨墙/楼层认定旁人 |
| 朋友在旁 friendly_neighbor | 原关系确为friend，朋友正在同层可达3格公共邻域闲等；治疗中、乘梯中或院外朋友不成立 |

性格只在本区域近处且环境差距不大的集合中影响取舍：害羞者偏向安静、不拥挤；好奇者偏向装饰与小戏；热心者偏向朋友；急性子更看重路程。选择邻座不生成关系进度，爱热闹不把争吵视为值得观看的活动。员工短休在当前区域比较局部行程和恢复总时长；PB04先筛出噪声或拥挤改善且另一项不退步的候选，再执行本节顺序，不能用性格得分推翻原改善条件。

算术样例假设两张椅子均合法、满足相同偏好且没有叫号：A路程2秒、环境80、八项均否；B路程8秒、环境78，只有安静和不拥挤成立。两者均在附近与环境带内。急性子A得−300、B得−1100，选A；害羞者A得−100、B得600，选B。另有24秒/环境99的C时，C超过最近2秒+12秒，不参加环境比较；31秒的位不进入自动池。它们是条件性选择计算，不声称游戏已经完成寻路或碰撞验证。

玩家可在患者尚未叫号的候诊中指定任何真实存在、可达、身体兼容的公共候诊座位，不受30秒、附近带或性格排名限制；沿途不改成自动区域寻址，暂时被使用时等待同一目标。原阻挡提示说明不能使用的原因，不增加确认、费用或奖励。自动区域无可立即使用位显示本区等待或当前兼容/路线问题，不能谎称全院没有椅子。原无座规则照常；走向候诊椅仍算有效临床候诊，与生活暂离不同，未真正坐下不触发效果。临床叫号优先取消未使用的候诊意图，入座小动作沿原1秒打断响应结束；实际离椅、收拢和电梯安全行程仍真实完成，再去服务位。

十种seating.entry_scene嵌入原入座动作：候诊卡认真立正、给装饰做无声验收、在朋友方向准备并排听号。scene_context_ids为空只使用自身卡片与坐姿；非空时至少一项当前条件仍成立才显示，否则用普通坐姿。卡片沿各身体正式承托适配，无手、叶冠、长颈与载具不长出新肢体。小戏不加时、不占日常互动组、不创建对话或旁人动作，入座后不循环；暂停、切层、读档直接映射当前坐姿与椅子效果。低动态保留同一事实的静态姿态，叫号卡始终可见。

变更面为原候诊选位的顺序、十种性格的座位权重和十个自身入座表现，不增加满意度指标、关系事件、专属椅子或资源收益。SeatSession/FacilityReservation拥有实际座位与空间，QueueTicket拥有候诊计时，Resident.social_personality_id引用唯一社会性格；选座分数和当前原因只读派生，不保存未来心愿或邻居快照。几何、交通等待估计、叫号打断、趣味可读性和本机负载仍须运行验证。

### 布置入口与椅子比较

建造页的“员工生活”直接提供双床休息室、共享办公室蓝图及护士工作台；护士台定位同层现有工作位，缺失时可直接进入普通摆放预览。两张员工蓝图引用真实起始布局，复制后照常购买、检查体型和路径；不会复制原员工、个人床归属、床位预约、工资或睡眠进度。房间尺寸可调整，提交前按目标员工卧姿与办公包络验证。

“座椅”仍是一组用途卡片，显示价格、收起占地、一项效果及适用情境。普通座椅保留稳定的等候/短休功能；四种效果椅是不同用途，不是四级品质。候诊只标安抚、静音，员工短休只标减压、活力；在其他合法区域摆放仍能当普通座位，卡片说明该状态下没有附加效果。没有“买最贵一把就全院最佳”的指引，也不把四种椅子加入强制任务清单。对比示例固定同一恢复目标：员工已在合法座位、能量35升至90且无补休/睡眠要求时，普通椅需55秒，活力椅在45.9秒边界达到目标。阅览椅仍用普通能量速率，在55秒内减压2.2，普通椅同段减压0.825；均受实际压力下限约束。这些是排除路程的算术样例，选座仍计入真实行程与移动消耗，不承诺远处好椅一定更快返岗。

## 18. 一位病人的就诊小票

患者卡可展开“这趟就诊”：从实际到院、接待、初诊、检查、会诊、治疗尝试、住院查房到离院，以已发生的阶段串成时间条。当前阶段显示正在发生的事和原系统提供的阻碍，未来阶段只列可能流程，不显示隐藏病名、随机种子、已承诺但尚未揭晓的成功结果或未来报复动作。病名仍在诊断证据≥90时揭晓，预计成功率仍是预计。

主流程各时间段互斥，合计等于本次实际在院时间；暂停与未加载医院不计模拟时间。一个阶段内部可以展开走路、乘梯、有效候诊、生活中断或事件注记，这些是可能重叠的标签，不能再相加制造更长总时长。有效候诊始终取QueueTicket及其既有累计，怒气、评分和离院抽签不读取小票另起计时。乘梯中未采样的环境不填0或100，也不拿楼层切换补样本。

主流程切换立即留下事实；阻碍历史最多每10秒采样一次且相同原因合并，标明采样时刻，不把采样间隔伪装为精确原因持续时间。当前阻碍实时读取，不等待历史采样。每Visit最多保留最近32条详细阶段/注记，早期记录折为按阶段的实际时长汇总，并显示“早期细节已合并”。不记录每个路径格或动画帧，不靠看诊面板是否打开决定是否记账。

离院后小票冻结本次结局、确诊或未确诊状态、实际执行方案、参与人员与科室的当时名称、阶段时间、已结算收费和体验分项。转诊、放弃等待、两次未治愈各保留原结局，不统一涂成康复笑脸。收费逐项引用职称诊费、各次检查/治疗/护理床使用费和治愈费的实收账目，显示实际医生与设施名称；未完成项目显示未收，失败项目只列已经完成的设施使用费。安全接续不新开一张治疗账单，护理床已包含照护，不能再叠加旧照护费。小票是历史投影，不能反向修改余额、奖励、病历或评分。

本院保留最近100张离院小票，按离院tick与Visit ID淘汰，活跃患者的过程不占这100张。小票淘汰不删除图鉴累计、熟客真实往事、评分窗口或院史摘要；旧故事仍可显示必要前情，但不能点击一个已不存在的完整轨迹。科室改名、房间搬走、医生离职后仍显示当时名称，定位按钮改成“已搬迁”“已离职”或“记录已归档”，不在原坐标凭空找回旧角色。

### 安静叫号与自动接续

号签是逻辑队列的可见表示，不是库存物品。五种queue_cues随原队列状态显示：等候时箭头折起、取得预约时展开、生活暂离夹上书签、改派时卷回旧箭头、条件未齐时贴着真实原因。动作是角色身旁的原队列提示，不要求角色有手或真的拿纸；微观居民的提示锚在载具外侧，其他骨架也使用自身提示位置。低动态用相同信息的静态图标，不逐字重播字幕。queue_cues.text只提供当前病例面板中的短状态标签，不作为现场句子、发言或叫号文字；现场只用票号、头像、站点和指向图示。没有导览屏也能正常叫号：轮到并取得有效预约时，患者查看号签、医护在原工作位置示意，角色自动走向实际目的地；静音时照常生效。SE03显示已确认的房间名称、楼层和当前叫号，不朗读、不新增喇叭，既有挂错科改善只按原规则结算一次。

候诊卡先显示下一步和真实原因；尚未绑定站点时按当前临床阶段与原就绪查询的实际缺项说明等候，只有确实在等待合法诊断台空闲时才使用该文案，不能用它代替治疗设备、医护或路线缺项。有有效预约后才显示目标房间与路线。预计时间依据当前剩余工作、有效队列和实际路程，原因或班次/占用尚不确定时写“等待条件齐备”，不编造精确倒计时。未确诊的号签不泄露隐藏病名。叫号不要求玩家点确认，也没有错过几秒就罚款或作废的规则。

叫号后保留当前站点，其他站点略快不触发折返。只有当前预约超时、资格/开放/设备条件失效或原路线不能恢复，才按统一调度重新选择，保留票号、病例、已付费用与累计等待。生活暂离按§17释放临床站点，回来重新选站；不占一台机器等喝水，也不打断正在服务的后来者。实际已开工的患者只走原治疗接续与临床安全规则，不能被叫号层另建一次治疗。

改派时个人号签与屏幕从同一预约读取新目的地，旧箭头立即撤下。一次原因变化只给一条短提示，反复查询不重复提示；关闭字幕只关表现。下一步自动继续，院长可以定位或优先照顾，无须为每次回队、换层和纠正挂号点“继续”。

## 19. 九类原因卡与科室复盘

原因卡只解释实际阻碍，按临床安全、硬条件缺失、正常等候的顺序展示主要原因，可展开并存原因。多个条件同时不满足时列出依赖，不保证处理第一项后立即开诊；无病人或没有样本时不编造瓶颈。临时故障、医生合法休息或角色生活需求不直接归咎于某个人。

| 原因 | 证据 | 可进入的操作 |
| --- | --- | --- |
| 当班岗位未就绪 | 当前合格员工、班次及安全占用 | 排班与招聘，保留手动锁与工资预览 |
| 设备暂不可用 | 实际故障/维护及唯一工单 | 定位维修页，不通过点击清除故障 |
| 通路或伸展空间不足 | 真实身体、设施展开体积、目标及可达图 | 定位阻挡格，进入改建预览 |
| 同层床位未准备好 | 当前床位容量、兼容性、监护及护理覆盖 | 临床资源板，不取消已承诺床位 |
| 轮到别人先看 | 原票号、站点预计开始时间 | 查看队列；优先照顾仍受两位后轮普通患者的规则约束 |
| 先照顾生活需要 | 当次饮水、如厕、座位等真实服务 | 查看可达设施，不把中断作新病例 |
| 一段误会还没结束 | 当前互动、情境、剩余安全收尾和护士任务 | 定位原事件，不按种族断言必然冲突 |
| 等最后一次查房 | 已完成恢复、待查房及覆盖缺口 | 查房排班；不提前释放床或结算治愈 |
| 治疗包不足 | 实存、有效预留、本次需要及采购预算 | 打开一份全院采购卡，不逐人劝返 |

现有经营提示继续按同源问题合并、限制短提示数量。持续问题只更新原卡，短提示按界面规格§7的首次出现/首次升级规则给出；十秒合并不是定时重播。原因卡使用内容定义的source与target_panel映射，由原就绪、队列、生活服务或事件系统给出事实；卡片不再计算一份资格、床位或路径。退休或尚无细分卡的合法原因显示原系统的具体说明，不用默认的“医生不够”覆盖未知情况。

科室复盘保持原最近3个已结算日、最多100病例的评分窗口；可从某一分项展开最多三条实际样本原因，看到其发生时科室、最终治疗科室以及相关就诊小票是否仍可查看。导诊差错按发生地，病例评分按最终实际治疗地，搬房、改名与转科不重分历史。未参与服务的医生不因远处厕所故障扣分，没有数据的分项保持缺样本。

尚未实际治疗就转诊或弃候时，最终治疗科室为空，标“未进入治疗科室”，不把最后路过的房间算作治疗者。医院仍统计该次就诊的实际结局和体验，已经发生的导诊/照护等流程事实仍按发生科室保留。已终结病例的显示归属不能由现时房间分区重新计算。

面板可并列两个已结算医院日的病例数、平均有效候诊、实际环境样本均值、治愈/转诊/弃候数，显示分母和可用样本，不将不同人数、疾病或方案的差异写成改建/培训的因果效果。操作提示用“可查看”“可能改善”，不承诺招一人就增加某百分比评分。没有新排行榜、排名奖金、强制整改任务或自动经营模式。

小票的有界过程与冻结摘要归就诊历史，病例执行仍归Visit/TreatmentAttempt，评价仍归RatingWindow，资金仍归账目。读档恢复采样游标，旧记录不重发完成事实；摘要可以保留已退役定义的当时显示文本，不为展示而实例化内容。静态检查只核对原因来源、页面映射与容量配置；真实时间归类、事实去重和复盘可理解性须在游戏中验证。

## 20. 日常清洁与环境恢复

垃圾和污渍只有清洁员实际完成工作才消失。没有自然清理、到时收纳或离线清理；换层、读档、移走来源设备、事件结束都保留原位置与工作余量。事件自己的演出道具在收尾时结束，已生成的真实垃圾是独立清洁任务，不随事件删除。没有清洁员时，垃圾一直保留。口袋、纸巾、湿脚印和洗伞事件结束后，原杂物与水迹照常存在；居民只收住自己尚未落地的配件或水流，不捡走地面污物。清洁员的止源任务与逐份地面清扫分别使用原事件工时和DirtPatch余量，不以一段演出双算两种完成。

cleanup_sources定义四类真实来源：事件散物；每处饮水设备完成6次饮水后的杯套；每处厕所完成8次如厕后的水印；每台门诊设备完成8次真实治疗后的包装。失败治疗也算完成，安全接续只记同一Attempt一次；不按种族、路过或空闲时间造脏。事件散物和杯套各需4标准工作秒，水印和治疗包装各需6秒；工时在生成时冻结。

杯套与包装若在4格内有可达FUR18垃圾桶，就投进桶，形成桶内待清理任务；桶中能看到小纸片，直到清洁员完成4标准秒倒桶。桶内垃圾不扣地面环境分，不另设装满惩罚、垃圾袋库存或清运车辆。同一桶只有一份待清理任务，后续投递合并表现、不增加工时；搬动保留其脏状态，打包或出售须先等清洁员清空。垃圾桶不随机损坏。后来摆桶不能吸走地上旧垃圾。

地面垃圾生成在来源旁最近合法格，按距离、XY稳定选择，不占家具、岗位、交通端口以及有效的伸展/工作预留；不能在已经承诺的设备伸展区里突然补一团垃圾。每格最多一份、每来源设备最多一份日常地面任务。每块已启用32×32地块各最多64份地面与桶内任务，事件每次仍最多3份；地面层按已购地块、上层按已完成楼板模块启用，预算只在该实际楼层与地块使用，不设全院64份总上限。垃圾按实际落点、桶内任务按桶锚点计入当地；无楼板或未购土地不生成垃圾。当地达到预算时不生成新的垃圾及其落地表现，已有垃圾与任务完整保留，不用删除旧垃圾腾名额。旧脏桶搬入另一地块仍须按原清空前置处理；任何重建、范围缩小或旧存档恢复造成超额也保留旧垃圾，只暂停当地新增直至低于预算。扩建只增加当地容纳范围，不凭空造脏，也不补生成此前被跳过的垃圾。使用余数达到门槛即归零，不积压待生成批次；重复垃圾并入已有表现，不累加隐藏卫生债务。

清洁员默认全院自动找活；原有手动区域限制、休息与排班保留。先过滤本人区域允许、有真实路线和可用操作位的任务，再在可做任务中先处理已等待60秒者、院长置顶的一项，其余按生成tick、路程、ID；每人一次只领一单。同类老任务也按原生成tick、路程、ID排序。不可达旧单不霸占闲置清洁员，其他人可处理适合自己体型的任务；保留原垃圾、余量、生成时间与置顶，通路恢复后自动参加原排序，不需要玩家再点一次清扫。

地面污渍为可走的薄层，不增加实体墙；清扫提示范围只增加绕行代价，但清洁员身体和工具使用区仍按真实占地避让。地面工作可站在污渍所在合法地格，或身体边缘距目标不超过1格的相邻合法操作位；目标与操作位之间不得隔墙、关门或实体家具。倒桶使用桶边可达操作位，按本人身体和完整工具动作核验，不能隔床吸走垃圾。操作位不足时说明具体挡物，不把更大清洁员缩小，也不按种族禁止其清洁岗位。

派出后因实体变化失去路线或操作位，释放尚未开工的员工预约，任务留在原处并按既有通路重查节奏等待；短时行人会车沿原让行规则处理，不反复抢单。正在清扫时医疗通行和实际使用者需要经过，清洁员按真实路线让到合法位置，暂停工作、保留余量与贡献；只有重新站稳且工具区可用才继续计时。没有安全让位点则不能先占住唯一出口开工。让行期间依然占自己的身体空间，不能靠取消清扫标记让旁人穿透。没有合法落点的来源不生成垃圾。

四种cleanup_sources各自提供待清理、清扫中、中断与低动态表现。事件散物翘角或水迹留小逗号、杯套顶歪帽、厕所水印像逗号、废包装举箭头，均保持原DirtPatch位置和可辨识的脏物轮廓；它们不是居民，不主动移动、不说任务台词、不额外制造垃圾。桶内用纸边表示原待清理任务，后来的投递不让它自行清空。

原清扫工作实际推进时才把散纸排队、杯套鞠躬、水印改成句号、包装折好等动作映射到进度；最后消失帧只对应实际清洁完成。中断停在剩余量对应的姿态，接班者继续同一工作，不重播开头、不重置工时。多肢、植物、灵体与微观职员使用原岗位骨架工具位，所有清洁员都能完成同样工作，不因没有人类双手丢失收尾。低动态以少量稳定姿态保留脏物与完成差异。

只有清洁员在真实操作位完成剩余工作，阶段⑥才产生唯一cleanup_completed并删除该份垃圾；经验归实际贡献最多的清洁员。中断、休息、换班和离职释放员工预约，工时与贡献仍归原DirtPatch，其他清洁员可接着做。垃圾保留到生成后的第几日都不改变清扫工时。清扫完成再释放置顶和任务、刷新环境；不存在expired终态。

建造或搬迁预览遇到地面垃圾时，先生成等待清扫的准备事项，不扣建设费、不盖住或搬走垃圾；清洁员完成后按正常改建流程应用。设备拆走仍保留地面的独立垃圾。保存DirtPatch的位置或桶引用、生成tick、来源凭据、冻结工时、余量、贡献和预约，不保存到期时间。终结记录按原任务与实践归并，不维护无界垃圾历史。

地面每处仍减4环境、局部最多减16；同层4格可达范围无地面污渍才有8分洁净项，清完四处可恢复24分。桶内任务没有地面扣分，也不造成隐形惩罚。清洁页只展示“待清理、正在处理、路线被挡住”和可定位来源，多个垃圾合并为一条卫生提醒；不显示清理倒计时。会排队的纸片、向拖把鞠躬的杯套等笑点全部发生在实际清扫工时内。

清洁预算属于后台表现数量约束，不作为患者拒诊、员工罢工或强制升级条件，面板无需玩家分配。两个地块各有64份容量，第一块满额不会阻止第二块真实服务产生垃圾，也不能把第二块空额度挪来让第一块生成第65份。每个桶和每个来源仍合并既有任务，扩建不放大单处清洁工时或环境惩罚。

## 21. 机器升级：施工完成后才生效

upgrade_tiers拥有每一级研究、基价比例、30秒标准工时。medical_equipment_profiles覆盖六种核心医疗设备并指向操作能力；R12/R13只开放改装等级，不替代设备自身建造研究。原始upgrade_level=0显示“基础型”，完成1显示“精修型”，完成2显示“奇想型”，每次只施工下一级。门诊仍保留MachineDef.upgrade_levels声明，其他医疗物件由操作档案引用同一等级表，运行时都使用原PlacedObject.upgrade_level。

高等级设备增加可发挥的诊疗能力，合格医护按专业能力发挥60%/70%/80%/90%/100%，E=升级级别×发挥率。门诊每E增加2.5个百分点成功率和速度分母0.2；初诊与检查增加证据与效率；手术由同一张台与三人配合提高成功率和效率；病房由本床与实际护士决定恢复效率。具体公式归模拟规格与临床团队。入门医护可以使用奇想型并获得明确增益，训练后同一台设备发挥更充分；设备升级不代替专业训练。概率/证据达到上限时面板明确显示上限和实际工时，不虚构额外百分点。

例：普通B档、能力1、无其他修正时，门诊基础型88%，精修型89.5%，奇想型91%；能力3配奇想型为96%。40秒机器在能力1/奇想型时为32.3秒，能力3/奇想型时为28.2秒。零级普通病例仍可顺利治疗，升级是持续经营中的改善。价格来自设备原定义：诊断台800、整复台/调理舱各1400、奇想台2800、手术台11100、护理床1850；价格来源只索引一处，不在升级表再定价。阅读页的材料价对照逐台从同一基价与upgrade_tiers生成，一级和二级分别向上取整后相加；护理床为555+833=1388币，不能先把75%四舍五入后再拆分。只列材料成本，工资、研究与扩建支出仍由各自规则说明。

升级材料每级分别按基价30%与45%向上取整，合计约75%；研究与真实施工仍需完成。效率系数统一取medical_equipment_effects：门诊0.2E、诊断0.15E、手术0.1Es、病床恢复0.15Ew。无其他修正时，诊断1的奇想型台把18秒检查缩至15.3秒；最低合格一级手术团队配奇想型台把120秒手术缩至105.9秒；护理5配奇想型床在138.5秒边界完成180标准秒恢复。苏醒、转床、主动护理、出院查房与实际路程仍独立占时，不能把手术台工作时间当成全程承诺。初诊8秒下限、98%成功率上限及病例总耗材保持有效；省出的时间只有在存在后续需求、人员与空间时才增加吞吐，不直接产生现金。

升级草案显示材料价、施工工作量、当前可替代机器及停诊影响。效果对比固定同一明确病例、相同方案与同一组真实合格医护，只改变本次目标设备等级；卡片说明所用病例和人员，未选病例或缺实际团队时先显示用途短句与缺项，不拼接不同人的最高能力。操作时间与原计划的候诊、苏醒、转床、主动护理、住院和查房分列，不能把操作差额写成整趟就诊必省时间。已冻结Attempt仍显示原承诺，新等级的比较标为后续服务；病床比较按当前真实覆盖护士计算。使用中的机器先通过原安全改建安排停止新预约，当前病例安全结束或完成明确的安全转移后才可应用。院长确认最新报价时一次支付本次材料费、创建唯一UpgradeOrder并释放准备安排；缺研究、现金、合法维修员操作位或正在参与另一改建时整单拒绝。报价中包含原升级施工服务，确认后从实际入口安排上门人员；入口或路线受阻时显示等待原因，不随时间自动升级。升级是发展支出，普通社区兜底援助不支付；自由建造仍沿原创作基金记实际成本。

设备有未完成升级时停止新诊疗。维修员调度先处理所有真实故障和符合策略的保养，再处理升级；升级之间按提交tick与ID排序。设备处于故障、待故障或尚有有效维护单时，升级保留材料和已做工作，先由原维护单处理；两单可以同时存在但绝不同时占用设备或维修员。升级施工期间照常故障扫描，阶段②发现故障先暂停，不能在阶段⑥抢先完成以抹掉故障。维修恢复的100状态与180秒免抽期只由真实维修/保养拥有。

确认应用冻结各级规则版本、材料价和标准工时；每级第一次实际施工冻结本次上门服务标准速率；换人、故障和搬入库存都保留原级标准工作量与贡献，重启时只重算当前工人的速度。完成一级时原子提高upgrade_level、把这一阶段已付材料加入物件paid_cost、产生唯一machine_upgrade_completed并释放阶段贡献；完成凭据记录实际外部施工人员，不发员工实践。整单完成后解除自身停诊原因，仍重查开诊意愿、路线、人员与设备状态；不自动完成病人的会诊或治疗。

尚未开始任何工作的阶段可以取消并按其实际预付材料原额退款；已开始阶段只允许暂停、继续，或在出售/拆除设备时明确“放弃未完成升级”。放弃不返已开始阶段材料，也不把它并入物件退款；尚未开始的后续阶段仍全额退。出售完成等级的已付成本只按原未用100%/已用80%结算一次。仅施工不算诊疗使用，ever_used仍由真实服务决定；升级不能清除已用标记。赠机基体退款0、已完成的付费升级按同一使用比例退；借用机器无升级入口，避免归还时遗留材料。

蓝图目标二级且无匹配库存时，预览拆列机器基价、一级材料与二级材料，确认放置创建零级机器及同一两阶段订单，预付两级材料；实际逐级完成60标准工作秒，不能直接出生为二级。当前层仅完成一级而二级尚未开工时，可取消后续阶段并保留一级；开始二级后只能按已开工规则处理。库存复用仍要求目标等级完全一致；升级中的库存不能充作蓝图成品。整组搬迁在工人安全停点暂停原单，订单随同一设备ID迁移，落位后依原规则接续，无重复购买或解锁。

例：自购整复台M09基价1400，一级420、二级630，完成总成本2450；使用过卖出退1960。赠送整复台完成两级后的实付成本1050，使用过退840。二级已预付、一级做12秒未完成时出售，未开始二级退630，一级420不退，主体仍为零级按原基体成本退款；不会为已演出的梳结、拼装等动作另退一台机器。恢复检查等级、完成阶段和付款凭据一致，目录变价不改已付款订单。

六种设备各有一条upgrade_presentations，按definition_id绑定原物件。基础型保留质朴玩具结构；精修型增加透明护罩、分段刻度与同步灯光，奇想型保留精修结构并加入悬浮组件、小工具助手或更丰富的机构联动，远景剪影也可辨。折叠症状板按真实检查项展开，整复悬臂只送出本次需要的工具，调理双环保留光照/声音/温湿病例各自的介质，奇想窗显示本次病例图案，术台协作标记跟随真实团队操作，护理床云形机构只在实际调整时动作；每条完整内容都在索引中可读。

升级附件始终留在登记动画包络内，不侵入患者/操作者/维修员空间，不增加地格、噪声、装饰分或额外故障抽签。低画质保留轮廓配件和等级徽记，减少粒子；关闭闪光仍可区分三档，效果不遮住病症与安全指示。施工半途显示未装好部件，完成才启用等级外观。关机、故障、待修与工作阶段分别有状态，炫酷外观不能掩盖故障。外形读取设备已完成等级，不能因操作者能力较低而把高级机器画回基础款；动作进度则读取原服务的真实工作。缺人、缺耗材、任务暂停或无人使用时，工作机构停在安全待机姿态，承托中的患者与展开占地照常保留，不能演出一次不存在的治疗。升级小助手与medical_progress_cues共用当前病例及屏幕内次要道具预算；同一工具不由两层表现各演一遍。临床Attempt已冻结的结果、工时与耗材不回算；病房设备升级须先腾空其影响床位，仍遵守既有安全交接。

## 22. 一种治疗包与真实采购

自动补货默认开启，小院起步仍为可用量低于20时补向60包。扩建后同一规则自动读取真实规模，不增加院长要调的供应链参数：

- 实体容量C=max(200,20×已安装门诊主体数+80×已安装手术台数)。按medical_equipment_profiles的outpatient/surgery类别统计所有楼层已完成放置的唯一设备，不数库存、蓝图草稿、内置附件或未完成建造。房间临时关闭或机器维修不移走其真实储物空间；护理床和诊断台不贡献治疗包容量。
- D为上一已结算医院日真正领用的治疗包数，首次开院D=0。补货目标T=min(C,max(60,ceil(3D/4)))；触发线R=min(T,max(20,ceil(D/4)))。只根据真实Attempt领用量，不用到访机会、准备预留或未开始方案虚增需求；新建空设备不会直接触发大额采购。
- 普通经营的自动保留额B=max(1000,既有财务投影中的下一次工资与运营应付成本上界)。不包含未知诊疗收入、未领取奖励、未来故障或尚未下单的发展开支，也不把这笔现金真正圈存；玩家手动采购仍可使用。报价页只显示“保留日常开支B”，详细来源可展开原工资与运营预算。

预留包计入实体库存、从可用库存扣除。普通经营可用量低于R时，可付数量=max(0,floor((当前现金−B)/20))；订单量=max(0,min(T−可用量,C−实体量,可付数量))。大于0才下单，差一点补不满T也买得起多少先买多少。初始医院B=1000时，可用19、现金1819买40包，得到59包、现金1019；可用0、现金1200先买10包，现金1000，已有足够用量的疗程可正常开始。

例如20台门诊主体与2台手术台提供C=560；上日实领320包时R=80、T=240。可用70、现金8500、下一次必要日结4000时，自动买170包花3400，留下5100。关闭接诊或未实际领用的日子不会制造新需求。打包、出售设备导致容量降低时完整保留已有实物与准备预留，不自动销毁、卖出或退款；超过新容量期间只停止新增采购，随真实消耗恢复余量。

创作模式同样先判断可用量<R，自动订单量=max(0,min(T−可用量,C−实体量))；不受普通经营的可付数量和保留额B限制。仍在原阶段①最多提交一单，原开关/容量/预留/实际用量全部生效。该订单总成本=数量×单价，医院实付=min(现金,成本)，创作基金直接付剩余差额，现金不变负、不先领资助现金。基金支付不占每日社区援助采购次数。实体不足没有付款事务时仍不能开工；库存超容量仍完整保留、停止新增。正常模式按现金保留规则补货，创作模式按真实订单记账，两个模式不混用。

检查发生在阶段①：先按已接受命令顺序处理玩家开关、手动采购等操作，再读取本院最新开关、现金和库存，最多生成一张自动订单；玩家刚关闭不会再按旧开关买一单，手动入库也不重复补到旧目标。后续阶段的实际消耗、预留与现金变化最早下一步触发，每次订单完成后不在同一步递归补货。可用量已经达到当前R便不因未补满T反复小单追目标。数量为0且实际不足时沿原一张原因卡说明真实原因；“自动补货预算不足”只属于普通经营，创作模式仍可因“库存空间已满”不能新增，不为每次重查弹提示；部分买入只在原库存页和账目显示实际数量，不逐箱庆祝或追加确认。玩家主动采购不受自动保留额B限制，但仍按其确认数量整单执行，不擅自缩单；可关闭自动补货。自动采购也逐笔付钱，不能透支、挪用预留包或跳过库存。

SUP01的四种opening_scenes分别对应三类门诊主体与手术台：软工具套、棉花云贴、幻想框护套与术台工具保护套。它们在Attempt真实开始并完成唯一领用后，嵌入原准备演出；一段包摞配实际包数，不逐包增加动作时长。准备预留不是开包，取消预留不播放拆封；暂停接续、转床与读档不再次拆包。诊断、护理、查房不展示领用治疗包。动画不会修改库存或单独新增垃圾，包装清洁仍引用既有真实治疗完成来源累计。

方案卡只显示本次需要、当前可用与推荐理由，成本按实际包数×单价解释。初诊、检查、护理、恢复和查房不另外消耗治疗包。方案报价不扣库存；真正临床准备最多提前30秒预留本次包数，与原患者、机器、人员和床位资源束原子提交。按票号、准备ID稳定处理并发；现存减全部有效预留即为可用量，不能把同一包同时承诺给两人。准备取消、超时、资源失效释放预留，不扣包、不发实践。

全员到齐真正开工时，同一事务验证预留、从实存扣除数量、释放预留、建立唯一TreatmentAttempt并冻结结果、工时、收费和用量。缺包不得先开始、记治疗失败、抽结果或补成负库存。开工后的中断、故障接续、换床和读档沿原Attempt，不再次扣包也不退已拆包；第二次真实尝试按新方案再取包。已开始手术所需包已全数领用，恢复和护理不会因仓库空了被中途取消。

现金账只在采购时列“治疗包采购”，属于原经营消耗分类；领用只减少库存并记录数量，不再另扣一笔耗材钱。采购与领用可以分别查询，初始采购也计入实际支出；日示例的消耗成本是平滑经营估算，不冒充当日采购现金流。快照保存库存、采购命令凭据、准备预留及Attempt唯一领用记录，各事实只有一个拥有者。SupplyUsage只保存当日实际领用累计与上一已结算日总量，领用事务原子增加当日计数，日结一次轮换；不另保存可修改的C/R/T/B，它们从真实设备、用量与财务投影派生。任何恢复中出现负库存、重复预留或未付到货都拒绝覆盖保存。

库存不足且实际有待治疗患者、现金不足400时，可点一次“援助采购”：社区补足医院当前现金与400的差额，医院实付其能承担的部分，真实购入20包。每医院日最多一单，仍需剩余容量≥20；普通余额充足时使用正常购买。援助写原非现金代付账，不把现金加到钱包，不用于买地、装修或设备升级。提示直接给出采购入口，无需刷任务、谈判或找某种族。离线不刷新次数；同日反复读档不能再领。未能采购时诊断与现有护理继续，未开始治疗按原等待和友好转诊边界处理。

### 22.1 自动检查先排除确定不会下单的情况

自动补货仍在原阶段①玩家命令处理完成后每边界检查一次；不增加间隔或跳过下一合法边界。先读本院当前开关，关闭就不求采购容量或保留预算。开启时沿原实存与有效预留得到可用量A，读取SupplyUsage的上一已结算日用量D；令U=max(20,ceil(D/4))，因原R=min(T,U)必有R≤U，A≥U已足以证明本边界不会下单，无需为此统计全院设备或求下一次工资与运营预算。U只是当前表达式，不另存一份可修改需求。

普通经营中B≥1000、每包20币，因此当前现金<1020也必定买不了一整包，可在求真实B前结束订单求值；判定引用原保留额下界与SUP01单价，不另设资金阈值。现金等于1020只表示有可能买一包，仍须读取真实B；下一次应付4000时不能按1000下单。创作模式没有这项现金排除，也不读取B，继续由原创作基金承担合法订单差额。

其余情况按原设备来源求C及原公式R/T；A≥R或实体库存已达到/超过C时不求B。只有普通经营仍低于真实R且有实体余量时，才读取原财务投影的当前B并求原整包订单量；创作模式在同样需求/容量条件下直接求原订单量。任何正订单仍按当前模式、现金、单价、容量和预留执行原子交易，同边界最多一单，不递归追T。设备统计、有效预留及财务投影各沿原事实所有者查询，本规则不要求新建缓存或把取值成本视为零。

这些排除只得出“本边界没有自动订单”，不产生缺货主因或替代库存详情。当前缺货卡仍沿原相关状态查询说明完整钱/空间/准备原因，不因现金判断先执行就遮住库存已满。日结后的D、命令后的开关/模式/现金/库存及按原阶段释放的预留都在下一原合法边界重新读取；尚未到②的预约释放不提前生效。暂停和载入继续原命令边界，无后台采购或离线补货。

变更面仅为原自动订单的等价求值顺序；阈值、购买量、日结、基金、供货、病例公平和缺货反应保持原定义。静态对照完整公式的普通/创作、取整点、预留、超容量及资金边界；实机在原160/640与宽高医院记录实际设备统计、财务求值次数和①/完整模拟步耗时，连同订单、现金、库存与随机结果重放比较。没有运行数据前不声称节省毫秒或达到帧率。

### 22.2 先补到能够继续这一项准备

全院缺货卡与原采购面板增加一个可选建议：“先补x包，y币”。原“买20包”和自定义数量继续提供，自动补货仍是默认日常方式。建议只取当前已经确定方案、其余临床条件可就绪、唯独包数不足的首个候选，顺序复用原公平临床准备查询，保留罢工、复工整理、休息和实际岗位覆盖的接单资格；不是在所有计划里挑最便宜方案，也不按病人收费、种族或院长正在选中谁换人。未确诊、没有实际准备意图、缺团队/通路/床位或已经保留完整用量的项目不成为这个建议。 若没有这种能接单的候选，但当前缺货事件仍有已提出罢工的参与者，改显示“补足这次缺货”，取原事件关闭查询中的各实际请求所需包数最大值为目标U。该查询只按原规则忽略本次抗议标记，不能因医护罢工就把真实缺包请求清掉；它只判断本事件能够关闭，不宣称人员已整理完毕或所有病例同时取得预留。没有真实请求时沿原规则关闭事件，不为建议造请求。

有就绪候选时U为它的原协议用量，复工分支时U为原缺货关闭的逐请求最大需要量；A为当前实存减所有有效预留的可用量，建议Q=max(0,U−A)，成本Q×SUP01单价。Q为0或两个真实分支都不存在就不显示付款按钮，不为库存低于自动触发线制造一个虚构病人。数量完整、现金与实体余量足够才可按建议正常购买；不够就解释真实钱/空间缺口，不把Q悄悄缩到一单不能开所需的部分量。玩家仍可在自定义采购中明确买其他数量。

普通经营的这笔手动采购不使用自动保留额B作禁止条件；付款预览同时列成本、付款后现金，以及低于日常保留额的事实。没有额外确认或资金圈存。若需社区援助，仍由原每日一次20包援助入口处理，普通购买不占援助次数。创作模式按当前现金实付与创作基金代付两栏预览，真实订单先付款再入库，不显示免费绕过治疗包。

建议说明定位当前候选并展示姓名与原医疗票号，如“按当前就绪队列，预计可继续这一项准备”。买入的是全院库存，不给这位患者专用预留或插队；临床阶段随后按原资源束规则重新核验、预约和领用。购入足量不代表已经到齐、开始治疗或治愈，期间其他真实条件仍可变化。 复工分支只说明当前真实缺货事件，不编造一位可立即治疗的患者；补足后仅按原规则关闭事件、每参与者一次减压及已罢工者30秒整理，必要护理不被打断。比如两个实际请求各需2/12包、可用5时，复工库存门槛为12，建议7包，不把两人的用量相加成并发保留14包。

按下采购动作时沿原输入规则捕获当前医院、数量与单价，处理时按原采购规则复核该数量、单价、当前现金/模式/容量并提交固定数量；单价有变化沿原报价差异规则保留意图并显示差异，不能悄悄改变金额。患者已转诊、别的组先取得资源或下一条建议改变时更新说明，不把已提交Q替换成新病人的用量，也不因原患者离院撤销一笔仍合法的共享库存购买。切医院或取消尚未提交意图沿原规则清除。报价/目标说明只属于只读视图，不保存临床目标或第二套C/R/T/B；订单和库存仍各由原交易、实物事实拥有。

条件性算例：普通A档需要1包、可用0、现金35时建议1包20币，付款后现金15；舒缓C档需要4包、实存10/已预留8、现金60时建议2包40币，实存12/预留8/可用4、现金20；手术难度3需要12包、实存5/预留0、现金150时建议7包140币，现金10。它们假设其余条件可就绪且未变化，只描述本单刚入库时，不保证本步开工；随后同阶段的自动补货、后续阶段的准备与领用各沿原规则发生。在创作模式同样7包成本140、现金25时，医院付25、基金付115、现金0，实存仍需真正从5增加到12。

SUP01.top_up_cues提供数量/成本与当前候选的短句，以及同次已付订单的纸箱回执：一包也认真让出数量标签的位置。这个姿态替代该次普通purchase_scene，不叠加第二次到货或庆祝；本次数量与代付来源仍取实际提交结果。成交订单保存当时的医院实付、直接代付和实际来源，历史回执不从当前经营模式重推，切到创作分支不重标旧社区援助。页面外不生成货箱、演员或运输任务；低动态只显示静态回执，读档不重播已成交动画，开包继续只在原Attempt真实领用时发生。

变更面是可执行的采购量建议、普通/创作付款差额说明及同次回执表现；不改价格、协议用量、库存容量、队列公平、预留、罢工、每日援助或临床成果。首候选复用已有缺货/Readiness查询，只在相关准备、人员/几何/预留状态变化时重取；现金变化只更新付款可行性，不每帧遍历全院患者和方案。读报价不下单、不消耗业务序号或抽临床结果。真实排序、按下到提交的并发、基金账目与正式本机负载仍须游戏运行验证。

## 23. 缺货时医护会抗议，也会自动复工

反应只来自真实缺货工作：医护当班、具有资格、其余资源可就绪，却因为本次需要的包数不足而无法开始。空库存但无人需治疗时不生气；没排班、在休息或不参与该工作的人不跟着抗议。引用原压力值，不增加生气条、忠诚度、工会或谈判系统，种族不决定是否罢工。

一次全院缺货事件从首个真实缺包阻碍开始。每名参与医护累计其实际被缺货阻碍的秒数，在60/120/180秒各加6压力，同一阈值只结算一次，每事件最多18。开始别的工作、休息或没有待服务病例时暂停累计；请求消失不伪造受阻时间。判断候选时忽略本事件的抗议标记，避免用“已罢工所以不算缺货”自我清除。状态页显示“缺包等待→准备抗议→罢工中”和当前原因，不要求玩家计算秒数或阈值。

累计受阻满180秒、压力≥50且仍缺所需物品时，医护提出罢工；下一安全边界停止接新的医疗任务并去休息区等待补货。已开工治疗、手术、术后转床以及当前承诺的护理和查房必须完成或真实交接；缺替班时继续必要照护，只拒绝新任务。罢工不取消已拆包疗程，不制造医疗事故、不锁门堵路、不带走库存。未罢工人员可继续有包的工作；无包项目暂停新接诊，实际诊断和生活服务仍可进行。罢工期间照常计薪与休息恢复。

采购后，若可用量足够覆盖每个当前缺包准备请求的完整需求（逐请求比较，不冒充全部并发预留），本次缺货事件关闭；没有请求时也关闭。等待者按原票号逐一重新预约，不能先到的拿走后又倒改已关闭事实。参加过本事件的医护各减6压力一次；已提出罢工者进入30秒自动复工整理，完成后按原排班和安全状态接单。正在必要护理中的员工无需离开患者演一遍罢工。后续新缺货是新事件，重新累计真实受阻时间，不能继承上一事件已满180秒的计时。

库存、阻碍、医护反应合在同一缺货卡，显示尚缺数量、补货按钮和预算原因；60秒首次提醒，临近罢工时更新原卡，不弹逐人确认。缺货动作围绕实际工作卡与尚缺数量展开：等待、准备抗议、罢工、复工整理分别有原状态与低动态姿态。休息使用真实可达的位置和已有家具，不把空包装变成可坐凳子；仍承担必要照护者不离开患者表演抗议，动作兼容九骨架；没有额外事件名额或永久关系惩罚。SupplyShortage保存缺货事件序号、每参与者累计受阻tick及已结算阈值；抗议/交接状态及复工截止tick只归Staff；读档不重复加压、扣货或复工奖励。

## 24. 轻松经营的信息边界

院长主要决定扩建、培养方向、接诊项目和环境风格。日常清洁、真实补货、维修派单、病例演出与实操成长按既定默认规则运行；不增加逐物件确认、逐患者配方或体型许可证。设施伸缩是真实占地，空间不足仍要改建；预览替玩家算尺寸，不替玩家消除空间约束。详细模拟条件用于一致执行和解释问题，不全部变成玩家面前的旋钮。

默认界面只显示当前主要问题及可完成的一步操作：缺货去采购、缺岗看招聘或班表、通路阻挡定位物件、设备故障看自动维修进度。每种实际原因合并一张卡，自动解决后收起。保留工资、评分怒气、医护培养、方案、排班、手术住院、装修、补助任务的完整功能；公式、统计分母、手动区域、研究树、排班格和多项状态在相应详情中按需展开。

只有六类医疗主体加研究台、装修工具台与两型电梯进入磨损、故障、保养派单。普通桌椅、灯具、门、垃圾桶、饮水和厕所、导诊屏与娱乐家具免维护，仍有真实使用与卫生来源；敲门等演出不损坏它们。清洁不会因此自动完成。新设备明确定义是否需要维护，未列入维护集合的物件不会偷偷出故障。

排班沿用能开院的默认模板，招聘预览附上可直接应用的班表建议；不代付招聘、培训或装修。工作经验自然提升能力，可选课程和带教用于更快成长。员工头像优先展示一个当前需要，详情再显示能量、劳累和压力的真实来源；自动长休和安全交接保留。新手按实际遇到的问题逐项认识系统，无限楼层、随机活动人数与独立医院保存保持原规则。
