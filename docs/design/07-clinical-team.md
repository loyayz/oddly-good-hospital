# 医生团队、治疗方案、手术与住院

版本1.97.0。本章定义医生和完整医疗流程，覆盖模拟规格中的通用员工规则。所有医疗、手术与麻醉表现属于玩具式幻想世界，数值用于游戏经营。病例无死亡、永久伤害或失败清档。

## 1. 医生的四个独立维度

医生拥有职称、能力、培养方向、性格，四者不相互替代。职称决定薪资和责任权限；能力决定可执行方案及实际效果；培养方向只是当前想提高的一项能力；性格影响合格方案中的偏好。同职称可以有不同长处，同种族可以拥有完全不同的性格。

全游戏的医护操作能力只有四种：诊断、治疗、手术、护理，均为0…5级，0表示尚未掌握。医生只有诊断、治疗、手术三条能力；护士只有诊断、护理、手术三条能力。基础医生为1/1/0，基础护士为1/1/0，手术在R34后学入门课。十个医疗专业继续组织房间、病症与机器，不各设一条技能，也不要求逐科拿证或限定医生只能学三个科室。医生的培养主方向只从本人三种能力中选择，更改不会清空经验。其余五岗位保留单一1…5岗位技能。

能力条的名称与一句用途读取clinical_abilities.work_summary。员工卡只显示本人三条；未掌握的手术写“尚未学习”，展开后再看研究、课程与岗位条件，不把十个医疗专业显示成待点亮技能。招聘说明使用研究和岗位的可读名称，内部资格代码不进入玩家提示。用途短句只解释原能力，不授予资格；是否能初诊、主刀、麻醉或查房仍由原岗位、职称和方案共同检查。

医生的能量、劳累、压力、休假与沟通沿用[诊室互动与员工休闲](09-consultation-wellbeing.md)。初诊和检查用诊断；所有门诊治疗和医生查房用治疗；主刀、麻醉与护士手术配合都用各自的手术；护士照护、转床、导诊与应急用护理。同名能力不混淆岗位：护士诊断用于检查，不代替医生初诊；医生手术用于主刀/麻醉，护士手术用于配合。一人不能同时占两个岗位。q_gp、q_tXX、q_surgery、q_anesthesia、q_test、q_ward、q_or、q_guide只是兼容现有调度的派生标记，不另存证书、第二套经验或外科/麻醉子能力。

| 能力 | 医生用途 | 护士用途 |
| --- | --- | --- |
| 诊断 | 初诊；诊断≥2且R11后可代做检查 | 诊断≥1可做已开放检查 |
| 治疗 | 所有已解锁科室的门诊、方案会诊与查房 | 不使用 |
| 手术 | 主刀或麻醉，另检查职称与方案难度 | 手术配合，另检查方案难度 |
| 护理 | 不使用 | 病房照护、转床、导诊、安抚与应急 |

## 2. 职称与晋级

| 职称 | 每医院日工资 / 招聘费 | 责任范围 | 晋级到此职称的条件 |
| --- | --- | --- | --- |
| 住院医师 | 140 / 280 | 已取得资格的初诊、门诊、基础查房；可接受培训和担任不占必需名额的手术观摩助手 | 默认起点，主方向至少1 |
| 主治医师 | 180 / 1,000 | 可担任普通手术主刀或麻醉医生，仍须具体能力合格 | 参与并完成20次就诊、主方向2、R11；晋级评估120秒，费用500 |
| 副主任医师 | 230 / 2,400 | 可担任复杂手术主刀，组织专科查房与带教 | 60次就诊、主方向3、诊断2、R11；评估180秒，费用1,200 |
| 主任医师 | 300 / 4,800 | 可担任高难度方案主刀；带教提供工作速度加成 | 140次就诊、主方向4、另一方向2、诊断3、R11；评估240秒，费用2,400 |

晋级条件可见，达标后玩家主动安排评估，评估必定通过，不随机卡职称。评估占用培训时段与研究桌，结束时职称改变、工资从该tick开始按新费率累计，不对当天过去时间补扣。正常模式支付评估费；研究援助不代付晋级。现金不足可以稍后晋级，不降级、不影响已有资格。

“参与完成就诊”在患者最终治愈离院时确认，参与初诊、治疗、手术、麻醉或出院查房的医生均可获得一次本人记录；同一医生在同一就诊中担任多个角色仍只计一次。单独参与方案会诊不刷实践或晋级病例。转诊只保留能力练习记录，不计治愈晋级病例。解雇后重新雇佣同一医生不重置记录，也不返还培训或招聘费。

标准招聘可按已开放职称和专业方向筛选：R11后可招主治，R34后可招副主任，主任需要医院已有一名通过晋级的主任后出现。展示确切职称、能力、性格、日工资和招聘费；没有隐藏免费高级医生。普通人类候选保底，能力与外观种族无绑定。

高级招聘为快速补齐成熟团队支付一次性成本，费用只取doctor_pay职称表，不按种族、性格、简历来源或额外技能暗中加价。以治疗主方向、已满足病例/实践门槛、从前一职称逐级培养且所有缺项都按未折扣课程补齐为参照：主治需500+400=900，副主任需1,200+600+400=2,200，主任需2,400+900+600=3,900，分别低于直接招聘的1,000/2,400/4,800。实操已掌握或R17折扣继续减少培养支出；两条路径到同一职称后日薪相同。培养仍需真实时间，招聘不赠本院履历、课程或晋级任务事实。已有招聘费为沉没成本，辞退没有回收套利。

标准医生主方向按职称为1/2/3/4，诊断至少1/1/2/3，治疗至少1；手术主方向需R34，其他主方向手术为0。同一治疗等级适用于全部已解锁科室的合法门诊设备，不为不同科室重学一遍。护士标准候选诊断1、护理1、手术0。入职能力按招聘卡原值保留，本院实践、晋级病例和课程从0累计，招聘不产生培训完成或治愈任务事实。

## 3. 专业培训与实践

医护能力有培训与实操两条成长路径。未学手术须先完成入门课；已学能力既可上课提早升级，也可在日常工作中自然提高。每人仅按自己的三条能力累计实践；门诊病例不分科累计，主刀和麻醉也共用手术经验。培训在研究桌进行，与研究、晋级评估互斥，每人同时一项课程。晋级认可两条路径获得的能力，不要求付费课程数量；工资仍只随医生职称或岗位变化。

| 目标能力等级 | 所需相关实践次数 | 费用 / 基础工作秒 |
| --- | --- | --- |
| 0→1 | 0 | 300 / 120 |
| 1→2 | 0 | 400 / 120 |
| 2→3 | 20 | 600 / 180 |
| 3→4 | 50 | 900 / 240 |
| 4→5 | 100 | 1,400 / 300 |

上表供医生和护士共用，护士手术0→1保留200币/120秒特例，其余查目标等级。等级2及以上须R11，手术入门须R34。R17将医护能力课费用与工作量减半，各向上取整；再应用学员课程工作量天赋并向上取整，人类为0.9。天赋不减学费，晋级评估不套课程折扣。医生导师须副主任/主任且该能力比学员高两级；护士导师须该能力高两级。双方实际共同工作才提供最多25%工作率加成，导师照常占班领薪，无导师也能学习。玩家日常只需选择一条能力并点击“培训”，详细成本与安排在同一预览中解释。

实践在实际完成时按原job_id记一次：初诊/检查记执行者诊断；门诊/医生查房记治疗，每医生每Visit最多一次查房实践；主刀、麻醉或护士完整手术协助记各自手术；护士实际照护、转床、纠正导诊、完整应急记护理。医生手术观摩须手术1，成功完整观摩记手术，中断不计。前两级课程无实践前置，手术团队不会卡在资格与病例之间。

实操自动达到2/3/4/5级的累计门槛为20/50/100/180次；高于1仍须R11，尚未解锁时保留经验。每方向累计最多180，不在升级时清零或扣除；等级取当前值与已满足门槛的最高值，不在高等级基础上重复加级。入职已有能力保留，本院实践从0开始；例如招来的3级医生需本院累计100次同方向工作才自动到4级，也可在50次后上4级课程。课程与实操都不自动提高职称。

被动覆盖、空等、走路和未完成动作不计实操；护士旁观不冒充完整配合。每原始工作对每位合格执行者只归入一种能力，不能把同台手术拆成主刀/器械/麻醉阶段重复记数。交接沿最大实际贡献者规则，手术三人分别按自己的合法岗位取得一次手术实践。合格完成失败治疗同样获得实操，取消或自然收尾不获得。

阶段⑨消费完成事实后提交成长，下段工作使用新能力，已开始Attempt不重算。课程固定报名能力和目标等级，但待桌、暂停或进行中的课程都不阻止已经取得的实操成长。同一归并阶段先处理真实课程完成/主动取消，再按累计实践取最高已满足等级；等级只取最大值，不在已升高的级别上额外加一级。若此时仍有未完成课程且本人已通过实操达到或超过其目标，原课程以“实操已掌握”终结，按原未完成工作量比例退还实际学费，释放导师安排与桌位，不要求院长手动取消。不自动改报更高等级或扣新学费。

例如治疗1已报名2级课程、尚余原冻结工作量的一半时，本院同方向实践达到20：自动到2级并退原实付学费的一半；学习记录写实操升级、剩余课程已退，不产生course_completed。若课程工时已在同一阶段真实完成，则先正常结课，无剩余退款，再按实践取最大等级，不重复升阶或重复发完成。取消与自动终结共用原任务唯一终态和退款凭据；不足一币的退款沿原规则向下取整。手术0仍不能靠经验绕过入门课，R11条件不变。

成长事实记录course/practice来源，实操不伪造课程完成。Q13要求三名在职医生各有至少两项本人能力≥2，门槛由该任务metric_parameters持有，Q26仍只统计医生实际完成课程；已由实操掌握而终结的课程不计。无可培训医生不投放该委托，已有委托若目标失去可行性可无罚放弃。职称逐级评估，第二方向指本人另一项能力。

培训遇到换班或设备坏掉保存剩余工时，回到培训时段接续；暂停、存档和移动研究桌不能刷课程完成。取消退未完成工作比例的学费，已获得等级和评估结果不退款。

## 4. 六种医生性格

性格在招聘时可见、长期保留，可与任何种族、职称和专业组合。它影响选择偏好和医患文字与沟通动作，不秘密修改实际成功率，也不允许越过资格与成功率底线。

| 性格 | 更可能选择的合格方案 | 现场表现 |
| --- | --- | --- |
| 谨慎 | 预测效果较好、恢复负担较小的方案，愿意多花时间 | 再核对一次大号清单，满意后认真盖章 |
| 果断 | 能有效解决当前复杂情况、总治疗周期短的方案 | 利落翻到方案页，给病人一个明确手势 |
| 好奇 | 在效果相近时选择自己较少使用的方案 | 掏出小笔记本记录；不会拿未学会的手术试手 |
| 温和 | 舒缓、安抚、住院负担低的方案 | 沟通与舒缓准备更仔细，仍按实际回应和已选方案执行 |
| 讲效率 | 等待短、占用资源少、周转快的方案 | 把号单排得整整齐齐 |
| 团队型 | 当前有熟练同事配合、交接顺畅的方案 | 向下一班同事递一张清楚的照护卡 |

### 4.1 看得到的初诊习惯

六种diagnostic_work_styles只替换FUR02工作时的通用次要道具反应。谨慎逐一核对、果断明确指向、好奇展开观察框、温和摆好软角纸签、讲效率对齐症状卡、团队型对齐采集箭头；共同的真实采集动作照常进行。医生的性格可在无对白、静音或低动态时辨认，不另开头顶说明或性格台词。

来源是已经开始的初诊服务中当前真实医生的DP性格，不是患者、推荐医生或员工卡的选择。检查包括医生代做和护士执行，均使用原通用检查表现。待诊、到岗路上、条件暂停、工作完成和证据不足继续使用MP01既有状态；尚未确诊时只有通用问号与采集图符。温和的纸签不产生安抚，好奇的观察框不取得额外证据，讲效率的手势不增加工作率，团队型不自动拉来护士。

合法接续段更换医生时，以新实际医生重新查询动作，原服务余量、证据和付费凭据继续；读档或重新进入视野直接取当前真实阶段，不重演开场。没有专用定义时可在同一名额内用原通用次要反应；专用与通用都占同一个名额，不叠播。名额不足或次要资源未就绪只保留主操作，不能换一种小戏绕过预算，也不能等待动画才开诊。动作与其他医疗次要小戏共用3组可见预算，排队或不可见初诊仍按完整规则运行，不限制诊断台数量。

同一病例可能出现这样的差别：谨慎医生选择较慢的舒缓方案；熟练而讲效率的医生用普通方案达到相近效果；外科专长医生遇到复杂病例且手术、床位齐备时倾向专科手术。性格偏好不能覆盖患者当前路线、资金、合资格团队或床位不足的硬条件。

## 5. 一种病症，多种方案

154种病症均有“常规门诊”和“舒缓门诊”两种方案；其中24种另有专科手术方案，总计332个疾病方案定义。原有488条种族—病症—机器绑定继续提供门诊的体型、症状和治疗表现；手术另用SurgicalAdapter引用相应病例绑定，不用门诊机器替代手术设备。方案不新增病种或重复计算图鉴病例。

| 方案 | 基础效果A/B/C | 工作量与耗材 | 收费与住院 | 关键取舍 |
| --- | --- | --- | --- | --- |
| 常规门诊 | 92% / 88% / 84% | 病例演出工时×1；治疗包1/2/3包（采购20/40/60币） | 实际门诊主体使用费+成功时原治愈费；不住院 | 快、便宜，对复杂病例把握较低 |
| 舒缓门诊 | 97% / 95% / 93% | 病例演出工时×1.8；治疗包2/3/4包（采购40/60/80币） | 主体使用费+成功时治愈费×1.1向上取整；C档需180秒住院观察及60护理床费用 | 更稳但更慢，占用医生与可能的床位；舒缓准备表现包含在该工时内 |
| 专科手术 | 各手术定义96%基础值 | 手术120/150/180秒；每次治疗包8/10/12包（采购160/200/240币），按手术难度 | 手术台使用60+护理床60；成功时治愈费×1.8向上取整；恢复180/240/300秒 | 复杂病例效果好，需要两名医生、手术护士、完整设备与床位 |

常规/舒缓取医生治疗能力：舒缓A≥1、B≥2、C≥3；常规A/B≥1、C≥2。手术难度1/2/3要求主刀职称≥主治/副主任/主任、手术≥2/3/4；麻醉医生职称≥主治、手术≥2/2/3；护士手术≥1/2/3。角色、资格和研究全部通过才计算设备发挥率。两名医生与手术护士互异，另有病房护理覆盖人员。

手术只购买一张整合手术台，麻醉云朵机、监护与器械助手随台提供。Es=该台升级级别×三名实际医护手术发挥率的平均值。成功率=clamp(0.96+0.015×(主刀手术−所需等级)+0.005×(麻醉医生手术−所需等级)+0.01Es+0.01×舒适等级−0.03×主刀低能量−0.04×术台低维护+重试加成,0.70,0.98)。工时=基础秒数÷(1+0.05×(主刀手术−所需等级)+0.1Es)×(1+0.003×主刀劳累)×科室专长倍率，最后向上取整到tick。三人都须合格，不能用一名高手替代缺员；性格不直接改概率。

手术护士在原30秒准备窗口内完成8标准秒器械核对，使用手术能力工作率与适用的or_assist天赋；全体到齐且核对完成才启动Attempt。准备记录随原ClinicalPreparation保存，过期释放且下次重新核对，不收耗材、不发实践。天赋不直接加速整台手术，护士手术能力通过团队发挥率影响临床效果。递接演出服从已承诺手术阶段，不另增动作任务或重复经验。

沟通只发生在开术前准备，不增加已承诺时长；麻醉医生和手术护士均须覆盖全过程。设备等级、团队能力、Es、结果、工作量与恢复基础量在Attempt开始冻结，之后换班、暂停、课程结业或维修不能重抽或重算。住院阶段另按本床实际设备和护士的当前覆盖段计算恢复工作率，不改变已承诺恢复总量。

有手术方案的病症可有“普通/复杂”就诊标签：普通占75%，复杂占25%。复杂不是新病种，常规成功率减0.18，舒缓减0.08，手术不减；先施加修正再夹限。只有R34完成、该种族至少有一个预测成功率≥75%的完整可执行方案时，复杂标签才参与生成；接诊页可关闭复杂病例。初始病例、教程和未开放手术阶段都使用普通标签。此比例不提高总来客数。

两次真正治疗尝试的上限保留，可在第一次失败后换方案；同一Visit不再收职称初诊诊费或重复已完成检查，新一次实际完成的治疗仍收对应主体使用费，治疗包按新Attempt领用，不重复扣采购款。搬移、故障延后、换班和暂停不算新尝试。手术失败没有随机死亡和永久伤害；手术完成先进入恢复，再决定第二次治疗或友好转诊。

## 6. 医生如何选择方案

正式诊断完成后，进入基础8秒方案会诊，实际按劳累与沟通修正、最低4秒，由具备治疗入门能力的当班门诊医生完成，患者卡保留初诊医生与负责医生。会诊不额外收费。候选先过滤：病例适配、已解锁、负责医生治疗能力、执行团队资格、路线、关键设备、床位、患者标签与预测成功率底线。常规/舒缓用该负责医生的实际能力；手术允许推荐给当前或下一班的合格外科团队，但负责医生本身治疗能力必须≥2。缺资源的方案仍显示并解释，不进入自动评分。

会诊可以复用初诊台，或该病例门诊机器的患者与医生操作区；都独占该服务位实际会诊工时，按诊室互动规格计算。没有机器也可在初诊台推荐已具备完整路线的手术方案。初诊医生治疗能力合格时直接接续，否则重新排队由当班具备相应治疗能力的医生会诊。C档舒缓方案额外要求R33、兼容床位、护理与查房覆盖；只完成病症研究不会绕过住院条件。

自动评分固定为：成功权重×预测百分数−时间权重×预计总用时/10−负担权重×方案负担值+熟悉权重×该医生该方案经验档+探索权重×未使用标记+协作权重×完整团队标记。方案负担为常规0、舒缓1、手术3；经验档min(5,已完成次数//5)；预计总用时含排队、治疗、恢复，不含未知未来事件；其余标记0/1。六组权重在内容目录中。相同得分按预测效果高、预计总时长短、方案ID排序，无隐藏重抽。

“完整团队”取当前已在岗、能在同一可用时窗执行的团队为1；只在下一班能凑齐时为0。门诊也按实际负责医生与可用设备计算，不永远填1。手术团队在当前或下一班的候选中按可开始时间、预测效果、员工ID选定；同一员工不能占两个岗位，不能拿分别最优却时间不相交的医生拼出虚假的成功率。预计时间用同一排队与排班投影，床位预估以其已承诺恢复余量和下一次查房覆盖为准；无法给出有限预计值的方案不参与自动选择。

医院策略提供“医生自主”默认、“稳妥优先”和“门诊优先”。稳妥优先先取成功率最高、差距≤2个百分点再按性格评分；门诊优先只要有≥80%门诊方案就先在门诊内选择，否则允许手术。患者详情可手动从合格方案中指定，预览效果、总时间、所需团队、收费、成本与床位；无资格或不符合底线的按钮不能硬选。

选择时记录plan_id、来源（医生自动/院长指定）、理由、决定医生、预计执行团队与计划修订号；真正开始前按执行者和设施重新检查效果与资源。效果提高或下降不超过5个百分点、仍满足原75%底线且方案有效时，更新实际报价后接续同方案。低于75%底线、下降超过5个百分点或原方案失去研究、适配、资格、合法路线等必要条件时，按以下来源处理，不能静默接受显著变差的旧报价。

- 医生自动：生成至多一项重新会诊，仍由实际到位且合格的医生执行原会诊工作、使用现有方案策略；不弹院长确认。完成后替换原推荐与理由，等待同一患者原票号继续，未开始的资源预约全部释放。没有合格候选就显示缺项并等待，条件恢复后才会诊，不为了重复展示缺项反复做8秒会诊。
- 院长指定：保留指定plan_id，患者卡显示一次“方案条件变化”，可在新效果仍合格时选“按新效果继续”，或选择其他当前合法方案、“交给医生”。不自动改成手术、较低效果或另一种消耗；交给医生后恢复原自动流程。等待期间不锁医护、机器、床位和治疗包，原候诊、弃候及友好转诊边界继续有效。

单纯资源正忙、短时缺货、预约未到齐或已承诺床位尚未腾空，属于等待同一方案的资源，不等于丢失资格。保留方案与原票号，显示原缺货/排队原因，不为这些波动反复会诊；资源到齐后照常重查真实效果。重评期间进一步变化合并到当前一项会诊或当前一张确认卡；同一已处理报价不重复发起。新决定完成会诊或经院长确认后才更新比较基准；实时面板的当前预估不覆盖这份基准，查看页面、相同查询或读档都不推进修订。医生策略改变影响下一次实际会诊，不覆盖院长指定。

大院等待查询可以复用可证明仍成立的必要缺项，依技术规格§6在相关真实变化及原时间边界复核。该依据只属于查询缓存；方案重评、会诊工作、原票序与候诊累计仍由当前PlanDecision/ServiceSession/QueueTicket拥有。缺货恢复、排班补齐或兼容床释放后回到原调度机会，实际资源束重新原子取得；依赖不足的条件保持原完整查询，不把性能优化变成延期治疗或缓存批准。

PlanDecision只保存当前推荐、来源、待重评原因与已处理报价修订，不累积会诊历史；实际工作仍由原ServiceSession拥有。每次真正开始时由TreatmentAttempt唯一承诺结果、时长、治疗包领用数量和最终收费；会诊、报价变化和重新确认不增加尝试、收费、耗材或实操经验。已开始后的换班、升级、故障接续与读档继续原Attempt，不再进入上述重评流程。

### 6.1 看得到的常规与舒缓

当前已开工门诊Attempt引用的协议拥有presentation_mode：常规为standard，舒缓为gentle。准备更仔细、工具动作较轻是本疗程表现，不是新增临床阶段。它包含在原1.8倍工作量的准备/过程内，没有附加8秒护士安抚、额外医护、第二次治疗包领用或另一份成功率加成。怒气继续取实际临床阶段、真实沟通与独立护士安抚；舒缓小戏不提交PatientAffect或“护士帮助完成”事实。温和医生可以更偏向合法安抚回应，但已选常规仍按常规操作，不由性格偷偷改方案。

舒缓的患者主演出仍使用本病例的症状、操作目标和合法身体：准备更清楚地核对与安顿原工具；过程中对同一目标使用较小幅度、分段衔接的操作；高潮仍一次；安全收尾继续原退出顺序。不是把常规整段动画全局减速，也不把患者没有的鼻子、书页或手加进来。工作量、耗材、概率、费用与C档必要恢复全部沿原冻结参数，当前机器小戏不决定效果。

三种门诊主体的protocol_variants在gentle模式下替代同台专业working_variants的次要小动作，按当前四段选一项：整复台的备用夹先整理自己的软面，调理舱的节拍球礼让半拍，奇想台的页签先轻轻抚平自己。主病例动作优先，高潮时次要道具定格；未获原3台动态名额时保留相应静态姿态。standard继续原专业动作，新增主体没有对应方案小戏时保留本病例主演出与实际方案文字。诊断台、手术台和护理床不套用这组门诊准备；舒缓C档在床边继续原180秒恢复与护理/查房状态，不重演机器前奏。

当前表现取Attempt引用的方案/协议及本档声明的内容版本，不取玩家正在修改的下一次PlanDecision。暂停直接沿原held_scene停在安全姿态；恢复从当前真实完成量继续，切层和读档不重播前奏。完成操作后改由原clinical_results/result_scenes显示真实下一步；gentle不提前显示成功颜色、康复章或移除症状。

变更面为两种门诊协议的表现标识、三种设备各四段的舒缓次要小戏及低动态姿态、当前疗程的可读提示；患者原绑定、专业工作目标、医生资格、概率、收费、领包、护理、真实安抚与共享表现预算保持原合同。当前模式由原Attempt/协议投影，不存第二套疗程、进度或医护任务。四段取整方式与实例由制作规格拥有；身体轨迹、安抚边界、读档和本机负载仍须正式资源及游戏运行验证。

## 7. 手术室与住院部的建设

## 8. 手术、住院与故障恢复

手术路线：会诊确定 → 候手术 → 预留兼容床位 → 团队准备 → 手术 → 15秒苏醒演出 → 护士陪同转床 → 住院恢复 → 医生出院查房 → 治愈/重试/转诊 → 离院。手术前必须同时取得手术室、整合手术台、三位当班工作人员、适配床和床区护士覆盖，不先做完手术再找地方安置。

预留先属于ClinicalPreparation，实际开术才绑定TreatmentAttempt，候人超时不增加治疗次数。主刀和麻醉医生在苏醒演出结束后释放；手术护士完成陪同转床后释放。手术期间床区必须由另一位护士覆盖，不能把正参与手术的人同时计入病房护理容量。每位护理护士只能归属一个病房；同病房多名护士按床位ID稳定分配，最多各8床。查房医生须在预计恢复结束后的300秒内有已排定的合资格覆盖，或开放合资格门诊医生插入查房，才视为路线完整。

床位预留属于该次治疗尝试，排队时不长期空占：只有完整团队可开始且距离开术≤30秒才原子预留。开始前病人和团队走到准备位，30秒未到齐就释放资源回队列，原票号保留。手术一旦开始，床位预留保留到转入或安全转诊；护理床主体与覆盖护士同样纳入可用性。不被新患者抢走。手术队列按原票号与优先照顾公平规则，不按付费高低插队。

成功结果在手术开始时承诺，手术结束暂记“治疗完成，恢复中”。手术与苏醒实际完成后收手术台使用60；实际恢复、护理及出院查房均完成后收本次护理床60，失败后完成的必要恢复同样计费。只有成功病例同时结算治愈费；失败不收治愈费。舒缓C档同样在完成观察及查房后收护理床费并判断治愈结算，不能治疗结束收一次、出院再收一次。医疗故障或缺员导致尚未完成的服务安全转诊时，该未完成项目为0；已经完成的项目保留。

恢复工作量仅在床位有效、对应护士有覆盖时推进；每位住院患者至少有一次8秒护士照护、最后一次10秒医生查房。医生查房要求诊断≥2且治疗≥1，可由排班“住院查房”的医生或玩家允许的当班门诊医生插入。恢复完成但医生尚未到达时标“等待出院查房”，不偷偷释放床位。夜间、未排班和读档都不自动跳过护理。

手术中设备抽中故障只记pending_failure，当前手术安全完成、不得重抽结果，之后关闭该室新手术；手术中主刀/麻醉/护士不会被调走处理走廊事件。护理床故障保留当前病人的占用，暂停后续恢复工作；护士可免费搬到另一兼容床并保留剩余恢复量。没有备用床时等待维修，120秒无进展提供并默认执行友好外部照护转诊，退还未完成照护相关预付项（基础规则无预收所以退款0），清理全部预约，不治愈、不发成功任务奖励。患者始终安全。

### 8.1 护理覆盖与床边工作

护理覆盖来自实际到岗：q_ward护士当班、归属此病房、人在房内、可达所辖床边且护理床主体可用；在同房巡视、进行床边照护可以提供覆盖；接班者正在工作台核对时尚不计入覆盖，原负责护士只在实际仍在房内且未进入离岗状态时保留覆盖至真实接班完成；休息、冻结、院外、去别层以及参与手术/导诊/其他房间工作不能覆盖。每护士同时分配的已占与承诺床最多8张，床位ID稳定排序；一床一个覆盖者，两个护士围着同一床不使恢复加倍。跨房支援先交出原覆盖再真实走到目标病房，排班板展示途中空缺，不能只改所属ID就远程护理。

住院恢复保留Attempt承诺的标准工作总量，当前床的Ew=床升级级别×实际覆盖护士的护理发挥率，每模拟秒推进1+0.15Ew标准秒；基础床为1倍。覆盖护士更换、真实完成能力升级或转床后在下一安全覆盖段冻结新速率，已做标准量不重算，暂停/读档保留小数余量，无覆盖或床故障时推进0。访客与床边表演不加速。每WardStay仍须一次8标准秒主动护理，使用护理能力工作率；同房照护一床时可覆盖其余床，但不能同时做第二件主动工作。

病房主动工作先处理真实安全转床，再做尚未完成的床边照护；同级按入床tick、Stay ID排序。最后10秒出院查房必须同时满足恢复余量为0、主动护理已完成、患者在有效床位及有合格医生，不能只看倒计时到零。查房医生实际到床边执行，同一医生只查一床；原门诊临床安全锁优先，插入查房在下一段可用工作窗口发生。失败尝试也需要安全恢复和查房，之后按原失败结局重选方案或转诊，不能因为表演了告别动作就计治愈。

接班护士已完成本工作段的工作台整理，再到同一病房的床边照护卡旁；两位具备覆盖资格时对同一组实际覆盖床位进行一次5秒交接，最多8床，不逐床重复5秒。交接开始冻结本组床位，新床位承诺等待该次交接结束；原护士在这5秒保留覆盖，完成tick原子转给接班者。接班未到时原护士不无限超班：完成正在执行的8秒照护或真实转床安全段后离班，记录相应补休；后来到岗者独自核对原记录5秒再建立覆盖。空缺期间恢复暂停，既不跳过交接也不重置患者进度。正式休息与加班计薪沿原规则，交接不是额外实践事件。

WardStay的无进展计时只在恢复量减少、主动护理实际推进或查房实际推进时更新；走路、改派、访客到场、改开关或反复换床不重置。故障阻碍120秒、缺员阻碍120秒提示/300秒转诊沿用原规则；多个阻碍同时存在取先到的适用转诊期限，来源改变不能把持续无进展清零。护理已完成标记、工作余量和最终结算凭据独立保存，读档不重放照护或发第二份费用。

### 8.2 陪诊与探视的真实到院过程

普通患者入院后，用既有arrival流为本次Visit抽一次25%的陪诊需要；教学病例也遵守同一需求，不专门补演员。需要陪诊才保留一份院外请求。陪诊者默认采用与患者同种族的独立家庭成员身份，其性格独立，熟客保留已建立的亲友身份；相同种族不等于同一个人。ST04的宽座停留只计真实院内陪诊者；奖励是这户家庭提供的大幅照片，照片里的亲属不作为角色出现在医院边界或窗外。真实来院的家属始终使用自己的身体、入口路线与座位空间。

陪诊请求只在关联Visit尚未离院、存在本人的可达、兼容且不抢患者的公共等候点时入院；从1F入口实际行走，不能生成在楼上床边。按请求tick与Visit ID派入，在模拟阶段③每5秒重查，按队列最多进入一位；陪诊可在所有班次进入，新的床边探视只在早/中班，不另增患者机会。停止新接诊不拦截现有患者所需的陪诊或合格探视。容量或路线不足保留轻量请求，不先创建Actor和一排院外实体；关联患者已终结就取消。陪诊者等候于当前服务附近的公共区，不进诊室、手术室或挤占床区；患者完成全部就诊后家属一起按真实路线离开，不再因“热闹”继续闲逛。

住院早/中班各提供一个探视窗口，意向抽样沿用arrival流并按Visit ID排序；每个Visit在当前医院日每窗口至多评估一次50%的家属探视意向；只在本次实际入床后的剩余窗口评估，晚班不补，读档与换床不重抽。已有陪诊者则使用同一身份，不能另造一位家属；没有陪诊者时只生成关联本患者的探视请求。本次Visit最多同时一位普通访客。患者卡默认允许已产生意向的探视，可选择暂不接待；拒绝取消尚未入院请求、在院者安全离开床区，不扣心情、不改变评分和故事奖励。没有意向时显示家属本班未提出探视，不提供邀请或重新抽取按钮。

开始前必须有床侧合法访客站位或兼容座位、真实出入路线以及护士/医生操作区仍可用；不足时显示“床边暂时没有安全探视位置”，医疗照常。实际到床侧且仍在早/中班窗口才开始30秒探视；到达太迟则结束请求，不在下一班补一场。开始时消费该窗口，30秒从真实床边相聚起算，走路和院外等待不算停留。已开始探视可跨班正常收尾；该患者上一场未结束前不评估下一窗口。每患者每日最多两次，已有在院家属转换VisitorStay.purpose时沿用同一Actor与容量。

## 9. 排班与交接

一天1800模拟秒，分早班0…599.9、中班600…1199.9、晚班1200…1799.9。医生排班按这三个600秒（8医院小时）班次循环，可编辑今天剩余班次和后续日模板。每班只能选门诊、手术、查房、培训或休息；门诊可关联最多三个已开放科室的服务池；这是工作范围，不是技能栏，手术可指定房间或手术池。至少一班休息，连续工作不得跨日超过两个班次；界面同时检查晚→早→中的跨日连续工作。休息班仍领工资。

初始增加一名轮转医生，共三名医生、七名员工：A早初诊/中休息/晚初诊；B早治疗/中治疗/晚休息；C早休息/中初诊/晚治疗。三位医生的诊断与治疗均为1，C在初诊与门诊间轮转，所有模板均通过跨日休息检查。初始招聘1,480、全员工资740/日，预设建设仍12,720，另采购60包支付1,200后余款10,600。空地模式可自行招聘，显示未覆盖的诊疗班次。

医生上班前检查资格和岗位容量；没有工作可做是带薪待岗。排班网格同时显示本班每科覆盖、每台手术的主刀/麻醉/护士缺口、住院查房覆盖和培训桌冲突。护士仍按工作池和能量轮换，但开始手术前必须能锁定一位合资格护士完成整个预计过程。支持复制模板、对调两个班次和恢复默认模板，批量编辑一次确认。

开术前计算所有成员的连续可用时窗：同一手术池的相邻工作班可以连用，最长400秒；手术转门诊、查房、培训或休息都截断时窗。主刀/麻醉须覆盖预计手术、15秒苏醒及20秒缓冲；手术护士另外覆盖预计转床路径。剩余时窗不足就等待下一次完整窗口，不能因为180秒手术加苏醒超过单班而使高难度方案永远无法开术。普通门诊服务加10秒缓冲不足时不接新患者，相邻相同门诊池可延续。

当前诊疗、手术和转床完成前不强制换人，计划修改对当前安全任务结束后生效。手术不能中途换主刀或麻醉；正常换班只交接尚未开术病例。查房完成当前10秒工作再换班；培训按tick保存剩余工作并释放桌位，待办队列不复制。术前还需满足每位成员预计完成任务后能量≥15，不把“当下有能量”当成可以接任意长手术。

事件等原因造成不可预期加班时，完成安全任务后优先补休，至少补回跨班占用的秒数且能量恢复到90；下一任务等待或由其他医生承担。跨日加班记录保存，不借修改排班跳过补休。患者已承诺的治疗不会因晚班结束重做或收费两次。医生暂不可用时重算预计等待；没有合格医生的项目暂停新预约，现有患者按正常等待/转诊规则处理。

能力、病例和计划经验均为该医生的累计事实；计划经验按plan_id计实际完成的治疗尝试，不含会诊、等待和重复载入。晋级病例集合只在活跃Visit中保留参与者；病例完成后原子更新医生总数与Visit结算凭据，不无限保存全部历史就诊ID。排班只保存今天的覆盖修改与循环模板，过去班次折成统计；补休债务独立保留。

恢复世界先重建全部预约和排班，再验证每床最多一名患者、每员工一项当前任务、主刀和麻醉不同、一个病例最多一份活动Attempt费用快照，诊断服务与各费用分项均有唯一入账凭据。缺失方案/适配仍按内容包兼容规则阻止覆盖加载。正在进行的方案保留开始时数值，新增或调整方案只影响后续会诊和新尝试。

临床设备按attempt_id与主体equipment_id去重：一次手术只在首次实际操作时给整合手术台记一次使用；护理床每次真正入住记一次，同一尝试移回原床不重复。医疗类别当前每日磨损为0，长期占床不按采样、查房或主动护理追加使用次数；内置麻醉、监护、器械与照护卡不单独磨损、故障或派工，护理床主体故障统一暂停恢复并沿原120秒维修/转诊规则。

手术与住院的病例结果、费用、总工作量和恢复总量只由TreatmentAttempt保存；门诊/手术执行会话与WardStay分别保留自己的剩余阶段工作，避免再次收费。休假、怒气和装修不会打破这些安全锁。

## 11. 培养目标、上课与带教

医护详情各可固定一个培养目标：医生可选本人能力下一等级或下一职称，护士可选诊断、护理或手术的下一等级，不显示医生职称按钮。目标展示已具备条件、还缺的实践、研究、学费、预计占班及接诊缺口，不预占研究桌、不自动报名、不赠资格；已有课程继续显示在同一处。更改目标只改提示，不取消正在进行的课程。可先补实践、安排替班或改学别的方向，目标没有截止时间。

报名时重查研究、当前能力、累计实践与现金，冻结方向/目标等级、本次费用、标准工作量、R17与适用种族天赋，一次付款创建唯一培训任务。等待研究桌和培训班时保留已付任务；无桌、停机、无路或学员仍在安全任务中时列出原因，不推进工时。缺桌报名须明确选择保留已付待办；晋级评估保持自己的费用，不套能力课程折扣。医护各只选择本人三种能力；一个人同时只有一项课程，实操照常按§3成长，已掌握目标则终结剩余课程并退款。

研究桌只有一个主工作位，同一时刻研究、学员或晋级评估只占一种；带教另需旁侧可达且不重叠的真实站位，按双方身体检查，不能把两人叠在桌边。跨楼层先走到位才计工作。自动分配在空闲时按任务进入可执行队列的序号及ID选择；当前任务不被新报名抢断。玩家可以指定桌或保持自动，指定桌不可用时说明原因，只有明确解除指定才改派。

带教为可选安排，导师与学员须同岗位、同方向且满足§3能力条件，并具备培训时段、能量与安全空闲条件，不能同时指导第二项课程、研究或看诊。护士排班增加可安排的培训时段，仍先满足必要病区覆盖、休息和应急安全任务。导师缺席时学员正常继续，到位才加速，离开立即停止。换班、休假、故障、改建与读档保留同一余量，不反复乘0.8。双方按各自原规则累计能量和压力；医生另计劳累，护士在此公式劳累倍率取1，不为护士复制医生劳累系统。加速最多为学员基础工作率的25%，且受实际导师工作率限制。

具体以报名后的标准工作秒为单位：学员独学速率为1/本段学员劳累倍率；共同带教速率为独学速率＋0.25×min(独学速率,1/本段导师劳累倍率)。每段从开始或恢复时冻结劳累倍率；短暂停课不重设总量。原120标准秒课程前60秒独学、后段双方倍率均为1时再需48秒，共108秒；不能在导师最后到场时直接将余量减为原总量80%。取消退款按剩余标准工作量/冻结总量乘实际学费向下取整，带教挣得的进度不退回；原课程的取消退款与真实结课增级/完成事实互斥，独立实操成长可同时触发其未完成课程退款，但不能冒充该课程结业。

课程中途辞退学员，在其现行安全任务结束的离职边界取消课程并按同一规则退款；导师离职只移除辅导安排。研究桌搬迁暂停任务，完成搬迁或取消改建后重新找站位；任务归属始终在学员，桌上不复制另一份课程进度。自动带薪长休不被培训占位绕过，休假结束后才重新参加学习。

本课程记录各导师实际贡献的辅导工作量；只有贡献大于0且课程最终完成，才可产生该导师的首次有效带教事实。挂名、刚分配尚未到场、已取消课程均不算；换导师不抹掉前任的有效贡献。课程结算后将贡献折为成长凭据并释放临时明细，已离职导师只留下历史署名，不生成返院角色。

## 12. 医护成长的小片段

6种成长片段分别由首次能力课程完成、首次将第二项能力升到2级、首次成功完整手术观摩、首次有效带教课程完成、首次晋级、首次主刀成功并完成住院结算触发。growth_moments.roles声明适用岗位：课程、第二项能力与带教三种同时适用于医生和护士，观摩、职称与主刀三种只适用于医生。它们引用实际医护与事实，可在员工履历和院史中看到姓名、方向、医院日及当时搭档；不把招聘时已有等级写成本院成长，不给护士虚构医生晋级，不把失败或中断观摩写成成功。


六种growth_moments的小动作与低动态姿态直接由目录生成。能力贴纸、并列能力卡、观摩记录、带教批注、新职称徽记和团队卡分别对应真实成长来源。初学者动作认真核对，不用举错标牌或笨拙操作贬低低等级医护；手术团队卡是实际身份头像的记录排版，不假装大家离岗拍过合照。

每位适用医护每片段最多一次，按实际完成事实去重；同一事实符合多个片段时全部留下文字，仅按片段ID选择一个现场动作。动作最多4秒，只有本人空闲且没有待接服务时可播，1秒内响应叫号；必要护理与床位覆盖优先，忙碌时直接保留文字，不积压将来补演。模型只是表现道具，不进入库存；不新增现金、实践、技能、关系或压力奖励。低动态以图标和文字替代动作。角色种族只决定身体适配，不决定哪个片段发生。

第二项能力达到2级可来自课程或实操，按该医护自己的三条能力从少于两项≥2变为至少两项≥2的实际变化判断；录用时已达标不立即补发本院成长片段。实操终结未完成课程只可能产生其真实能力成长片段，不产生第一张结课贴纸或导师完成。合规社区研究与实操成长也可留下真实纪念，不以是否支付研究费或学费作为统一成就条件；自由模式仍按原规则限制现金奖励，课程原收费不变；同源片段和纪念卡继续合并，不弹多份庆祝。

培养目标、导师安排、课程剩余量及退款凭据沿原任务保存；每位医生和护士保存本岗位适用的已发生片段ID集合，院史只保存既有上限内的摘要。片段集合不承担技能或病例计数，临床结算仍是唯一事实源。目录可新增片段定义，但新增定义不回扫全部旧履历补奖或伪造旧片段。真实课堂调度、带教站位、跨层到场及工作率在实现后验收。

## 13. 医生办公室与护士工作台

医生办公室是4×4起步的员工专用房间，至少一张SE05医生办公桌，开局可建。办公桌2×1格、300币，包含一个实际办公座位；多个医生可轮流使用，可加桌提高同时办公能力，不要求每人一间。它是病例整理、上岗交接和空闲待岗的地方，不能接患者代替初诊室、替代研究桌或隔空完成查房。研究和付费课程仍使用原工作地点与课程规则。

SE06护士工作台2×1格、300币，开局可建，可放在病房内的合法工作带或相邻员工工作角落，不新增护士站房型。每名护士按任务所在层自动选可达兼容工作台；病房必须有同层且可达的护士工作台才能新增床位承诺，可以由多个相邻病房共用。护士在这里查看真实床位待办、交接及待岗，实际护理、转床和检查仍去相应地点。工作台界面聚合原WardStay与护理工单，不复制另一份病情或护理进度。没有病房时也可放在门诊员工工作角，供诊断护士使用。

两种设施按FF06核验主体、实际办公姿态/操作位与退出路线。医生桌使用seated_or_rig_equivalent，护士台使用standing_or_rig_equivalent，由九骨架姿态映射提供对应承托和工具位置；使用者的有效身体包络不因坐姿或站姿自动缩小。FF06保留桌台基座，升降台面与附件留在登记包络内，操作者区域单独占地，自动调节桌面与承托；三格员工不能隔墙操作。办公位一次一人，内置座位计入该操作者区域，独立椅子不能叠放进内置办公座位；护士台可采用站姿或对应身体的稳定承托。它们属于日常工作家具，免维护、无随机故障和耗材，不增加到六类医疗机器中。患者和普通访客不使用办公位，也不穿过员工专用房间当捷径。

医护在每段连续临床工作开始时自动去相应工作基地完成6秒上岗整理；班次相邻且岗位连续时不重复，休息、休假、培训或离院后开始新的临床工作段才再次需要。同一员工只预约一个工作位，按已排工作段开始tick与员工ID排队。上岗整理需要实际到位，计正常工作能量与工资，不生成病例、治疗收入或能力经验。完成后依现有服务调度接单；空闲待岗可在基地停留，收到实际任务立即起身，不能为了表现拖延6秒。

上岗整理使用staff_base_cues的两段办公表现：医生面前的病历夹在小夹子帮助下按真实待办排队；护士核对床位签，纸签折成小床但不自行完成护理。两段嵌入原6秒有效整理时间，不另等一次动画。实际待办为空时使用各自empty_scene，不造假病例、床位或工作量；门诊护士查看原检查或导诊安排。可见纸签只代表当前少量展示项，完整待办仍取原工作表，不把全部患者逐个实体化成道具。

表现从base_preparation_remaining_ticks定位当前姿态；紧急照护打断时停止整理，安全接续从余量继续，完成只取原准备事实。空闲待岗不循环重演6秒，收到任务立即离位。九骨架共用既有工具握持、夹具或承托适配，正常人类同样参与；桌夹与纸签在原桌面登记包络内，没有独立居民、库存、垃圾或任务奖励。低动态保留当前待办与准备状态，当前视角之外不维持小夹子动画。

默认选择岗位权限允许且全程可达的共享基地，按预计可开始整理时间、包含跨层的路程、物件ID排序，不保存一套永久私人办公室分配。普通短暂占用只排队，已接受的安全诊疗与必要照护优先：新替班者先完成上岗整理、再到病房实际接班，原照护者完成责任再离岗，不让两人同时去工作台留空病床。当前人员必须接续紧急必要照护时可以中断尚未完成的基地整理，保存余量，安全后继续；不得借此新开没有完整团队的手术。

缺基地或路线不通时显示“缺医生办公室”或“缺同层护士工作台”，可直接定位并建造；当前安全治疗与已有护理照常完成，新增服务只在实际基地、人员和路线就绪后开始。接诊Readiness把可用基地作为支持条件，但正常办公排队不被误报成科室关闭。已经完成本工作段准备后基地被改建，不撤销已发生的准备；现有临床承诺继续，下一段开工前重查。医院增长不要求逐人买桌，一个共享基地可服务多名轮班员工，实际拥堵在预览中可见。

Staff的当前连续工作段拥有唯一work_block_id、base_preparation_remaining_ticks与完成标记；设施只拥有当前使用预约。切班、读档、设备搬动和回看履历不创建第二次交接费用或奖励。新工作段由实际排班和任务边界派生，不能因每帧刷新岗位池反复登记。卧床睡眠沿职员睡眠状态拥有，两种工作基地都不代替员工床位。

工作台6秒上岗整理与病房5秒真实交班分别对应工作段准备和护理责任移交。新工作段先整理，再沿真实路线到病房交班；持续工作段中支援另一病房只做必要床边交班，不重复工作台准备。HS21飞卡片和CW01同事动作共用原5秒交班，不另加演出时间；床边8秒主动护理仍是独立的实际工作。全部自动接续，玩家只看到“整理待办、前往病房、正在交接”等当前状态。

## 14. 职称诊费与医疗设施收费

初诊医生职称越高，诊费越高；住院医师20、主治医师30、副主任医师45、主任医师60。医生卡直接显示“初诊诊费”，招聘卡同时列职称、诊费与原日工资。实际开始初诊时冻结医生ID、当时职称和金额，完成后入账；预约前改派用真正接诊者价格，已经开始的交接、晋级或读档不追补差额。一次Visit只有一笔职称诊费，不按参与医生人数收费。后续方案会诊和出院查房属于原方案；自动分诊仍按资格、排班与排队，不为了高价医生让患者反复换人。

医疗设施基础、精修、奇想三级暂用同一使用费；升级通过效果、速度和外观体现价值，不产生新的费率管理。门、椅子、饮水、厕所、员工小憩床、办公室、护士工作台及交通设施不计诊疗费。治疗包成本在医院采购时支付，患者账单不再按包重复加价。设施价是固定内容规则，没有院长逐台定价、折扣券或患者负债系统。

设施收费与是否治愈分开：完成操作但失败仍支付已完成项目，第二次真正尝试另计其设施使用；未开始、未完成、单纯等待和免费会诊都是0。第一次失败不会再次收初诊诊费；安全暂停、同次尝试换床或换班都沿用原项目，不收第二份使用费。医院原因中止尚未完成的恢复时不收60床费，不能靠让病人长时间占床增加收入。失败所增设施收入不高于该次治疗包成本，不提供“故意失败赚钱”的收益优势；成功治愈费仍只收一次。

诊断台升级和诊断能力成长可能让C档少做一次检查：两位实际执行者诊断能力均3、所用诊断台均为奇想型、本院尚无该病治愈经验时，初诊49.2，光谱后93，直接进入会诊。基础能力1和基础台对应42→77，仍需共振。已到诊断门槛不做多余检查，所以前一种少收20币共振费，也不花对应检查时间和磨损；这不是收入损失惩罚，而是更顺畅的真实流程。方案/升级卡分别显示服务次数与实际收费，不能同时宣称省略检查又保留那笔收入。

方案卡用“本次设施使用费／成功后另收治愈费”两行展示，住院项目可展开。当前预计价格在开工前重查；真正开工后按ServiceSession或TreatmentAttempt的快照结算，不读取后来更新的价格。成功费用向上取整到整数币，基础病症价与方案倍率仍各有一个来源；十进制倍率按精确分数或等值定点数计算后只取整一次，1.1即11/10、1.8即9/5，不能由二进制浮点误差多收1币。比如住院医师初诊、D09常规门诊第一次成功：20诊费+5初诊台+10治疗机+200治愈费，共235；失败再成功为245；两次失败为45，没有200治愈费。主任医师初诊的同一首试成功病例为275。

诊断ServiceSession保存医生报价与设施报价；治疗Attempt保存主体、可能的护理床和成功治愈费报价。每个账目分项以“事实所有者ID+分项类型”为唯一键，服务完成与余额入账在同一提交中完成。初诊两项同批提交，护理床和成功治愈费在出院时同批提交；重复完成消息不再增加余额。阶段账目可在不同医院日入账，小票按实收累计，总额不把预计价再加一次；缓存小票不是收费事实来源。保留活动Visit的服务凭据直至终结，历史小票淘汰后也不重新执行旧服务。

账目类别为gp（职称初诊）、facility（设施使用）和cure（成功治愈），facility分项带实际service_kind与equipment_id；原care类别不再单独入账。经营账页、小票与今日收入都投影这些唯一账目，不按界面汇总再提交一笔收入。

## 15. 治疗结果与下一步

临床结果先说明真实进展，再说明下一步。治疗中的高潮、机器工作结束、恢复完成与最终治愈是不同事实。患者卡和现场提示使用下面的状态键；键是原流程的只读投影，不是新的治疗状态机。

| 结果键 | 必须已经发生的事实 | 接下来发生什么 |
| --- | --- | --- |
| diagnosis_confirmed | 初诊或检查实际完成，累计证据达到90 | 显示正式病名，进入原方案会诊；诊断不代表治愈 |
| more_evidence | 初诊或检查实际完成，累计证据仍不足90 | 显示已取得的线索与下一项必要检查，病名继续保密 |
| awaiting_recovery | 手术操作实际结束，或需住院观察的门诊操作实际结束 | 手术仍先苏醒、真实转床；两者均等待必要照护、恢复与出院查房，不显示已承诺的成功或失败 |
| cured | 不需住院的门诊完成并真实结算成功，或住院查房完成并真实结算成功 | 结算一次治愈费，按本病例恢复身体与康复动作，沿原谢礼和离院规则继续 |
| retry_ready | 首次尝试真实结算失败，且必要恢复、照护和查房均已完成 | 显示“这次没奏效，仍可再试一次”，沿原失败反馈、安全离位和方案选择继续；名字不保证当前已有空机器或完整团队 |
| final_failure | 第二次尝试真实结算失败，且必要恢复、照护和查房均已完成 | 显示“两次已完成，安排友好转诊”，无第三次尝试，无成功谢礼或治愈费 |

手术操作结束时只允许awaiting_recovery；护理床只允许最终的cured、retry_ready或final_failure。转诊和放弃等候直接使用Visit原结局及就诊小票，不给尚未完成的项目补一个机器结果。护理缺员、机器故障、安全转床、改建等待均显示原原因，不被写成治疗失败。

每次已结算失败只消费一次原结果事实：怒气+15、CB15失败反馈和可能的既有失败事件各读自己的原来源，结果卡不再加怒、减怒或生成情境令牌。CB15使用当前实际到位且合格的医生及合法回应，最多8秒；门诊可由刚完成服务的医生接续，住院使用真实查房人员。不能为解释召回已离班术组或占用唯一护理护士；护士不能立即参与时沿原无护士回应回退。没有可执行反馈人员时显示真实结果与等待原因，不能冒称已安抚；后续实际会诊可在原沟通工作中解释，不补排第二场对话。已进行的安全照护先完成。

首次失败默认自动继续。医生自动方案由一次实际方案会诊重选，读取当前策略、执行人员和第二次尝试加成；不让玩家逐人点击“再试”。院长指定的方案保留指定意图，条件仍合法时使用新报价自动接续，不能因为失败或更换医生而偷偷改手术。显著变差或条件失效继续使用§6的原重评/确认规则；单纯等货、等人、等床只等待，不反复会诊。院长可在真正开工前选择其他合法方案、交给医生或主动转诊，已开始后仍执行原安全边界。

结果反馈、安全离位、既有事件与重试会诊按原阶段顺序执行，不同时占两处操作位。上一服务的设备、团队和床位按真实离位释放，重试在当前合法队列取得票号；该队列的改派与反馈不清零已累计等候。没有第二次可执行方案时沿既有候诊、弃候、缺资源和友好转诊规则处理，不新增无限“等重试”状态。全院暂停新接诊或把该病权重设0不阻断现有Visit的这条链。

进入新会诊、准备或第二次实际治疗后，现场使用当前工作/等待提示，上次结果留在患者卡的已发生栏；同一台机器不能一边进行新治疗一边继续表演旧失败。结果短动作没有等候播放义务，当前主要动作、必要安全离位或新任务到来时直接收拢到合法姿态。没有执行的反馈不能标成已完成及时帮助；在下一次原沟通中说明时只按那次真实回应结算，不给被省略的CB15补一份安抚或照护分。

失败本身不把同族设为敌人，也不改熟客身份或已成立关系。冰冻、龙烟等反应仍需怪脾气、实际公共情境、本人性格/怒气和原机会预算；本次就诊至多一次报复机会。第二次失败不追加机会，失败卡不能等待或制造报复来完成自己的收尾。没有冲突时，失望、提问或再试的态度由真实性格和已有专业回应表达。

## 16. 看得懂的方案比较

方案卡首先并列“这一次的预计成功率、操作/必要恢复、尚待条件、本次设施费、成功后治愈费、所需治疗包”。已完成初诊与检查列在“本次来院已收”中，不加入新一次的待收价。护理床费用只出现在实际需要住院的方案里。耗材显示领用包数及其采购成本参考；确认方案不买包、不扣现金，真正开工仍按原库存预留与领用。

首试失败后保留该次Attempt冻结的成功率、执行人员、设备档位及已经收取的分项。卡片可展开“下一次的变化”：第二次尝试原有+15个百分点、当前人员能力/能量、已完成升级、真实舒适与设备维护条件；最终概率仍按原公式夹限。当前报价的增加或减少不反写上一Attempt，也不把一次随机失败归因为“医生水平差”“机器坏了”或某个种族。已知故障与缺员用实际来源说明，单次失败不能证明其中任一因素是原因。

例如首试92%，其余条件不变时第二次为98%；不能写成107%或保证成功。更换人员、环境和维护状态可能改变报价；界面取实际可执行方案，不承诺第二次一定更高。报价无有限合法时窗时只列缺项，不填一个假的精确等待秒数。默认只比较当前推荐和一个合法备选，其余仍可展开全部方案；没有备选就明确说明原因。

没有把两次成功率相乘后的数当作这一次效果。两次累计概率只用于下节的条件性设计校准，患者卡仍显示当前一次真实报价。查看比较不消费随机数、不预抽第二次结果，也不提前预留机器、床位、团队或治疗包。价格、成功率和阶段结局各由原所有者提供，不在方案卡保存另一份可修改的收费或结果。

## 17. 重试、耗材和升级的数值校准

balance_reference.outpatient_examples引用同一真实僵尸零件装反病例与常规/舒缓方案，比较基础、精修、低维护和舒缓四种条件。初诊均由住院医师完成；治疗能力1、能量100、劳累0、无舒适/科室专长/治疗天赋/沟通修正、非复杂病例。设备状态分别按样例读取。每例假定首试失败后第二次保持相同条件且确实完成，没有弃候、转诊或中断。这是条件性解析比较，不是普通接诊、自动医生偏好或每天完成数的预测。

样例状态100和39指首试开工前数值；按真实每次使用磨损2，第二次开始前分别为98和37，仍处于相同维护修正分档且高于停诊线，不把设备状态免费恢复为100。若中途真实保养、成长或排班改变条件，实际方案报价依当前事实计算，不用校准样例覆盖它。

令p1、p2为按原规则换算后的两次成功概率，则最终治愈概率=1−(1−p1)(1−p2)，平均尝试数=1+(1−p1)。每次相同方案时平均领用=平均尝试数×该方案包数；平均治疗机工作量=平均尝试数×向上取整到tick的单次操作时间。收入参考=实际一次初诊诊费及初诊台费+平均尝试数×主体使用费+最终治愈概率×取整后的成功治愈费。减去领用成本只是单病例贡献参考，不是扣除工资、维护、运营、培训和升级后的利润。

四例数值由统一阅读页内容索引从当前数据生成：基础常规92%/98%，两次累计99.84%、平均1.08次；精修将首试提高到93.5%，平均1.065次；低维护的首试为88%，平均1.12次；基础舒缓97%/98%，平均1.03次但每次领用2包、操作工作量为常规1.8倍。精修的材料投资、施工、实际排队与吞吐价值仍取原升级及调度规则，不能只拿少量成功率收益承诺快速回本；舒缓也不保证每天比常规赚钱。跨过维护阈值、换方案或换人时须使用分段条件，不能照搬本表。

实际D09常规账单仍是首试成功235、失败再成功245、两次失败45；首试失败后主动转诊为35。只完成初诊便放弃等候为25，已完成额外检查时另加对应实收。所有参考均不写入余额、奖励、客流或援助资格；解析期望与单次真实账单分栏。正式试玩同时记录首试失败后自动接续是否易懂、成功结局是否揭晓过早、舒缓占用与升级收益是否符合体验，以及有效候诊、弃候和必要照护对实际完成数的影响。

逐班客流投影复用本章的实际报价和锁持来源。原初诊、必须检查、方案会诊与每次尝试分属各自实际资源；自动重试只按已经公开的概率作参考期望，不读取尚未揭晓的结果。医生跨岗仍是一份工时，床预留、苏醒、转床、恢复和查房不能压成术台秒数。投影只解释本院新工作能承接多少，不派员工或提前承诺病例；单D09条件算例用于核对工时到流量的算术，不取代本院病例混合、真实排程或实际完成量。

### 17.1 手术与舒缓住院的资源账

balance_reference.inpatient_examples以真实适配引用三档手术及同一复杂D14的舒缓方案。全部使用基础医疗主体与护理床、初始状态100、能量100、劳累0，无舒适、天赋、科室专长或沟通修正；初诊与必要检查能力1、本院该病治愈经验0，覆盖护士护理1。所需研究、互异团队、真实同层床及查房资格均满足，首次失败后确实以相同条件完成第二次。每次使用沿真实磨损，不免费修复设备；两次均未跨维护阈值。条件性算例不替代临床接单资格、实际排班或普通到访计划。

两次最终治愈率和平均尝试数沿本节原公式。初诊与实际必要检查只收一次；每次完成操作及必要恢复各收原主体与护理床费，最终成功才收一次精确取整后的治愈费。三档最低合格团队的首试均96%、第二次98%、累计99.92%，平均1.04次。D14复杂舒缓由治疗3执行，首试89%、第二次98%、平均1.11次；当前界面仍只显示本次报价。

工作量分开读：操作医生在手术及15秒苏醒中各自持续占用，不能把两人合计工时当成一个可串行替代的岗位；手术护士还须真实陪同转床，床区另有覆盖护士。主动床边照护为每次8标准秒，可在有覆盖的恢复期间执行；最后10秒医生查房必须在恢复与护理完成之后。基础护理1的本次8秒可与恢复重叠，不再给恢复额外叠8秒；相应主动任务仍真实占用护士。

每次床承诺自实际开工起的下界为“操作＋手术苏醒（门诊为0）＋基础恢复＋最后查房”。三档手术分别325/415/505秒；失败后确实再做一次时的平均下界为338/431.6/525.2秒。它还未包含开工前最多30秒的实际预留、真实转床、覆盖空缺、查房排队与安全离床。护理床已承诺、已占用、正在恢复和待释放分别取原准备/Attempt/WardStay与安全占用事实，不另存一个床周转倒计时。手术台也须等待原实际安全离位，不能用操作结束替代服务位释放。

复杂D14舒缓操作按52×1.8÷1.1向上取到85.1秒，每次基础床承诺下界275.1秒、平均305.361秒。它与二级手术使用同一居民身体和病症，比较的是所需资源与当前效果；舒缓平均主动护理8.88秒、查房11.1秒，不等于只付这点工时便能省去整个病房覆盖。三档手术平均操作医生各占用140.4/171.6/202.8秒，原班次安全窗口与交接仍先核验；一个1800秒医院日不能据这些数字保证完成整数台数。

双床病房预设继续作为起步布置，实际有空床不代表接诊组合已经齐全，也不保证手术台始终连续开工。增加床、培养术组或提高护理床等级改善不同瓶颈；需要多少床取真实准备、恢复、覆盖与转运事实，不能用两个分别忽略等待的下界相除后声称最低床数。布局建议先说明当前实际缺项，沿原扩建/方案比较入口处理，不自动采购病床或生成另一套收益排序。

统一阅读页从源数据生成收入、领包成本、扣包后贡献与分别占用的工时。D14二级手术首试成功/失败再成功/两次失败账单为1260/1380/300；三级D78为1296/1416/300，条件性扣包后贡献1050.31。D14舒缓对应790/860/200，条件性贡献707.45。贡献未扣工资、运营、维护、培训及设施投资，不能写成利润或回本天数；收费可能跨医院日入账，不能把期望全算作来院当天现金。

变更面只增加设计校准输入与离线阅读表，不增加运行时全院病例×方案计算、世界状态、随机流、缓存或保存字段。静态算术可核对概率、收费、领包及资源归属；真实弃候、无进展转诊、换班、床位释放、成熟医院现金节奏与160/320/640人下的临床吞吐仍须运行验证。24小时钟面与全部医院时间换算由模拟规格§1.1拥有，本节秒数继续采用模拟秒单位。

## 18. 结果体验的责任与验证边界

临床流程拥有失败后的实际反馈、方案来源、队列接续和安全退出；TreatmentAttempt拥有次数、承诺效果、工作与结算，WardStay拥有必要照护和查房。内容定义拥有结果键对应的标签与动作，界面投影已发生结果和当前报价，账目、评分、关系、任务及院史继续各自归并原事实。结果表现不成为额外治疗、随机事件或奖励来源；扩展病症和种族沿原适配规则接入。

资源增加为18种设备道具结果姿态及低动态版本、当前可见对象的少量投影查询和选中患者的方案比较；资产共享与缓存仍计入原总预算，不能声称增加表现没有内存或帧耗时。每个Visit仍最多两份Attempt，结果和反馈使用其原凭据，历史沿原100张小票和院史窗口归档；医院数、楼层与实际经营实体继续按原成长与保存规则处理。

静态核验覆盖结果键合法性、引用、字段边界、条件性概率/收费/领包算术和旧措辞清理。自动接续的实际等待、手动意图保留、失败反馈的人员与占位、住院揭晓时点、九骨架和症状包络的结果姿态、切层/读档与160/320/640人负载仍须按验收章提供运行证据。趣味性、放手观察的轻松程度和升级/舒缓在真实吞吐中的价值须试玩，不由解析样例宣称已成立。
