# 临床连续局部转弯修复

基线为 `30056f3b433939f315b5b590978ebc80453de0f9`。在独立副本使用 Godot 4.7.2 与已校验 Linux 原生库验证，没有修改用户 Codex 工作树或性能分支。本次是功能修复，不是性能优化。

## 原因及变更

原 CLIN-24 的真实前提在 tick 4452 重现：护送护士已合法停在 [45,71]，护理护士在 [45,71.8] 被右侧设备和该身体挡住。旧直角/一个身体跨度连接不能连续绕过设备，实际后退后反复返回同一受阻位置。移动护送停车点只能转移堵塞，已撤回该候选。

现在仅在原局部连接不通时，从身体外扩一个通行宽度的设施/身体空间索引取得真实障碍边缘，验证至多四段的正交连接。已验证路线最多两个剩余中间角点保存在原局部意图中；现场每一步仍重查身体、扫掠、静态几何和床边使用权，实际到达原路线才推进游标。没有动态整层搜索、优先级、固定人物搬移或新旅程。

独立反例证明只记第一个角点不够：人物到达首角后，后续设备离开查询邻域，旧候选会忘记下一转弯并约每25 tick循环。保留短连接后，两种设备几何正常行走及冷恢复都到达。存档拒绝过长、跨层、斜线、重复/回折、缺回接及越界索引。

CLIN-27 另暴露离班生活往返的护士被“有生活任务”误认为固定工作身体。只对现有生活任务明确拥有的单人地面行走允许原有局部绕行，实际工作、临床离位、培训、坐姿和同行组保护保留。原目的地、任务、请求顺序和路线不变。

这将旧设计中“只允许固定三种连接”扩展为身边几何的短连续连接，已同步两份设计文档。不是恢复旧动态全图搜索，也不是把历史测试失败改写成通过。
