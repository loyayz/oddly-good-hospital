# 公共区域真实入口阶段核验

基线：`30b76afa321d8e93ce61a599b69b4adc3525ee8f`。本阶段只交付公共区域入口与实际入区后的任务交接，不表示所有运行时整层搜索已经消除。

## 规则与改动

- 入区只枚举真实门道、医院入口、连接器及完整身体所需的邻接接续，不预先排序整个区域站位。允许在静态加载准备时缓存入口几何。
- 入口可通行与当前位置可安全停留分开判断。完整身体进入目标区域后，原任务才可改去本区设施；没有可用设施时须真实走到安全占地再停下。
- 患者候诊、生活服务、员工短休、双人娱乐和访客候诊使用实际移动交接。到椅子才取得使用权，其他任务、绕行、承托退出和多人移动不能被可选公共任务取消。
- 保留厕所/饮水原45秒剩余额度预判：选区的入口行程加服务队列估计超过剩余额度即进入原兜底；相等仍可尝试。原需求时钟不重置，真正开用仍检查实际450 tick边界。
- 饮水中拆除最后导诊台和诊室设备后，返程到当前合法区域的安全站位。区域内的饮水服务位本身不构成安全站定，票据暂停仅在实际安全抵达后解除。
