# 任务、寻路与移动重写：暂停交付记录

状态：核心重写及相关功能回归已完成；最新160人快速性能对照未完成，未证明整体性能收益。开发、测试和性能验收保持暂停。本次归档不包含新测试、构建、性能测量或优化。

需求依据为[任务、寻路与移动规格](../specs/26-10/2026-10-19-task-navigation-movement.md)及对应设计文档。代码以本报告所在提交为准。正式Release性能验收没有通过结论。

## 已实现的职责与行为

| 层次 | 职责与状态 |
| --- | --- |
| 任务 | 决定业务目标、区域和具体位置；保有业务阶段、资源承诺和目标身份；依据实际到达结果开工。 |
| 寻路 | `HospitalNavigation`计算具体起终点之间的合法结构路线和基准通行时间；只拥有可丢弃的查询与导航缓存。 |
| 移动 | `HospitalMovement`保有真实行程、路线游标、受阻与让行进度，执行实际行走、过门及竖向交通交接。 |

`HospitalSpace`继续提供建筑几何、设施和身体索引及现有调用入口；人物位置、交通票和业务任务没有新增副本。现有业务任务继续拥有选区、选点和资源承诺，没有引入替代它们的统一任务状态机。

- 存在合法结构通路并满足业务出发条件即开始移动。普通行人、短时操作预约、电梯排队和轿厢忙碌不再被当作结构无路；实际移动仍检查完整身体、操作区域、预约权限和分段扫掠。
- 跨层寻路按真实连接、停层、完整同行组尺寸及合法运行方向搜索。基准通行时间包含步行和固定登乘离舱时间，不含未知排队；独立交通估时仍可返回未知。
- 路线查询不创建交通票，不推演整个现有电梯队列，不预先证明未来时刻其他人物的出口。完整组实际到达电梯口后才正常取票、排队和登乘。
- 相同目标的有效请求复用当前行程。目标变化重新规划；运输中变更目标保留安全段，落地后继续处理。实际遇到临时阻挡后再等待、让行或局部绕行。
- 只有门和护理病床允许自动伸缩。椅子、员工个人床、医疗机器、手术台、生活和娱乐设施保持固定主体尺寸，真实身体、容量和操作空间仍须满足条件。
- 自动选座取消累计30秒到达门槛和“最近候选加12秒”的硬筛选；时间仅参与评分，原环境偏好、环境分带、性格条件和稳定平局顺序保留。
- 公共自动使用保持先到区域再取具体设施；手动操作保持指定设施；医疗设施保持出发前预约；员工个人床保持自动长期固定归属。旧存档兼容不在范围内。

内容源数据、生成内容、schema、相关设计文字和用例随规则同步调整。当前内容指纹为`6369abdacadd0ec32a95c46a9ce4ef6e9710166c475905ae0cd88202ad0b45a8`。

## 发现并修复的问题

| 问题 | 处理与边界 |
| --- | --- |
| 合法路线被未知电梯等待时间否定 | 普通点到点路线只证明结构通行，独立估时未知不再拒绝出发。实际交通队序、安全登离舱和故障方向仍由交通执行。 |
| 固定椅子参与伸缩试算及逐人出口证明 | 固定设施使用固定主体尺寸；全局出口证明保留在可伸缩护理病床的真实空间变更处。固定设施的真实使用占用仍阻挡移动。 |
| 已完成退让的人继续挡住优先者 | 调整让行处理顺序，让优先者能围绕实际停下的身体继续局部绕行。 |
| 新启动任务没有历史路线可退，形成迎面僵持 | 在原礼让局部范围内寻找真实可到达的让行位置，检查完整身体及优先者剩余路线，实际走过去，不瞬移或改变业务目标。 |
| 小数坐标连接段被粗网格预约误判 | 连接段先检查结构几何；真实移动仍使用精确预约与身体扫掠，避免相邻区域的粗网格误拒绝。 |
| 临床改派遗留旧票据拥有的设施预约 | 改派时释放准备承诺，同时覆盖就诊ID和当前票据ID。身体仍占用时转由真实身体维持占用，实际离位后才释放空间，避免删除票据后恢复校验失败。 |
| 只读设施试算清空真实移动的路线检查记录 | 空间索引切换临时世界时不再清空移动记录；移动系统在真实执行世界变化时管理自己的记录。路线复核复用已有静态几何。 |

未沿用的旧规则有明确原因：未知等待不能表示无路；固定椅子不能借伸缩规则扩大主体；30秒及最近加12秒筛选违背时间仅作选座权重的规则；为普通路线推演整个交通队列及其他人物未来出口越过了任务、寻路和移动的职责边界。这些是规格变更，不作为保留旧输出的兼容要求。
