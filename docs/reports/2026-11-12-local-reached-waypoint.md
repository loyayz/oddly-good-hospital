# Completed local target / current original waypoint handoff

## Result and limit

A narrow movement ownership defect is fixed locally. A completed local retreat could physically reach its current original floor waypoint without having a `rejoin` field. `_local_resume` then requested a zero-distance return, failed to choose a return, and retained local ownership forever. It never earned the original waypoint even though actual arrival was already proved.

The fix recognizes only a completed intended local target equal to the valid current original floor waypoint, with no existing rejoin and after all outstanding corners are handled. It advances that one cursor, clears local ownership, and invalidates the same route-check cache as the established rejoin handoff. Existing intentional/future rejoin handling, passing a point, body/sweep checks, movement budgets, ticket rules, priorities, jobs and work accounting are unchanged.

This is not a full acceptance result. Targeted worker226 has not arrived; maintenance222 remains travelling, 0/20000 work. No full 7000-step replay, performance window, Release/GPU or long acceptance was run for this fix.
