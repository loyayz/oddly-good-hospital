# Linux平台源码与发行候选验证

本次把平台差异实现为正式源码中的Windows/Linux条件编译，不依靠运行前改写Windows代码的测试适配器。Windows原生分支经预处理逐项比较保持原有代码行为，函数指针静态断言仅改为平台中性文字；Windows导出预设逐字保持。这不是Windows编译或实机验收。

## 改动范围

- Linux独占资料锁使用非继承文件描述符和flock，拒绝非普通文件及符号链接guard；SQLite路径使用UTF-8。
- Linux时钟、线程身份和独立数字locale保持原生接口契约。
- 保存预算使用实际MemAvailable与cgroup v1/v2全部祖先剩余额度的较小值。要求初始cgroup命名空间、完整可见挂载及祖先链；命名空间遮蔽、挂载遮蔽、缺失或格式错误均拒绝，返回零额度和具体原因。初始命名空间inode是当前Linux内核实现约束，其他实现会安全拒绝，不猜测容量。
- 新增Linux库配置、导出预设、离线原生/依赖构建与发行导出入口。固定引擎ABI、依赖版本与哈希、实际编译输入、工具和产物均记录身份。
- CORE-49复验发现既有JSON流对象在同步操作结束后保留捕获自身的回调，导致循环引用。现于完成/失败/下次重置时释放回调，不改变编码字节、哈希、数值、错误顺序或保存事务。

## 真实导出与分发边界

官方Godot 4.7.2模板归档完整下载后核对官方SHA-256：f298490b8d44d934be425a5a65a51bf15f422428b229a06a6e11d9ffea248011。提取的Linux Release模板SHA-256：d9f79ab89b5ae369aeed11c6052d402e8218cd503bf85b4a235f9c30c46a7c63。未用部分归档CRC代替完整来源校验。

已实际完成内容检查、完整导入和Linux程序/PCK导出，并从独立目录、全新资料目录启动导出的程序，无窗口退出0，没有读取源工程或依赖LD_LIBRARY_PATH。这只证明无头启动，不证明图形、音频、输入或完整保存/恢复。

首轮发现并保留了两类失败证据：默认HOME配置/缓存目录不可写，以及导出PCK意外包含历史报告/可行性数据。构建工具改用独立可写状态目录；Linux预设收紧排除规则。导出器直接读取固定PCK v4目录，核对每项路径、边界、重复/重叠和内容摘要，并按运行资源白名单拒绝报告、测试、工具、未知文件与原生源码。未知或加密格式拒绝。

依赖编译也加入稳定路径映射，防止静态库的__FILE__把本机源码路径带入玩家动态库。最终分发须以通过PCK和公开文件内容检查的产物清单为准，早期运行成功但含报告/本地路径的包不可分发。

分发材料记录13类组件及许可证/通知文件；系统GMP/MPFR/glibc和共享编译运行库不捆绑。官方Godot模板可能静态包含的编译运行库，其Runtime Library Exception依据显式记录供审查。清单支持合规核对，不是法律完整性保证。

玩家文件仅按public-release-files.json中的相对路径、哈希和字节数白名单归档：程序、PCK、原生库、许可证及公开运行要求。完整构建日志、源码身份、内部构建清单和测试证据另行备份，不放入游戏安装包。

## 仍未完成的验收

1. 当前云环境处于非初始cgroup命名空间，无/sys及cgroup挂载，隐藏祖先限额不能可靠证明。安全拒绝不代表成功保存/恢复已验收。必须在完整资源限制可见的实际Linux环境执行CORE-18～29、CORE-46等成功路径，不能注入虚假预算通过。
2. 当前本机为Debian 13 x86_64/glibc 2.41。原生库需要GLIBC_2.38、GLIBCXX_3.4.32、CXXABI_1.3.15及相应GMP/MPFR接口。没有在干净目标发行版安装验证，也不承诺兼容所有发行版。
3. 无真实图形输出、Windows运行或安装环境。OpenGL 3.3、X11/Wayland、音频和输入等实际目标运行验证仍保留；ELF依赖闭包不能覆盖全部dlopen功能。
4. 因上述边界，交付是Linux发行候选与验证材料，不是全平台正式验收完成。
