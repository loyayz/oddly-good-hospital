# 建造几何局部优化验证

本轮以已包含墙边障碍视图的实现为公共基础，仅比较 `build_geometry.gd` 与 `room_structure.gd` 两份几何文件。所有合法格子、身体、候选和后续安全检查保持；局部测量与160人完整模拟步分别判定。

## 实测成本与实现

三次分段诊断中，85×95的prepare均值142.264ms，其中结构识别118.869ms；96×95分别151.722/129.636ms。结构分量排序合计23.361/26.545ms，形状又排序12.179/15.602ms，并执行两次flood共12.789/13.759ms。分量扣除物化和排序后的剩余经过时间约51.782/53.685ms，包含未细分工作及探针成本，不能称作纯搜索CPU。

辅助8×8仍对8128个开放分量格子排序，排序20.363ms；其依赖计算另占41.439ms。上述诊断包含插桩，嵌套项不能相加，也不作为加速数值。

实现使用引擎 `PackedInt32Array.sort` 排序行优先整数键，保留原完整点集、visited和最终y/x顺序。形状通过键取回原独立坐标数组，保持整数值浮点数和负零类型。所有格子先完成合法性、范围、唯一性及包围矩形统计；只有数量恰好填满包围矩形时，才证明连续无孔并省去重复flood。非矩形继续执行原连通和孔检查。

## 正确性与限制

15项选定流程均有完成通过证据：PERF-10、ROOM-BUILD-02/03/06/08/09、SPACE-52，以及GUIDE-01/07/12、CLFLOW-23/25、SPACE-09/10/24。PERF-10的39项断言覆盖25种形状和8种完整分量，包括96边界、窄长、浮点/负零、重复冒充矩形、孔洞、断连、非法值、完整返回类型和返回值隔离。

首批因新增测试前提误把预期数量作为实际cells而中断；此前完成的CLFLOW-23/25分别耗时1.153/4.850秒，证据复用。只修正该测试输入后，其余13项全部通过：准备11.606秒、导入21.401秒、测试48.890秒，总81.912秒。没有把中断批次称作完整通过。

局部工作量和耗时下降，保留该优化。同步prepare仍约100～124ms；剩余结构遍历、复制和依赖计算继续存在。160人整体性能尚未因本组结果获得通过结论，后续使用固定综合输入单独验证。
