# 公共设施区域寻址、个人床分配与160人快速验证

公共设施已采用“自动先到区域、真实到场后选位”，手动请求始终指定原设施；员工床由系统自动形成长期唯一归属。医疗预约与原安全交接保留，当前未发行版本不实现旧存档迁移。

**性能结论有正有负。** 同输入三轮无插桩完整步对照，门诊/清洁窗口均值中位数 **454.326ms → 333.725ms，下降26.55%**；GP窗口 **58.552ms → 79.397ms，上升35.60%**。两个窗口的后续步均值均未改善，不能把冷首步改善写成整体稳定吞吐达标。公共设施竞争与初次分床另列诊断；所有证据均非Release正式性能验收。

## 公共设施竞争与后段诊断

新增竞争输入SHA-256为 `56ea8338361470fee88659ed806d412aa49927c0709c30d4fbdf536a20eb4f76`。它在完整160人原医院上声明合法临界初态：绝对时刻统一平移1800tick，16名原闲置患者位于四层生活区外的合法接近位置，首次生活需求刚满180秒，四个厕所区域均保留真实设施与原容量；正常提交清洁、待工装修及一条手动固定椅子请求。全部前提变更、真实去返路径、容量依据与世界校验见原始`.preparation.json`。

这些位置是**场景起点**，不是从原GP场景连续运行到此的证明。后续2623→2923共300步按原0.1秒步长真实运行，场景不预造到场、排队、完成或离位。完整人数与工作资格、公共队列及使用契约分别判断，不把普通排队当错误。

最终300步**root诊断**完整、160人、同一人物集合和世界校验全部通过；实际临床与清洁进展资格、手动请求、实际排队、至少两个使用区域、实际完成、完整身体退出后接续及观察器无规则错误均通过。四个区域共有**16次真实使用并全部完成、1,280个实际使用tick、8次真实安全退出后的接续、0次兜底**；队列峰值8人，累计620人次tick。原GP55、会诊81、接待60个临床工时tick真实推进。

全窗475.449秒，均步1,584.830ms、P50 94.168ms、P95 16,110.792ms、最大68,096.465ms。相同输入的v5中间版root为490.200秒、均步1,634.001ms、P50 169.054ms、P95 15,498.528ms、最大35,730.515ms。最终均值略低，但P95及最大值更差，且真实完成12→16、接续4→8、排队1,100→620人次tick；**不同实际公共工作量的n=1插桩窗口，不能证明普遍或无插桩整体收益**。没有为看起来更快而只保留此前的12次使用。

最终根阶段：临床分派297.995秒（62.68%）、候诊分派146.449秒（30.80%）、环境分派7.975秒（1.68%）、科室采样7.504秒（1.58%）、环境推进4.502秒（0.95%）。修复真实清洁途中整程重报价后，环境推进由117.569秒降至4.502秒，但临床与局部取位长尾抵消了多数收益。完整窗口路线29,188→39,925、楼层构建72,576→98,771、交通搜索28,048→39,363；这些实际成本和额外成功使用均保留。此窗仅是新行为完整快速诊断，**性能未达正式阈值**。

在实际完整窗口的2923边界另冻结全部事实，前后各测1步nested以定位长尾。两次都完整、160人且世界合法，但没有实际临床工时，**代表场景资格为false**，只作诊断，不能替代300步。该步16,477.243ms→15,595.110ms；候选查询114→102、普通分派120→108，说明生活暂离早退确实少做了12次分派。仍有3次方案报价，后值合计约8,916ms；楼层来源读取58,082→55,179，后值约5,766ms。单次差值含波动，不作为可靠加速比例；多数临床查询仍属于其他合法等待者。

## 初次分床与保留的无收益结果

32名员工和16张已有床的初次分配完整考察512个组合；1024次真实去返路线没有减少，优先匹配关系保持完全相同。将逐员工只读范围合为一个批次后，初次分配 **29,798.465ms → 29,015.494ms**，楼层构建5,622→5,577，重复读取298μs→545μs，均为n=1。这个差异不足以证明实质收益；共享范围没有消除主要计算量。

最终源码另测一次：初次分配**28,141.085ms**，重复ensure **338μs**，重复读取没有增加任何路线查询；仍为512组合、1024次真实去返路线和5,577次楼层构建，匹配关系与此前完全一致。未造成移动或临床事实变化，世界校验通过。单次波动不能建立可靠加速结论，**初次分床约28～30秒仍是明确瓶颈**。

仅存在未分配员工和可用无主床时，动态通路事实才参与机会重核；已归属床不重排。该机会分支保障真实让路后可以分床，**尚无大规模“持续缺配且仍有无主床”的成本证据**，不能用床已全部归属时的快速读取掩盖它。
