# 单人回接意图：实现与选择性功能验证

基线为 `30056f3`。单人侧移后先意图走向原路线 B，真实受阻再尝试 C、D；始终从实际位置继续。静态几何与护理床停点权限决定可构造的正交连接，沿途人物不再按整条未来连接预演。下一次真正迈步继续检查身体、已接受扫掠、门与预约。尝试接点不推进原路线游标，实际到达后才交回原路线。

当前接点意图可随真实侧移或后退保留；转角根据真实接触方向及上一段实际行走方向选择，避免侧移后立即折回阻挡方向。后退走到真实检查点再尝试侧方，不在每个部分后退步重复选择整条连接。状态没有增加优先权、让行承诺、整层搜索或尝试历史。恢复仍验证当前腿的正交性、接点属于原路线、同层与有限坐标；合法的后退可以携带尚未实现的接点意图。

SPACE-10 实际执行后，除旧家具/入口双拐角场景外，其余局部场景、对向只一方绕开、静止/受保护员工、真实后退、重复目标、恢复坏状态及现有精确扫掠证明检查均通过。旧场景在独立、未修改的 `30056f3` 中单独复现 `arrived=false`；本实现也未解决该输入，保留失败、真实轨迹及恢复结果，未删除或放宽到达断言，不声明完整 SPACE-10 通过。该输入需要当前直角连接集合之外的局部静态连接，不能用本轮专项通过宣称所有交通布局已可达。

首轮四人反转 ID 场景出现来回运动，修正真实接触后的转角选择后通过；床边场景随后暴露侧移后立即折回问题，以最后真实方向选择静态转角后通过。测试还修正了新输入中误用 StringName 身份键的问题。失败试验保留在过程目录，最终通过证据及未解决基线失败见 [清单](evidence/2026-11-10-local-return-intent-functional/manifest.json)。

本阶段没有改变合法负载、模拟步长、环境任务数或随机流接口，没有运行画面、完整发行构建或全量专题。性能收益在相同初始 160 人、1000 前缀步与 2000 采样步、串行三次的后续测量中判定；本报告不宣称提速。

后续复核补齐回接再次碰到固定人物时的既有侧移出口检查：新分支同样按真实接触者的当前可移动性选择入口，没有新增通行承诺。专项增加 `fixed_contact_after_rejoin_attempt`，实际接触后使用固定身体出口检查，原固定人物保持不动，最终到达。最终四个回接意图用例、四组移动/导诊/离院回归和五项床岗位选择再次通过；SPACE-10 仍只有上述既有双拐角场景失败。最终功能证据见 [清单](evidence/2026-11-10-local-return-intent-final-functional/manifest.json)。`815500b` 的首轮三次试测完整保留，补齐边界后的提交另行完整测量三次，不混用版本或挑选轮次。

`700ff4a` 的第一轮在 3000 步后被终态验证器拒绝，后续两次自动停止，不能列作通过的性能轮次。`bench_patient_0035` 的实际 X 为 `10.0000009536743`，旧近共线历史点 X 为 `10`；选择旧点作为后退目标生成了极小斜向意图。后退检查点现在只提供沿当前轴的距离，保留角色当前实际横向坐标，不改变位置、历史、原目的地或碰撞/距离容差。新增第五项真实碰撞后退用例验证一 ULP 的近共线历史；SPACE-60 小数移动预算、四组移动/交接回归和床岗位 21 项检查通过，见 [轴线修复证据](evidence/2026-11-10-local-return-intent-axis/manifest.json)。修复后再次冻结源码执行完整三次验证，失败数据保留。
