# 公共候选共同路线与区域刷新修复

基线为 `dev` 的 `305393872b2164b15c2dfbcaf9b8e5d4024439e0`。优化范围为同人多目标的共同连接网络、区域刷新中的重复复制/映射挂接，以及等待点门检查。合法160人负载、全部候选、固定0.1秒、原业务规则和性能阈值保持。正式性能验收继续暂停。

## 采纳与实现

| 方向 | 结论 | 实现与边界 |
| --- | --- | --- |
| 同人多目标不再重复求解共同连接网络 | 采用 | 原Boost Dijkstra增加单源完成模式，返回实际settled顺序、精确整数标签及前驱；仅单人、成本报价、原动态只读批次内复用。第一目标仍惰性求解，第二个不同目标才建树；后续目标分别验证目标层终段。完整可执行路径、同行组、非空阵型及独立调用保留原流程 |
| 区域刷新不再复制无关完整设施布局、重挂未变映射 | 采用 | 区域只读取原位置、实际占地和患者位；完整布局包含的其他服务/状态字段不复制。完整区域依据、层集合及顺序均相同则保留当前全局格点映射。真正变层、删层、懒加载层及换世界仍按原完整派生/重挂 |
| 等待点检查不再逐候选扫描本层全部门 | 采用 | 使用现有BodyIndex/Boost.Geometry，以实际门宽的原grow(1)禁站矩形宽筛，再按原编号执行原精确谓词。每层一棵当前门索引，span变化原位更新；身体、岗位、预约和人物检查不跳过 |
| 单电梯单源树不展开再次登梯边 | 采用，修复首轮无收益额外工作 | 仅恰好一部lift的共同树适用；源点已提供到全部合法停层的直边，固定每层整数耗时与非负登离舱成本保证再次登梯不能更优。实际目标终段仍查询；楼梯、多连接、第一目标、完整路径和同行组保持原流程 |
| 根据未经证明的“变化楼层通知”跳过全院依据比较 | 不采用 | 现有WorldState.touch/invalidate_geometry只提供全局修订，投影、恢复及直接事实修改不能据此证明其他层未变。直接略去比较会使区域过期。本次仍完整比较，仅删除无关复制和相同结果的重复挂接；没有建立第二套不完整变更账本 |

共同网络的主体、实际起点、初始时间、拓扑身份及完整额外停层声明必须相同。新批次、异世界或新声明不继承旧标签。节点按Boost实际确定顺序处理，严格更小才替换目标；零成本边不能通过事后排序模拟原顺序。整数MAX仍可表示，溢出沿原不可达处理。选中walking_distance从目标终段开始，沿前驱逐边反向累计，保留原浮点顺序和结果类型；批次不持有第二份世界事实或交通票。

单电梯约简使用当前规则中的线性整数楼层时间。若一跳耗时为S+B+P×|目标层−源层|，多次乘同一电梯的耗时至少为S+kB+P×各段层差绝对值之和，不能小于一跳。故障仅允许下降时结论仍成立；溢出不能通过分段变成更小的合法整数。内部无益绕回源层标签可以消失，公开完整报价及同分选择保持。未替换或手写通用最短路算法。

变化交接为封闭导航批次→共同连接标签→各目标报价、区域实际几何→全局映射，以及门空间宽筛→原精确禁站规则。选例18项：STAFF-69/70/71/72/75，SPACE-07/08/10/23/24/28/46/48/51/54/55/56/57。覆盖公共选区/排队/取位/手动指定、真实移动、连接/运行方向、完整组、引用与来源隔离、安全阻挡和恢复。

新增回归包括：

- 合法双连接五层场景，5个不同目标完整报价与冻结基线逐字段、逐类型比较，只有1次原惰性搜索、1次共同树及3次命中；完整路径与同行组仍分别惰性求解。
- 同一世界的新批次、嵌套异世界、初始时间差异、额外3F/4F停层声明分别隔离；目标封堵/恢复、故障安全下降、来源位置/朝向变化及返回值改写保留原结果。

- 原生单源模式覆盖完整可达标签、真实零边发现顺序、前驱、精确MAX、溢出缺席及回调失败原子性；原单目标惰性停止断言继续执行。
- 区域完整格点、顺序、锚点、哈希与设施映射对完整参照一致；无关全局修订保留映射，实际变化、删层和异世界仍重建。区域准备不调用完整facility_layout。

## 首轮无收益及修正依据

首轮a/b/c/d已有公共/GP实际求解1933→306、426→258次，但窗口平均改善有限。GP完整点查询诊断416.952→419.306ms，公共2651为202.794→216.142ms，均未改善；不能因求解次数下降宣布路线成本已经解决。
