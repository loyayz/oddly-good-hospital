# 公共选区Worker试验与移动成本诊断

四个公共选区并行变体均不采纳。延后分批解决了结果失效，但完整GP窗口的P99仍显著退化；共享静态来源及独占交接导航缓存也未建立整步收益。生产源码与测试保持dev `5712c6f7fbc7e222e2a483bc376201352fd5ffc2`，本轮基线工程提交为`afff405b1f6f66e51a95fe76bf77ef35924516b2`。正式性能验收仍未通过。

## 固定输入与完整整步

沿用同一合法160人输入：120患者、32员工、8访客，4层、64房间、1336设施，0.1秒固定步长。Godot 4.7.2 Windows headless debug、原生DLL、默认四任务部门环境采样、结构反向场、12次真实查询预热、128MiB导航总预算及查询部分1/4清理规则保持。每个进程重新创建服务，不恢复运行时缓存、不提前预热、不截短前缀。

## 实际并行边界与失败原因

所有变体实际调用`WorkerThreadPool.add_group_task()`，并等待完整屏障后按原visit顺序消费。工作线程只计算候选区域、入口和旅程报价；意图、实际移动、取位与预约仍由原主线程路径提交。每个任务拥有独立WorldState派生索引、空间服务、可变查询容器及AStar对象。身份、tick、几何、人物、适配/预约、连接与交通票、房间改建、权限、故障、有效扫掠和内容均在消费前复核；不符时回退原选择。完整缓存预算在主线程和任务间分配，没有另加每线程128MiB。

| 实际工作 | B | C | D | E |
| --- | ---: | ---: | ---: | ---: |
| 批次 / job数 | 1 / 4 | 19 / 38 | 19 / 38 | 19 / 38 |
| Worker请求 / 完成 | 112 / 112 | 94 / 94 | 94 / 94 | 94 / 94 |
| 直接消费 / 失效回退 | 9 / 103 | 94 / 0 | 94 / 0 | 94 / 0 |
| 完整窗口区域派生，控制4次 | 20 | 156 | 4 | 4 |
| 静态路径实际构建，控制191次 | 379 | 390 | 390 | 306 |
| 路线请求入口，控制391次 | 601 | 580 | 580 | 514 |
| 图缓存驱逐，控制未出现 | 76 | 未出现 | 未出现 | 未出现 |

B在早期人物按原顺序取位后，后续103份结果的人物事实证明失效，必须重新计算。四份冷缓存又在原总预算内触发76次驱逐。线程确实并行执行，但重复工作显著增加。

C在实际扫描位置才准备批次。使用完整身体包络检查是否已经位于候选区域内，包含偏移身体；可能立即取位者先串行执行。批次遇到已有生活任务、到期需求、已有座位处理或可能取位的人物时停止；可安全跳过的纯continue分支保留原顺序。94个Worker查询全部有效，其他18个选择仍串行执行，完整区域访问保持112次。独立边界成立，但产生19个碎片批次，每批重新准备两套服务和冷缓存，反复派生区域156次，原本跨人物摊薄的来源和距离场也被拆散。

D在屏障前完成区域唯一的惰性入口单元准备，借用已完成区域、设施位置和楼层来源的只读叶子。外层映射、门视图、索引、查询和AStar仍私有；主线程在屏障期间不修改来源。消除了重复区域派生，但38套私有服务仍重复准备门视图、连接拓扑和路径图。D的结构反向场未出现成功命中，控制有51次；不是原12次预热规则被取消，而是私有冷记录没有得到原串行共享的累计次数。

E在无开放路线查询的主线程边界，将导航缓存条目独占移给job0，主线程缓存容器暂时为空；屏障后归还，另一job只补入不同键。相同AStar没有同时用于两个线程。E保留12次结构反向命中，但仍有38次连接拓扑准备、39次门视图准备，第二个任务在碎片批次间反复冷建，额外路径工作未消除。该试验没有合入生产。

## 验证、保留与未完成

全部10个引擎窗口、1080步完成，160人资格、完整业务、事件、随机流、最终状态和非计时sample通过隔离核对。四个变体均实际记录非主线程ID，所有请求完成且每份结果均归入消费、拒绝或未使用；没有失败批次、未使用结果或脚本错误。引擎进程时间区间核对无重叠。

初次工程准备误用`report["worker_sample"]`文本锚点，断言失败，没有启动引擎；实际runner使用`report.worker_sample`。修正后另建baseline02工程，原baseline目录未覆盖，来源逐项核对并保留失败记录。两次只读定位使用了不存在的源码路径，按实际文件名继续，不作为游戏失败或计时证据。

四个变体因完整窗口退化全部拒绝，没有运行原定STAFF-48、57、61、69、75与SPACE-51独立功能回归；不将最终状态相同称作这些业务用例通过。未变生产的第三人真实退出、负缓存唤醒及让座证据继续引用[占满座位依赖回归](2026-10-23-occupied-seat-dependencies.md)。没有新增生产代码、测试或缓存失效责任。
