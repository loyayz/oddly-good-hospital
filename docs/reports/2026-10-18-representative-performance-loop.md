# 固定 160 人完整步性能闭环与重复工作排查

dev `dba8612cef21668cbd7b38560c19f9f40b0e3847` 基础上，实际 GP 工作与会诊交接的快速对照取得整步收益：三对无插桩窗口的均值中位数 **564.935ms → 86.847ms，下降84.63%**。完整事实、随机流与有序事件二进制相同。收益集中在两个昂贵交接步，**P50、P95 没有改善**。含实际门诊、清洁、休息/睡眠及待工装修的组合窗口，首步两次55秒探针均超时，尚未形成合格的整步收益证据。

全库同类排查另记录 **37 类残余静态候选**，见 [重复扫描与重复执行审计](2026-10-18-repeated-work-audit.md)。静态候选、快速收益和正式验收分别记载；本报告不宣称整体性能达标。

## 相关功能回归

变化的规则是有效原票的员工工作所有权；实际交接为等待→真实到场→开工、失败不分配、临床准备/护理占用和选定医生报价。接口语义未变的供给、候诊与环境消费者在代表边界停止扩大，不默认运行完整专题。

本批选择 `CLIN-01/02/06/15/16/23`（票与真实开工、报价/准备原子性、护理所有权）、`STAFF-35/42`（相关设施和候诊占用）、`OPS-11/32`（缺包及临床结果交接），**10项通过**。一次工程准备2.438s、导入8.018s、实际测试进程11.536s、总22.011s；用例记录/前提来源和各正文耗时完整保留。此前最终b7eb临床源上的 `CLIN-33/34` 两项通过，套件正文15.061s，144报价变体；相关实现和用例未变化，复用结果不重跑。

总计12项不同的相关用例证据，不是全库/全专题通过。独立静态复核未发现这32行临床改动的阻断问题。静态、导入、功能回归、性能测量和渲染证据分别报告。
