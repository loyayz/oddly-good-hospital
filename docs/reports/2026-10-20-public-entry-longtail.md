# 公共入口长尾与重复局部派发

基线为dev `39402b6c127d52bce425c3c7e834ca75f072bf39`。同一合法160人场景中，原11～13秒长尾主要耗在公共区域入口候选的重复下界计算、对象构造和脚本排序。入口查询改为批内计算复用与原生整数排序；实际终点被占时保留原行程等待，避免重复派发无法消除占用的路线。相关回归另发现并修复碰撞矩形浮点漂移。正式性能验收继续暂停。

原始输入、逐步耗时、函数覆盖清单、失败及最终世界见[证据目录](evidence/2026-10-20-public-entry-longtail/README.md)。

## 长尾时间分摊

补齐57个根阶段标记，并将原来遗漏的实际`HospitalNavigation`、`HospitalMovement`实例接入函数观察；记录实际包装路径、方法、缺失方法和生成源码。阶段互不重叠；函数inclusive包含子调用，exclusive扣除已观察子调用，不能相加inclusive，也不能把函数耗时再加到阶段耗时。未包装的叶子工作仍归直接调用者，不宣称每条语句都已独立计时。

公共及GP的原最大步均为窗口第28步，分别是tick2651、851。根阶段独立诊断如下：

| 场景 | 完整步 | 候诊/公共任务调度 | 占比 | 实际移动阶段 |
| --- | ---: | ---: | ---: | ---: |
| 公共 | 11.446秒 | 11.410秒 | 99.68% | 11.17毫秒 |
| GP | 13.243秒 | 13.201秒 | 99.68% | 18.42毫秒 |

细化函数后的同一步中，公共`_waiting_point`调用103次，自身耗时10.014秒，占所观察整步88.14%；实际点到点查询885次、inclusive仅0.343秒。GP对应入口调用120次，自身11.613秒，占85.69%。这些长尾的主要成本不是移动执行或A*本身。

进一步观察公共入口下界：`_entry_lower_bound`调用642294次，自身5.880秒；入口函数扣除它和其他已观察子调用后仍有4.577秒，包含候选对象构造、脚本比较排序及其他未单列工作。每个点反复读取相同身体、速度、起点和取整参数，每个候选另建Dictionary，再经`sort_custom`多次进入脚本比较器。

细探针自身记录开销1.682秒，使该诊断步达到13.343秒；这些数字只定位成本，不与最终plain计时直接计算收益。根阶段诊断开销约0.1毫秒，普通嵌套探针在公共原长尾约113毫秒。原有及最终40步剖面的事实、事件、随机流二进制摘要均与同输入的基线plain40一致；360步移动观察的最终摘要也分别与对应plain运行一致。

## 修复及保留边界

| 问题 | 处理 | 保持的规则 |
| --- | --- | --- |
| 每个入口点重复计算相同起点、身体、速度及步数换算 | 同一查询只准备一次参数与有限距离步数表；跨层最后落点与已有估时同批准备 | 小数起点的独立两次ceil、未知估时的原弱下界、真实路线报价保持 |
| 大量候选Dictionary和脚本比较排序 | 使用`PackedInt64Array.sort()`；安全整数编码保留原下界、y、x总顺序 | 枚举全部原候选，无人数、区域、距离或候选上限；严格最佳值更新保持；大整数或不能安全编码时完整回退原元组排序 |
| 终点被实际碰撞者占用仍每步重排 | 原礼让之后，仅在本次实际命中的当前身体必然占住本层段终点时正常等待 | 原路径、目标、FIFO、blocked时钟及每步实际碰撞保持；身体离开即可恢复；同行逐成员判断，不合并空隙；躺卧与不能证明的情况沿原查询 |
| 当前朝向边角被挡被误当成所有到达方向都无解的风险 | 只用任何直立朝向都包含的中心正方形证明必占 | 换到达朝向可能避开的长方身体边角仍可绕行；历史扫掠和中途障碍不冒充当前终点占用 |
| 同朝向矩形反复平移产生浮点漂移 | 从实际目标位置与已缓存身体形状生成目标矩形 | 不放宽重叠容差、身体尺寸、移动步长或完整组提交；沿用原精确扫掠 |

排序使用引擎现有原生实现，没有新写通用排序或寻路算法。真实目标空闲、预约、队权、身体适配和到场取位检查保持；没有缩小合法区域或提前绑定公共设备。

## 派发和退让增加的原因

对先前`913cebe`及基线`39402b6`各观察同输入360步，并核对最终世界与各自原plain运行一致。旧版本只用于解释前一轮计数增加，性能优化基线仍为最新`39402b6`。

| 观察项 | 旧913 | 基线394 | 最终修复 |
| --- | ---: | ---: | ---: |
| 实际路线派发 | 490 | 1118 | 381 |
| 局部绕行入队 | 253 | 877 | 138 |
| 重复人物/目标/局部目标/身体/几何签名的派发 | 228 | 834 | 112 |
| 原定义`yield_attempts` | 1051 | 1599 | 1599 |
| 真正派发的退让行程 | 37 | 40 | 40 |
| 同目标请求复用 | 3835 | 3787 | 3787 |
| 真正改目标重规划 | 2 | 2 | 2 |

此前新增的628次派发主要对应新增624次局部绕行入队。最新基线3971次请求中，3787次同目标请求复用原行程，只有2次真正改目标；不是任务每步重设目标导致1118次派发。`yield_attempts`表示进入退让处理的尝试，不表示实际做了1599次退让动作。

基线最突出的`bench_patient_0104`和`bench_patient_0044`分别局部重排251、180次，位置停在目标前，目标分别为[8,15]、[53,15]。实际终点被身体占用，局部查询找不到动态替代时仍以`contention`返回原结构路线；派发成功并不表示占用解除，下一步再次受阻，又立即重排。旧版相同人物已完成行程，拥堵与路线分布变化暴露了这个已有循环；重复重排在旧版也存在。

最终739次明确的终点占用等待替代无效入队，实际派发减少737次；入队与已派发数受窗口末尾待处理项影响，不能混用。原1599次等待/退让检查没有少做，真实优先级判定和40次退让行程保持。观察器仍将这739次无入队返回保守标为`unknown_no_queue`，生产`local_goal_occupied_waits=739`提供明确分支证据；没有把标签猜测冒充观测。

## 相关回归与失败

9项相关选例全部通过：STAFF-45、61、65、71、75；SPACE-10、53、56、57。覆盖真实到场使用、完整入口独立枚举、小数起点、稳定平局、近点被实际占用、远端唯一候选、大整数排序回退、目标占用/释放、长方身体、门、礼让和完整组。

最终6项共享准备3.506秒、导入6.929秒、测试4.369秒；随后补验涉及真实移动的STAFF-61/65，准备3.459秒、导入6.836秒、测试3.026秒。纯候选计算STAFF-75复用首批通过证据，其候选实现、输入及依赖没有变化；未重复完整专题或全量回归。各例前提、构建/读取时间及实际断言时间均保留。

- 首批9项有1项断言失败，另SPACE-56断言虽通过但出现脚本错误，不能当成全组通过。旧礼让探针缺少当前接口需要的cursor/path，补齐探针前提后SPACE-56干净通过。
- 单人释放场景没有实际产生先前假设的历史扫掠命中；真实等待、释放和到达断言保持，历史扫掠契约另用合法0.2格碰撞计算输入验证，没有伪造人物完成移动。
- SPACE-57组安全连续三批失败。tick143实际扫掠矩形与世界身体矩形相差数个float32舍入单位，生产返回无命中，真实身体时空扫掠却相交；端点不重叠并不足以证明途中安全。修复目标矩形来源后，原安全、真实恢复、组到达及所有其他断言全部通过。
- 一次补测命令因自动审批服务403未执行，经同一审批入口重试成功，原服务失败说明保留；没有将未执行当成测试失败或通过。

## 未采用的删减与剩余问题

| 做法 | 未采用理由 |
| --- | --- |
| 保留少量最近入口、缩小区域或负载 | 会遗漏合法最优点和远端唯一可用点，改变规则；完整候选仍被测试 |
| 删除实际碰撞或改为低频轮询 | 临时占用可能每步改变，且本轮已复现真实途中碰撞；只取消已证明无效的重排 |
| 用当前朝向完整矩形或同行合并AABB判定终点必占 | 换朝向或组间空隙仍可能合法，必须保守证明 |
| 用加大epsilon掩盖组安全失败 | 会放宽真实碰撞规则；修复矩形事实来源，不改容差 |
| 仅凭重复行程签名缓存所有失败绕行，或设置重试冷却 | 签名未覆盖周围身体变化；其他人移动可立即打开绕路，失效不全会压住合法恢复 |
| 将公共排队、等电梯或未知等待视为无路 | 排队合法，不能靠拒绝出发降低成本 |
